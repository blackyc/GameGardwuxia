# GameGard 项目架构参考

## 基于《杀戮尖塔2》(Slay the Spire 2) 解构的完整目录结构

本文档说明每个目录的职责，以便团队成员正确放置资源。
**完整复刻STS2架构，不做裁剪。**

---

## 📁 项目根目录 `GameGard/`

```
GameGard/
├── .autoconverted/   ← STS2引擎自动转换文件
├── .tmp/             ← 临时文件
├── .godot/           ← Godot引擎缓存（自动生成）
├── src/              ← 源代码（C# + GDScript）
├── scenes/           ← Godot 场景文件（.tscn）
├── images/           ← 图片资源（PNG/JPG/Atlas）
├── animations/       ← 动画资源（Spine）
├── materials/        ← 材质文件（.tres/.mat）
├── shaders/          ← Shader 文件（.gdshader）
├── fonts/            ← 字体文件
├── localization/     ← 本地化文本（14种语言）
├── themes/           ← Godot 主题资源
├── models/           ← 3D模型/辅助模型
├── banks/            ← FMOD 音频 Banks
├── addons/           ← Godot 插件
├── steam/            ← Steam SDK 集成
├── System/           ← 系统文件
├── doc/              ← 项目文档
├── .gitignore
├── project.godot
└── README.md
```

## 🎮 `src/` — 源代码层

所有游戏逻辑代码，分为三大模块：

### `src/Core/` — 核心逻辑（C#）

**Entities（游戏实体定义）** — 定义游戏中的各种实体的类型、枚举、接口：
| 目录 | 职责 | 放什么 |
|------|------|---------|
| `Entities/Cards/` | 卡牌实体 | CardType、CardRarity、CardKeyword、CardPile、CostModifiers 等枚举和类 |
| `Entities/Creatures/` | 生物实体 | Creature 基类、生命值、护甲等 |
| `Entities/Characters/` | 角色实体 | 可选角色定义 |
| `Entities/Players/` | 玩家实体 | Player 基类和角色实现 |
| `Entities/Powers/` | 能力/Buff实体 | PowerType、PowerStackType |
| `Entities/Relics/` | 遗物实体 | 遗物类型和效果定义 |
| `Entities/Potions/` | 药水实体 | 药水类型和使用逻辑 |
| `Entities/Orbs/` | 宝珠实体 | 宝珠类型和触发逻辑 |
| `Entities/Enchantments/` | 附魔实体 | 附魔机制 |
| `Entities/Encounters/` | 遭遇实体 | 遭遇类型定义 |
| `Entities/Intents/` | 怪物意图 | 意图图标和类型 |
| `Entities/Merchant/` | 商人实体 | 商人物品和定价 |
| `Entities/Gold/` | 金币实体 | 金币管理 |
| `Entities/Rewards/` | 奖励实体 | 战斗奖励类型 |
| `Entities/Rngs/` | 随机数 | 各种子随机数生成器 |
| `Entities/RestSite/` | 休息点 | 休息点选项 |
| `Entities/Actions/` | 行动 | 卡牌行动、攻击行动等 |
| `Entities/Ancients/` | 神灵 | STS2特有：古代神灵实体 |
| `Entities/Ascension/` | 难度提升 | 上升难度系统 |
| `Entities/CardRewardAlternatives/` | 卡牌奖励选择 | 替代卡牌奖励 |
| `Entities/TreasureRelicPicking/` | 遗物拾取 | 宝藏遗物选择 |
| `Entities/Models/` | 数据模型 | 数据绑定模型 |
| `Entities/Multiplayer/` | 多人实体 | 多人模式实体定义 |
| `Entities/Text/` | 文本 | 文本实体 |
| `Entities/UI/` | UI数据 | UI状态数据 |

|------|------|---------|

| `Multiplayer/Messages/` | 消息协议 | 多人通信消息定义 |
| `Multiplayer/Transport/` | 传输层 | 网络传输实现 |

## 🏗 架构核心思想（来自STS2）

### 三层分离原则

1. **逻辑层** (`src/Core/` 纯C#) — 不依赖Godot节点，可独立测试
   - `Entities/` 定义"是什么"（类型、枚举）
   - `Models/` 定义"具体数据"（每张卡的数值）
   - `Combat/`、`Commands/`、`GameActions/` 定义"怎么做"（逻辑流程）

2. **节点层** (`src/Core/Nodes/`) — C# Godot节点，连接逻辑和视觉
   - 继承Godot节点类（Node2D、Control等）
   - 调用逻辑层API，驱动UI变化

3. **场景层** (`scenes/`) — .tscn文件，纯Godot编辑器产物
   - 在Godot编辑器中组装
   - 节点树结构、资源引用、布局

### 命令模式（Command Pattern）

STS2使用 `Commands/` 实现可撤销的操作：
- 每个卡牌行动 → Command对象
- Command可执行/可撤销 → 支持战斗回退
- `Builders/` 简化Command创建

### 事件钩子系统（Hooks）

`Hooks/` 允许遗物/能力在战斗流程中"钩入"关键节点：
- 出牌前 → 检查遗物是否修改费用
- 伤害结算后 → 触发遗物效果
- 回合结束 → 触发持续效果

### 多人游戏架构（Multiplayer）

STS2独立的多人模块：
- `Entities/Multiplayer/` — 多人实体定义
- `Multiplayer/Connection/` — 连接管理
- `Multiplayer/Game/` — 多人游戏逻辑
- `Multiplayer/Messages/` — 通信消息协议
- `Multiplayer/Transport/` — 网络传输层

## 🔑 协作指引

### 资源放置规则

| 角色 | 工作目录 | 注意事项 |
|------|---------|---------|
| **程序员** | `src/Core/` | 先写Entities和Models，再写Nodes |
| **场景制作** | `scenes/` | 在Godot编辑器中创建，引用Nodes脚本 |
| **美术** | `images/` + `animations/` | 图片放对应类型目录，动画放对应类型目录 |
| **特效** | `vfx/`（scenes+vfx下） | 场景+图片+材质+shader配套放置 |
| **数值设计** | `doc/balance/` + `src/Core/Models/` | 设计表在doc，实现在Models |
| **本地化** | `localization/` | 翻译文件放对应语言目录 |
| **UI设计** | `themes/` + `materials/ui/` | 主题和材质配套 |
| **音频** | `banks/` | FMOD Bank文件放在banks目录 |

### 命名规范（参考STS2）

- **C#文件**：PascalCase，如 `CardType.cs`、`IroncladPlayer.cs`
- **场景文件**：snake_case，如 `card_selection_screen.tscn`
- **图片文件**：snake_case，如 `bash_card_art.png`
- **Spine动画**：snake_case，如 `jaw_worm_front.skel`

### 不要手动创建的文件

以下文件必须在Godot编辑器中创建/修改：
- `.tscn` 场景文件
- `.tres` 资源文件（材质、主题等）
- `project.godot` 项目配置
