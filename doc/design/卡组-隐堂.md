# 【隐堂】卡组详解

## 流派定位

低费极速过牌 / 组合技（Combo）/ 毒素直伤。

## 宗师角色

**夜修罗**（HP：2）（主诡 / 副灵）

### 被动1：夜袭

你的回合打出的第一张[诡]系卡牌，内力消耗-2。

### 被动2：毒发

每当敌方累计获得3层[淬毒]标记时，标记清零，敌方直接失去1点生命值。每回合敌人可以因[淬毒]失去多点体力。

### 命中词条解释

携带[命中]词条的卡在出招区或判定区时，若敌方因战力判低获得[破绽]，则称为[命中]。

## 核心策略

1. **毒发是最主要输出**：不是靠战力赢，是靠叠毒→引爆→1血直伤
2. **夜袭免费引擎**：每回合第一张诡系几乎免费（阎王帖0费、透骨钉0费），极速展开
3. **血滴子是核心毒源**：0费2战力，进弃牌堆就淬毒——主动弃掉、被打掉、结算清场都可以触发
4. **佛怒唐莲斩杀线**：敌方淬毒≥3层时打出，吸取3层→基础战力翻倍→战力 10×2×2×2=80（3层时），一卡毙命
5. **万蛊噬心**：淬毒引爆阈值从3降为2，加速毒发频率
6. **暴雨梨花针**：清场+直伤，可用于斩杀或清破绽保命
