## 三、行动出牌策略逐阵营审计

### 3.1 魔教行动 (modengAction)

```javascript
秘术 → 对隐堂猛攻(gap>=1) → 修罗化血阵 → gap>=4找震伤 → 追平 → gap<2铺心法
```

| 环节 | 评估 |
|------|------|
| 修罗化血阵优先级 | 🔴 **当前是陷阱**：修罗化血阵的zhengshangDrain有Bug（扣自己内力），AI却热衷铺它。在Bug修复前，铺化血阵=自残 |
| gap>=12天魔解体 | ⚠️ **阈值过高**：600局测试0次触发。建议降至gap>=6或HP<=1时强制使用 |
| 对隐堂猛攻 | ✅ **合理**：gap>=1即出牌，防毒积累。但胜率仍只有36%，因为追平不够快 |
| 追平逻辑 | ⚠️ **不够激进**：尝试找 effPower>=gap 的单卡，找不到就打最强。若所有单卡都不够，应考虑combo（低废+中废连续出牌） |

**具体优化建议**:
1. **修罗化血阵**: 在zhengshangDrain Bug修复前，降低其scoreCard评分或暂时从AI优先级中移除
2. **天魔解体**: `gap >= 12` → `gap >= 6`，同时加条件 `self.hp <= 1` 时必触发（背水一战）
3. **祭血连环斩**: 当self.flaws>0时，scoreCard已有+4加分，但executePlay未体现flawDraw——确认代码已有 `if (card._data.effectType === 'flawDiscount' && card._data.flawDraw && self.flaws > 0) { gs.drawCards(...) }` → ✅ 已正确实现

### 3.2 武当行动 (wudangAction)

```javascript
纯阳牺牲(非隐堂) → 秘术 → 对隐堂快攻(gap>=2出牌/gap=0铺心法) → gap<3铺心法引擎
```

| 环节 | 评估 |
|------|------|
| 纯阳牺牲限制 | ⚠️ **`this.oppFaction !== 'yintang'`** ——对隐堂完全禁止纯阳牺牲！这是合理的（怕卖回合被毒死），但导致武当16%胜率下缺少补牌手段 |
| 对隐堂"gap=0也压一波" | ⚠️ **`gap=0`时铺心法而后立刻surrender**：即使铺了心法，下一步没有攻势力。心法铺完应继续出牌，而非立刻投降 |
| 兑隐堂快攻 | ⚠️ **gap>=2才行动**——阈值太保守！面对84%胜率的隐堂，gap>=1就应行动 |

**具体优化建议**:
1. **对隐堂阈值降低**: `gap >= 2` → `gap >= 0`（任何时候都找最优出牌）。隐堂毒速攻不给喘息空间
2. **纯阳牺牲对隐堂**: 若 `gap <= 3 && self.hp >= 2 && self.dantian.length >= 4`，允许牺牲。2心法换2牌，弃车保帅
3. **gap=0时**：不要立刻surrender。检查是否有 `innerToPower`/`innerToPowerBuff` 卡可以碾压式出牌（武当基础剑/九阳神功），或出 `moveCostReducer`（两仪桩功）为下回合减费
4. **太极剑意策略**: shouldTriggerTaichi中的 `self.hp <= 1 → false` 是对隐堂过度保守。对隐堂时hp<=1已经濒死，碰瓷即使掉hp也值得（早死晚死都是死，不如搏一把）
5. **缺少针对性的毒对策**: 武当AI完全不了解"毒"的存在——没有"尽快清毒"、"避免给含沙射影触发空间"的逻辑。建议加入：若 `opponent.poisonStacks >= 2`，优先出能直接赢判定的高战力牌（避免被阎王帖/含沙射影堆毒）

### 3.3 隐堂行动 (yintangAction)

```javascript
秘术 → 踏雪无痕回收 → 鬼影迷踪 → gap>=5毒爆发 → gap>=2铺毒/追平 → 隐堂基础内功
```

| 环节 | 评估 |
|------|------|
| 毒爆发优先级 | ✅ **极其高效**：`gap>=5`时佛怒唐莲→暴雨梨花针→万蛊噬心，精确的爆发链 |
| 铺毒策略 | ✅ **合理**：追不平就铺毒，为下回合爆发蓄力 |
| 血滴子利用 | ⚠️ **被动依赖**：血滴子是核心毒引擎（进弃牌堆=毒+1），但AI没有主动让它进弃牌堆的策略。只是打出后等自然结算清除 |

**优化建议**:
1. **隐堂太强了**——84%和64%的胜率说明AI不需要优化，但需要**数值调整**（降低毒发阈值/减慢毒积累速度）
2. **鬼影迷踪阈值**：`gap > 0 && gap <= 6`——gap>6时无法使用。这合理，但可以在gap>6时加入"含沙射影盖放→下回合必毒"的远期规划
3. **千机图谱除外选择**：代码优先从弃牌堆除外，保留了手上资源 → ✅ 策略精明

## 九、结论

当前AI策略**整体优秀**——阵营特色鲜明、克制矩阵应用准确、秘术时机选择合理。主要问题在：
1. **4张卡牌未实现/有Bug** 拖累整体强度（魔教尤甚）
2. **武当对隐堂策略过度保守** 导致16%的灾难性胜率
3. **隐堂数值过高**——84%胜率说明毒系速攻在当前版本缺乏克星

修复P0项后预计效果：魔教 vs 武当 35-40% → 45-50%，魔教 vs 隐堂 36% → 40-45%，武当 vs 隐堂 16% → 25-30%。但隐堂仍需**数值削弱**才能达到50%±10%的平衡区间。
