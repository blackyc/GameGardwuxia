# B2 文本歧义审计

> 审计日期: 2026-05-22
> 对比对象: 卡牌效果文本（设计文档） vs 代码实现（ai.js / engine.js / combatResolver.js）

---

## 严重歧义（文本与代码行为显著不一致）

### 1. 九阳神功 — 效果文本 vs 实现完全偏离
| 维度 | 内容 |
|------|------|
| **设计文档** | 「每回合一次，消耗X点内力，令一张[武当]武技牌获得X点战力」——定向Buff |
| **cards_wudang.json** | `effectType: "innerToPowerBuff"`, power=8, innerPower=6 |
| **代码实现** | `if (et === 'innerToPowerBuff') power += self.innerPower;` ——仅自身战力加成 |
| **歧义性质** | 🔴 **严重**：设计意图是"消耗内力为任意武当武技增伤"，但代码实现为"自身战力=打底+当前内力"。完全不同的功能 |

### 2. 修罗化血阵 — 扣内力方向错误
| 维度 | 内容 |
|------|------|
| **设计文档** | 「每次打出带[震伤]的牌，**对方**失去1点内力」 |
| **代码实现** | `advantaged.innerPower = Math.max(0, advantaged.innerPower - 1)` ——扣**自身**内力 |
| **日志输出** | `'修罗化血阵：P' + disadvantaged.id + ' 失去1内力'` ——日志说扣的是对方 |
| **歧义性质** | 🔴 **严重Bug**：日志说扣对方但代码扣自己，卡牌效果与文本背道而驰 |

### 3. 天魔解体 — 效果文本仅部分实现
| 维度 | 内容 |
|------|------|
| **设计文档** | 「打出此牌你立刻损失1点血 **并立刻结算大清场**，结算后你**额外多抽2张**卡牌，**下个回合内你可以不支付任何【消耗】使用武技牌**」 |
| **cards_modeng.json** | `selfDamage:1, nextTurnFreePlay:true, bonusDraw:2` |
| **代码实现** | 在 `executePlay` 中**无任何 forcedResolution 特殊处理**。`selfDamage`、`nextTurnFreePlay`、`bonusDraw` 均未接入执行引擎 |
| **歧义性质** | 🔴 **严重**：标注了4项效果但无一实现。`scoreCard`中仅有+7加分，实际打出无效果 |

### 4. 修罗饮血功 — 文档有但代码无
| 维度 | 内容 |
|------|------|
| **设计文档** | 「每当你因自身效果获得[破绽]时，本回合临时获得1点内力」 |
| **cards_modeng.json** | `effectType: "selfFlawGivesInner"` |
| **代码实现** | ai.js / engine.js / combatResolver.js 中**无任何** `selfFlawGivesInner` 处理 |
| **歧义性质** | 🔴 **缺失**：卡牌数据已定义，效果文本已设计，但核心逻辑不存在 |

### 5. 梯云纵 — 文档有但代码无
| 维度 | 内容 |
|------|------|
| **设计文档** | 「[拆招]：敌方卡牌战力上升时响应。抵消敌方所获得的战力增幅效果，并使自己抽一张牌」 |
| **cards_wudang.json** | `effectType: "chaizhao_negateBuff"` |
| **代码实现** | ai.js / engine.js / combatResolver.js 中**无任何** `chaizhao_negateBuff` 处理 |
| **歧义性质** | 🔴 **缺失**：拆招牌完全空壳 |

## 中度歧义（文本描述与实现存在出入）

### 6. 餐风饮露功 — 多副本叠加问题
| 设计文档 | 「此卡提供的内力额外增加X，X为你弃牌堆内卡牌数量的一半（向下取整）」 |
|------|------|
| **歧义** | 「此卡」暗示**每张**餐风饮露功各自提供加成。但代码 `resetRound` 中 `break` 只触发一次，遍历到第一张即停止。若丹田有3张餐风饮露功，按规则应是 3×floor(弃牌堆/2) 内力，但代码只计1次 |
| **严重度** | ⚠️ 中度：理论上3张餐风饮露功应该产生 3×地板(弃牌堆/2) 内力，现在只产生 1×地板(弃牌堆/2)。但通常玩家不会在丹田放3张同卡 |

### 7. 克制加成数值不一致 — 文档内部矛盾
| 核心规则.md §3.2 | 「优势方的该卡牌基础[战力]+6」 |
|------|------|
| 核心规则.md §3.2（后段） | 「无法触发**+8**加成」 |
| **歧义** | 同一段话出现 +6 和 +8 两个数值。代码使用 `CONST.counterBonus`（需确认实际值但大概率=6）。可能是旧版残留（v0.8时期克制加成=8） |
| **严重度** | ⚠️ 中度：文档自身矛盾，容易误导新开发者 |

### 8. 纯阳无极剑 — 触发条件泛化
| 设计文档 | 「**因此卡**造成破绽时，恢复自身1点生命值」——强调必须是这张卡导致破绽 |
|------|------|
| **代码实现** | `triggerFlawHeal` 在对手放弃出牌时检查 advantaged 是否有 `flawHeal` 卡，只要有就回血。不验证是否"此卡"造成的破绽 |
| **歧义** | 规则文本暗示需因果联系，代码弱化为"在场即可"。实战中差异不大（优势方通常恰好用该卡打败对手），但严格语义不一致 |
| **严重度** | ⚠️ 中度：多数情况下结果一致，但多卡组合战可能存在差异 |

### 9. 鬼影迷踪 — 劣势判定由AI标记而非引擎校验
| 设计文档 | 「打出时**若处于劣势**，立刻抽1张，本回合内此卡返回手牌」 |
|------|------|
| **代码实现** | `clearZones` 检查 `_returnToHand === true` 决定是否回手，但「是否处于劣势」的判定完全依赖 AI 设置此标记。引擎未验证打出瞬间的实际战力差 |
| **歧义** | 若更换AI实现或手动操作，可能在不劣势时也返回手牌。引擎应独立校验 `disadvantaged` 状态 |
| **严重度** | ⚠️ 中度：当前AI正确，但耦合度过高，换AI可能出错 |

### 10. 透骨钉（魔教版）— 淬毒无收益
| 魔教 rules 文档 | 「命中时，赋予1层[淬毒]」 |
|------|------|
| **cards_modeng.json** | `hasHit: true` → 命中触发 `triggerHitEffects` 给毒 |
| **歧义** | 透骨钉是公共卡，魔教预组中确实包含它。但魔教角色/卡组**没有任何毒收益机制**（毒是隐堂专属），给毒纯粹是"白送"。这不算Bug但会造成玩家困惑："我毒对方然后呢？" |
| **严重度** | ℹ️ 轻微：设计选择问题，不影响游戏正确性 |

## 轻微歧义（描述不够精确）

### 11. 聚气诀 — 文本描述与实际流程差异
| 设计文档 | 「此卡从手牌明牌打出进入[出招区]（不提供内力），直到你的下回合开始时，才被移入【丹田区】生效。若打出时你有[破绽]，则取消延迟直接进丹田」 |
|------|------|
| **代码实现** | 有心法类型卡牌通过 `executePlay`：无破绽 → `actionZone`（等 `resetRound`）；有破绽 → 直接 `dantian` |
| **歧义** | 文本说「进入出招区（不提供内力）」但代码中它是心法类型，`executePlay` 直接 `dantian.push`（有破绽时）或 `actionZone.push`（无破绽时）。有破绽时它**直接进丹田并即时+3内力**，而不是"取消延迟进丹田"。文本未明确"有破绽时是否即时获得内力" |
| **严重度** | ℹ️ 轻微：结果相同，只是文本未覆盖细节 |

### 12. 修罗饮血功 — effectType 命名歧义
| effectType | `selfFlawGivesInner` |
|------|------|
| **歧义** | 「selfFlawGivesInner」暗示"自身破绽给内力"，但设计文档说的是"因自身效果获得破绽"——限定为**主动自伤**获得的破绽才触发。这个命名可能误导开发者以为所有破绽都触发 |
| **严重度** | ℹ️ 轻微：功能尚未实现，但不修正名称后续实现可能出错 |

### 13. 武当基础心法 — altEntryDantianDraw vs 太极剑意
| 设计文档 | 武当基础心法：「此卡因打出以外的途径进入[丹田区]时，抽1张牌，且本回合你使用的第一张[巧]系武技卡消耗-1」 |
|------|------|
| **代码实现** | `judgmentPhase` → 太极剑意触发的重判 → `altEntryDantianDraw` → 抽1 + `_skillfulDiscount = true` |
| **歧义** | 文本说"进入丹田区时"，但代码只在太极剑意碰瓷的特定路径触发。若未来有其他「非打出进丹田」途径（如卡牌效果），可能遗漏此触发 |
| **严重度** | ℹ️ 轻微：当前只有太极剑意一条非打出进丹田路径，但架构耦合 |

## 歧义汇总

| 级别 | 数量 | 关键项 |
|------|------|--------|
| 🔴 严重 | 5 | 九阳神功功能偏离、修罗化血阵方向Bug、天魔解体未实现、修罗饮血功缺失、梯云纵缺失 |
| ⚠️ 中度 | 5 | 餐风饮露功多副本、克制加成数值矛盾、纯阳无极剑触发泛化、鬼影迷踪耦合、透骨钉淬毒无收益 |
| ℹ️ 轻微 | 3 | 聚气诀流程细节、effectType命名、武当基础心法路径耦合 |

**结论**: 最紧迫的是5项严重歧义——它们要么是代码Bug（修罗化血阵），要么是完全缺失（修罗饮血功/梯云纵/天魔解体），要么是实现方向错误（九阳神功）。
