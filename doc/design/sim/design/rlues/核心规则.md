《江湖对决》核心规则说明书 v1.0
1.0 游戏概述
《江湖对决》是一款1V1双人对战卡牌游戏。玩家将扮演一位武学宗师，通过构筑独特的卡组，在战斗中利用招式克制与心理博弈，使对手暴露[破绽]，最终将其击败。
1.1胜负条件：双方玩家初始拥有等同于[角色被动]所规定的生命值（通常为3点）。率先将对方生命值削减至 0 的玩家获得游戏胜利。
1.2生命与破绽：游戏中，玩家因处于判定劣势或受卡牌效果影响，会获得**[破绽标记]。当任意一方玩家累计获得 2个[破绽标记] 时，将扣除其1点生命值**。
1.3资源基石（内力）：玩家出牌须支付相应的[内力]点数。内力池的上限由置入在【丹田区】的心法卡数量决定，每回合重置全额点数。
1.4胜利条件：将对手的[生命值]降至0。
2.0 玩家区域
每位玩家面前的游戏区域划分为以下部分：
[主卡组] (Main Deck)：玩家的主要牌库，游戏开始前放置洗切好的25张卡牌。背面朝上，抽牌的唯一来源。
[额外卡组] (Extra Deck)：放置5张无需洗切的高阶[绝学]卡牌，独立于主卡组，必须通过条件“领悟/检索”才能置入卡组。
[手牌] (Hand)：玩家持有的、可打出的卡牌，玩家最多拥有8张手牌，超过8张再获取手牌时直接进入弃牌堆。
[判定区] (Judgment Zone)：单格。仅用于[准备阶段]暗盖卡牌，确立本回合初步优势。判断区只能存在一张牌。
[出招区] (Action Zone)：用于[出牌阶段]明牌打出的武技卡。在此区的卡牌将提供战力或生效其动作词条。出牌区的牌只能明牌。
[丹田区] (Vigor Zone)：放置[心法卡]以提供[内力]和[战力]的区域。此处卡牌作为常驻引擎，回合结算时不会**进入弃牌堆，长久累积。一旦心法牌离开丹田区，玩家立刻失去心法牌所提供的[内力]和[战力]加成。
[弃牌堆] (Discard Pile)：使用、被破坏或被弃置的卡牌进入此区域。
[除外区] (Exile Zone)：被特定效果（如[秘术]献祭）移出游戏的卡牌进入此区域，本局游戏无法再使用。
3.0 卡牌类型与关键机制
3.1 卡牌类型
[武技卡]：用于战斗的核心卡牌，拥有[战力]点数和所属武系。
[心法卡]：用于提供[内力]的资源卡，打出后常驻于[丹田区]。只在[丹田区]提供属性加成。
[秘术卡]：带有[秘术]次标签的特殊卡牌，通常用于从[额外卡组]获取卡牌。
3.1.1卡牌牌面标准UI范例：
【名称】 《太极剑法》
【类别与系别】 武技卡 · 巧系
【次标签】 [剑法] / [武当]/ [秘术]
【属性点】 消耗 2 内力 / 战力 6
【效果文本】 若你丹田内有[武当心法]，此牌战力+3。
【风味文本】太极生两仪，两仪生四象
3.2 武技四象相克
武技卡存在绝对属性压制。判定其胜负依据为：最终战力 = 卡面基础战力 + 克制加成 + 其他效果增益。
四象属性：[灵]、[诡]、[巧]、[霸]。
克制链：[灵]＞[诡]＞[巧]＞[霸]＞[灵]。
克制加成：在[判定阶段]，若盖放的武技卡存在克制关系，优势方的该卡牌基础[战力]+6。
无克制关系：若不存在直接克制（如[霸] vs [诡]），则双方均无加成，仅比较总[战力]。[心法卡]被用作盖牌时视为无属性，不会被克制（无法触发+6加成）。
3.3 关键状态：[破绽标记]
[破绽标记]是衡量玩家劣势程度的指示物。
当任意玩家累计获得 2个[破绽标记] 时，该玩家失去1点[生命值]，并立即抽2张牌。
4.0 游戏流程
4.1 游戏准备
选择宗师：双方选择各自的[宗师角色]，明确其初始[生命值]与被动技能。
构筑卡组：按照6.0规则准备好25张[主卡组]与5张[额外卡组]。
起始手牌：将[主卡组]洗切后，各自抽取5张牌作为起始手牌。
4.2 战斗阶段循环
游戏在一个动态的阶段循环中进行，每个回合可能历经反复交锋，必须严格依照顺位处理。一回合包含以下四步，第三/二步可能会不断折返，直到进入第四步。
4.2.1 [准备阶段] (Preparation Phase)
玩家自身技能/状态结算（若有）。
双方各自从手牌中选择1张武技或心法卡，**背面朝上（暗盖）**放置在【判定区】内。（不消耗内力）
4.2.2 [判定阶段] (Judgment Phase)
双方同时翻开[判定区]的卡牌。
执行【克制加成规则】，结算双方全场（判定区+出招区+所有其他修正）的总战力点数。
总[战力]较低的一方成为**[劣势方]**。每个回合，每位玩家首次成为[劣势方]时立刻抽取 1张主卡组手牌。
游戏进入[出牌阶段]，由[劣势方]获得优先行动权。(特例：总点数相同时，目前拥有破绽最少的人变为劣势方；若完全对等则猜拳决定优先权)
4.2.3 [出牌阶段] (Action Phase)
4.2.3.1行动权：当前[劣势方]拥有行动权并主导本阶段，另一方除非持有[拆招]响应卡外，须静默等待。此时操作方可以执行以下任意行动且次数不限，只要有牌与相应费用：
打出心法：打入[丹田区]作为资源引擎，当前即可产生等额[内力]点数。注意，心法牌只有在丹田区中才会提供玩家内力，若心法牌因效果原因离开丹田区，玩家立即失去对应内力。
打出武技：消耗相应的内力点数，将武技打入[出招区]。结算该武技附带文字效果，并将战力数值加加入自身总战力内。
合成功法：发动特定具有[秘术]标签或描述的功能置出卡牌压缩牌库换出高阶组件卡牌入场或入局操作。
4.2.3.2出牌规则：当出牌方不再出牌或耗尽所有手牌与内力后，须主观宣告“本轮出牌终结”。
4.2.3.3循环触发：行动方宣告结束后，若其总[战力]已超过对手，游戏立即重新进入[判定阶段] 4.2.2。此时，原优势方将成为新的[劣势方]，并重复该阶段的流程。
若玩家在自己的[出牌阶段]无法或不愿再出牌追赶战力，可宣告放弃，此时将再次被判定为[劣势方]，获得第1个[破绽标记]，并进入结算阶段。
4.2.4 [结算阶段] (Resolution Phase)
触发条件：任意玩家在[劣势状态]下因战力不足而获得1个[破绽标记]时。
结算流程：
将双方[判定区]和[出招区]的所有卡牌置入[弃牌堆]。
双方未使用的手牌不进入[弃牌堆]，[劣势方]抽1张牌，[优势方]抽2张牌。
游戏返回[准备阶段] 4.2.1，开始下一轮交锋。
5.0 牌库与抽牌规则
5.1 抽牌条件
玩家仅在以下特定时机抽牌：
游戏开始时，抽5张牌。
每回合，每个玩家在首次成为劣势方时，抽1张牌。
在[结算阶段]，[劣势方]抽1张牌，[优势方]抽2张牌。
玩家损失一点生命值时，抽2张牌。
5.2 牌库耗尽
当玩家需要抽牌，但其[主卡组]卡牌数量为0时，必须先将其[弃牌堆]的所有卡牌洗切，形成新的[主卡组]。
完成洗切后，作为惩罚，该玩家立即获得 1个[破绽标记]。
6.0 卡组构筑规则
卡组容量 (Deck Size)
[主卡组]：必须严格为 25张。
[额外卡组]：必须严格为 5张。
同名卡限制 (Copy Limit)
同名卡牌最多投入 3张。
资源牌浓度限制 (Resource Cap)
[心法卡] 的总数量不得超过 10张。（特定角色被动可突破此限制）。
双修法则 (Dual-System Limit)
必须且只能选择 1个[主修武系] 和 1个[辅修武系]。
[辅修武系]的武技卡总计不得超过 5张。
攀升限制 (Key Card Limit)
带有 [秘术] 次标签的卡牌，总计不得超过 2张。

8.0“初始破绽”机制
因为 1滴血 = 2个破绽，直接给角色加1滴血可能步子迈得太大（导致4血角色胜率飙升）。
作为设计师，如果你发现某个角色给3血太弱，给4血又太强怎么办？
我们可以引入**“初始破绽”**的概念（类似于围棋的贴目，或者某些游戏的初始护盾）。
微调档位示例：
T0 强力机制角色： 2血（开局 0 破绽）—— 标准身板
T1 稍弱的机制角色： 3血（但开局自带一个类似“护盾”的抵消Buff，抵消一次破绽）—— 相当于 3.5血
T2 偏后期的角色： 4血（开局自带 1个破绽）—— 相当于 3.5血，稍微输一次拔河就会立刻掉第一滴血，但总血量依然比3血多。
