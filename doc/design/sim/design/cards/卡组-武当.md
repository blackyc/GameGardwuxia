[宗师角色]：无极道人（HP：3血）[主修]：巧系（剑法） / [辅修]：灵系（身法）
【专属被动：太极剑意】
你的主卡组可最多投入15张[心法卡]。在盖牌【判定阶段】，若你盖放的心法卡战力低于对方，你将该心法卡直接置入你的[丹田区]，并使其生效；那之后，你必须打出一张武技卡代替其留在判定区，双方立即进行**[重新判定]**。（每回合限触发1次）。
【卡组核心组件分析】（展示重点单卡机制）
此流派需要大量的0费、1费心法用于“碰瓷获取内力”，并配合需要消耗高额内力的【巧】系卡在重判中一锤定音。
[公共/心法] 《餐风饮露功》	（满编3张）
属性：消耗0 / 提供1内力 / 战力0。
效果文本：常驻。此卡提供的内力额外增加X，X为你弃牌堆内卡牌数量的一半（向下取整）。
[武当/心法] 《纯阳心法诀》 （满编3张）
属性：消耗0 / 提供1内力 / 战力1。
效果文本：常驻。你的丹田区每有2张卡，此卡的内力+1。当至少拥有6点内力后，可选择主动将此卡与丹田中的另一张卡丢弃，抽2张牌。
[武当/心法]  《武当基础心法》 （满编3张）
属性：消耗1 / 提供2内力 / 战力1。
效果文本：此卡因打出以外的途径进入[丹田区]时，抽1张牌，且本回合你使用的第一张[巧]系武技卡消耗-1。
[武当/心法]《两仪桩功》 （满编3张）
属性：消耗1 / 提供1内力 / 战力2。
效果文本：此卡从任意区域移至另一区域时（不饱含从手牌中打出），随机使你手牌中1张武技卡的消耗-2。
（机制价值：回手不仅不亏，还能达成伪降费，越回手你下回合的攻势就越顺畅。）
[巧/武当/剑法]《太极剑·三环套月》 （满编3张）
属性：消耗2 / 战力5
效果文本：此卡进入判断区时，根据你[丹田区]中心法卡的数量获得等额战力×2的加成。
[巧/武当/掌法]《太极掌·绕指柔云》 （满编3张）
属性：消耗3/战力6，若本回合发生过卡牌位置移动，此卡战力+3。
[巧/武当/剑法]《武当基础剑》 （编3张）
属性：消耗2/战力6，从手牌中打出时：可额外消耗X点内力（X≤10），使此卡战力+X。
[灵/武当/身法]《梯云纵》 （满编2张）
属性：消耗1 / 战力1
效果文本：[拆招]：敌方卡牌战力上升时[响应]。从手牌中打出：抵消敌方所获得的战力增幅效果，并使自己抽一张牌。
[巧/武当/秘术] 《真武密录》 （最多带2张）
属性：消耗3/战力0
效果文本：将场上/弃牌堆中2张[武当]移出游戏，从额外卡组选择1张牌加入手牌，此卡打出后洗入主卡组。（同名卡中仅有第一张享受此效果）
【额外卡组 5张】
1x 《真武七截剑》（巧/武当/剑法，消耗6/战力13。进入出招区时，你的[丹田]每有1点未消耗的内力，此卡战力+2。这张卡获得的属性加成永久保留。）
2x 《纯阳无极剑》（巧/武当/剑法，消耗5/战力16。这张卡不受[拆招]影响。因此卡造成破绽时，恢复自身1点生命值。）
1x《九阳神功》（巧/武当/心法，消耗4/内力6/战力8。每回合一次，消耗X点内力，令一张[武当]武技牌获得x点战力。）
1x 《阳光普照》（公共/心法，消耗0/提供3内力/战力4。若此卡在额外卡组，当你只剩下1 点【生命值】时，你可以立即从其【额外卡组】中挑选任意 1 张卡牌，加入手牌。）
