# 00 — 游戏全景

> 🎮 **适合谁**：所有人。这是理解「江湖对决」的第一份文档。

## 这是什么游戏

「江湖对决」是一款 **1v1 卡牌对战游戏**。双方扮演武学宗师，各自构筑 25 张主卡组 + 5 张额外卡组，通过暗盖判定 → 出牌追分 → 迫使对手暴露破绽，最终将对手生命值削至 0。

## 一句话核心循环

```
盖牌判定 → 劣势方追分 → 逆转/放弃 → 掉血补牌 → 下一轮
```

## 三大阵营

| 阵营 | 角色 | HP | 风格 |
|---|---|---|---|
| 🔴 魔教 | 血刀 | 4（+1初始破绽） | 血换资源、中速碾压、手牌破坏 |
| 🔵 武当 | 无极道人 | 3 | 丹田引擎、资源循环、后期爆发 |
| 🟢 隐堂 | 夜修罗 | 2 | 低费连击、淬毒爆发、玻璃大炮 |

## 资源系统

| 资源 | 说明 |
|---|---|
| **生命值（HP）** | 3/4/2（角色决定），归零即败。**1血 = 2破绽** |
| **内力** | 出牌消耗。丹田中心法卡数 = 内力上限，每回合重置 |
| **破绽** | 因战力比拼落败或卡牌效果获得。**2个破绽 → 掉1血 + 抽2牌** |
| **手牌** | 上限 **8 张**，超出直接弃入弃牌堆 |

## 卡牌类型

### 武技卡（Wuji）
- 用于战斗的核心卡牌
- 进 **【出招区】**，提供战力
- 有四象属性（灵/诡/巧/霸）

### 心法卡（Xinfa）
- 进 **【丹田区】**，常驻不弃
- 提供内力上限 + 常驻战力
- 某些心法有被动效果

### 秘术卡（Mishu）
- 带 `[秘术]` 标签
- 从额外卡组检索卡牌
- 通常需要放逐（除外）场上/弃牌堆的牌作为代价

## 四象相克

```
灵（Spirit）  >  诡（Deceptive）
  ∧                  ∨
  |                  |
霸（Domineering）<  巧（Skillful）
```

**克制加成**：判定阶段，克制方战力 **+6**。

心法卡无属性，不参与克制判定。

## 八大区域

| 区域 | 说明 |
|---|---|
| 主卡组 | 25张，抽牌来源 |
| 额外卡组 | 5张绝学，需秘术检索 |
| 手牌 | 上限8张 |
| 判定区 | 单格，准备阶段暗盖 |
| 出招区 | 武技明牌打出 |
| 丹田区 | 心法常驻 |
| 弃牌堆 | 用过的牌 |
| 除外区 | 永久移出本局 |

## 卡牌构筑规则

- 主卡组：严格 25 张
- 额外卡组：严格 5 张
- 同名卡上限：3 张
- 心法卡上限：10 张（武当角色可突破至 15 张）
- 必须选 1 主修武系 + 1 辅修武系
- 辅修武系武技卡 ≤ 5 张
- 秘术标签卡 ≤ 2 张
