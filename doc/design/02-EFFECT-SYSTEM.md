# 02 — 效果系统

> ✨ **适合谁**：实现卡牌效果的开发者。本文档定义所有效果词条的语义和结算逻辑。

## 效果触发时机

| 时机 | 英文 | 说明 |
|---|---|---|
| 打出时 | ON_PLAY | 卡牌从手牌打出到目标区域时 |
| 翻牌时 | ON_REVEAL | 判定阶段翻开暗盖牌时（盖放生效） |
| 命中时 | ON_HIT | 对手因战力判低获得破绽，且此卡在出招区/判定区 |
| 回合开始 | ON_ROUND_START | 准备阶段开始时 |
| 常驻 | PASSIVE | 只要卡牌在有效区域就持续生效 |
| 进弃牌堆时 | ON_ENTER_DISCARD | 卡牌以任意方式进入弃牌堆时 |

## 关键效果词条

### 震伤（Zhengshang）
> **对手因战力比拼获得破绽时，弃其 1 张手牌。**

- 触发条件：你的出招区有带 `[震伤]` 的卡，且对手因战力低获破绽
- 效果：对手随机弃 1 张手牌
- 同名效果不叠加（多张震伤卡也只弃 1 张）
- 时机：破绽产生后**立即**触发

### 淬毒（Poison）
> **叠层标记。满 3 层 → 清零 + 直损 1 血。**

- 每层独立计数，叠在**敌方角色**身上
- 达到 3 层时立即触发：清零所有淬毒层数 + 敌方损失 1 HP
- 每回合可多次触发
- 隐堂被动「毒发」与淬毒是同一个机制

### 拆招（Chaizhao）
> **响应对手操作，打断并产生效果。**

- 从手牌中响应触发，不消耗出牌权
- 常见触发条件：
  - 对手打出心法时（如舍身撞：弃对方2张丹田心法）
  - 对手战力上升时（如梯云纵：抵消战力增幅）
- 必须严格遵守响应窗口时序

### 秘术（Mishu）
> **从额外卡组检索卡牌。**

- 代价：通常需要放逐（除外）场上/弃牌堆的指定卡牌
- 流程：选择放逐目标 → 从额外卡组选 1 张加入手牌 → 可选额外抽牌
- 放逐 = 移出本局，不进弃牌堆

### 命中（Hit）
> **携带方在出招区/判定区时，对手因战力判低获得破绽。**

- 本质上是一个触发条件，不是独立效果
- 通常与淬毒/抽牌等效果组合使用
- 如「阎王帖」：命中时抽 1 + 赋予 1 层淬毒

### 延时（Delayed）
> **牌不进丹田，暂留出招区，下回合才生效。**

- 例：聚气诀打出后留在出招区，下回合开始才进丹田
- 如果打出时有破绽 → 取消延迟，直接进丹田

## 效果结算顺序

当多个效果同时触发时（如同一个破绽事件），按以下顺序结算：

1. **即时伤害/回复**（掉血/回血）
2. **状态标记**（淬毒/破绽）
3. **连锁触发**（震伤/毒发）
4. **抽牌/弃牌**（补牌/弃手牌）
5. **区域移动**（除外/回手）

> ⚠️ 同一层级内的效果，按「出牌方先生效，对手后生效」排序。
