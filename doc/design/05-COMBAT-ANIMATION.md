# 05 — 战斗动画规格

> 🎬 **适合谁**：动画师、特效师、技术美术。本文档定义江湖对决战斗系统的全部动画、运镜、音效和 Juice 规格。
>
> **核心理念**：卡牌游戏 ≠ 小打小闹。我们要让每一轮战斗看起来像格斗游戏的超必杀演出。

---

## 设计哲学

> **"卡牌是决策的语法，动画是决策的诗。"**

### 三大支柱

| 支柱 | 来源 | 含义 |
|---|---|---|
| **一击一画（Hit Stop）** | 鬼泣 / 罪恶装备 | 每一帧关键打击都有暂停、震屏、粒子爆发 |
| **戏剧节奏（Three-Beat）** | Inscryption / 电影叙事 | 盖牌悬念 → 出招表演 → 审判高潮 |
| **角色即舞台（Character as Stage）** | GBF Versus / 街霸 | 每个角色有专属入场、待机、愤怒、受伤姿态 |

### 为什么不是"纯2D卡牌对撞"

我们不是 Hearthstone 式卡牌飞脸，也不是 Shadowverse 的进化动画。江湖对决是**基于角色的战斗演出**——卡牌是角色的招式，角色是真正的表演者。这更接近：

- **罪恶装备 Strive**：每次确认命中都有 Roman Cancel 级别的镜头暂停和粒子爆发
- **鬼泣 5**：不是动作多复杂，是 **Hit Stop + 镜头震动 + 慢动作 + 粒子** 四件套拉满
- **GBF Versus**：2D 格斗 + 超必杀特写，证明了"2D"和"帅"不矛盾

## 战斗动画总览

### 完整节奏图

```
┌─────────────────────────────────────────────────────────────────┐
│                        一场对局 = N 回合                          │
│                                                                  │
│  回合1          回合2          回合3          ...               │
│  ┌─────┐       ┌─────┐       ┌─────┐                            │
│  │四阶段│  →   │四阶段│  →   │四阶段│  →                        │
│  └─────┘       └─────┘       └─────┘                            │
│                                                                  │
│  每回合 = 5 个动画节拍（见下文）                                   │
└─────────────────────────────────────────────────────────────────┘
```

### 动画清单总表

| 编号 | 节拍 | 时长（秒） | 优先级 | 核心动画 |
|---|---|---|---|---|
| B1 | 回合开场 | 1.5 | P0 | 角色入场姿态 + 内力流转粒子 |
| B2 | 盖牌暗放 | 1.0 | P0 | 手臂抬牌 + 卡牌飞入判定区 |
| B3 | 同步翻牌 ⚡ | 2.0 | **P0** | 翻牌爆风 + 战力弹出 + 四象判定特效 |
| B4 | 弱势出招 | 每牌 1.5 | P1 | 角色出招动画 + 对手受击/防御反馈 |
| B5 | 审判一击 ⚡ | 2.5 | **P0** | 胜方特写 + 笑/蔑视 + 败方受创 + Juice 炸弹 |

> ⚡ = Juice 高密度投放点——动画预算集中砸在这里

## Beat 1：回合开场（1.5 秒）

### 视觉目标
建立"新回合开始了"的信号，展示双方状态对比。

### 分镜序列

```
00:00 ─ 00:00.3   黑屏闪白 1 帧 + 「第 X 回合」横条滑入
00:00.3 ─ 00:00.8 双方角色进入默认战斗姿态
                   - HP 血条从 0 动画涨至当前值
                   - 内力槽填充动画
00:00.8 ─ 00:01.5 角色待机呼吸循环开始
                   - 气氛粒子持续飘散
```

### 角色入场 Pose（阵营特色）

| 角色 | 入场 Pose | 待机 Idle |
|---|---|---|
| 🔴 血刀 | 从暗红血雾中踏出，右手握刀横于胸前 | 刀身微微震颤，鲜血沿刀刃滴落（循环粒子） |
| 🔵 无极道人 | 拂尘一甩，左手剑指，足踏八卦 | 衣袂飘动，呼吸间太极图在脚下明灭 |
| 🟢 夜修罗 | 从黑影中现身，双手暗器预备 | 身体微微起伏，周身暗色毒雾缭绕 |

### UI 元素动画

- 血条：从 0 匀速涨至当前 HP（0.5 秒，缓入缓出）
- 破绽标记：如已有破绽，红色裂纹动画在血条旁跳动
- 内力槽：从空涨至丹田中心法数对应的上限
- 回合数：仿毛笔书写动画 + 印章红戳

### 参考

| 作品 | 借鉴元素 |
|---|---|
| Guilty Gear Strive | 角色入场特写 + 名字黑底白字弹出 |
| 仁王 2 | 血条从 0 涨至满 + 数字跳动音效 |
| 鬼泣 5 | 角色待机时细微信号（Dante 转枪、Vergil 收刀） |

## Beat 2：盖牌暗放（1.0 秒）

### 视觉目标
"我在隐藏我的意图"——制造悬念，但不要太拖。

### 分镜序列

```
00:00 ─ 00:00.5   卡牌从手牌区飞入判定区（暗盖 = 背面朝上）
                   - 飞入轨迹：弧形抛物线，带轻微旋转
                   - 卡牌背面显示角色阵营纹章（魔教/武当/隐堂徽记）
00:00.5 ─ 00:01.0 判定区暗盖完成
                   - 卡牌暗色脉动光晕（1 秒 1 次）
                   - 角色做一个"藏招"的微表情（嘴角上扬/眯眼/屏息）
```

### 镜头

保持对峙镜头不变。如果一方已盖牌而另一方在选牌，镜头微微推向未盖牌方（制造压力）。

### 音效

- 卡牌飞行：纸张破空的"唰"声
- 落定：闷响（类似围棋落子），低音

### 参考

| 作品 | 借鉴元素 |
|---|---|
| Inscryption | 盖牌时的烛火摇曳 + Leshy 的眼睛微光 |
| Slay the Spire | 卡牌飞入弃牌堆的抛物线物理感 |

## Beat 3：同步翻牌 ⚡（2.0 秒）— Juice 炸弹 #1

### 视觉目标
这是**整回合第一个高潮**。玩家需要感受到"揭晓！"的冲击力。

### 分镜序列

```
00:00 ─ 00:00.2   判定区卡牌同时震动
                   - 震动幅度从小到大（0→5px, 0.2 秒）
                   - 卡牌边缘蓄力光效（判定阶段专属金色或阵营色）
                   - 音效：蓄力低吟 crescendo
00:00.2 ─ 00:00.5   翻牌爆风！
                   - 双方卡牌同时翻转（3D 旋转或 2D 翻牌 spritesheet）
                   - 翻牌瞬间：冲击波圆环扩散（200px 半径）
                   - 音效：重击 + 金属回响
00:00.5 ─ 00:01.0   战力数字炸出
                   - 从卡牌中心爆出大字战力图（双方战力数字，粗体描边）
                   - 数字从小（scale 0.2）急速弹出（scale 1.5）→ 回弹至 1.0
                   - 如果有克制关系：克制方数字颜色变为金色 + 闪光
                   - 克制图标（四象符号）从数字旁浮现
00:01.0 ─ 00:01.5   战力条拔河
                   - 底部或侧面出现红蓝战力条，以动画形式推拉
                   - 双方的战力条移动速度:
                     - 差距小（<3）：慢速拔河，来回摇摆 0.5 秒
                     - 差距中（3-7）：中等速度，较短摇摆
                     - 差距大（>7）：一方快速碾压
                   - 劣势方血条边缘出现红色警告闪烁
00:01.5 ─ 00:02.0   劣势方标记
                   - 劣势方角色上方出现「破绽预警」标记（红色裂纹图标）
                   - 镜头轻微推向劣势方（zoom +5%）
                   - 音效：心跳声 1 声（压迫感）
```

### 克制加成特效

当元素克制触发时（如灵 > 诡，额外 +6）：

```
1. 克制方战力数字爆出金色粒子风暴（0.3 秒）
2. 四象图标（灵/诡/巧/霸）以中国传统纹样风格浮现
   - 灵：羽翼光纹
   - 诡：暗影蛇形
   - 巧：齿轮/机关纹
   - 霸：猛虎獠牙
3. 克制的"咬合"动画：优势图标吞掉劣势图标
4. 音效：铜钟轰鸣 + 锁链断裂
```

### 太极剑意特殊动画（武当专属）

无极道人的太极剑意触发时：

```
1. 翻牌后正常显示战力
2. 突然——心法卡脱离判定区，旋转飞入丹田
   - 飞行轨迹：太极弧线（不是直线，是阴阳鱼曲线）
   - 丹田区亮起蓝光 + 太极图旋转
3. 手牌区一张武技卡自动飞入判定区代替
4. 战力重新计算，数字刷新
5. 字幕：「太极剑意·碰瓷成功」
```

### 参考

| 作品 | 借鉴元素 |
|---|---|
| 鬼泣 5 | SDT（真魔人）变身时的冲击波 + 慢动作 |
| Marvel Snap | 三路同时翻牌的战力弹出动画 |
| 街霸 6 | CA 超必杀的特写 zoom + 背景变色 |
| Persona 5 | 总攻击结算画面——全屏水墨喷溅 + 大字 |

## Beat 4：劣势出招（每牌~1.5 秒）

### 视觉目标
这是**劣势方的表演时间**。每一张牌都是一次出招——但不是对砍，是劣势方攻、优势方守。

### 攻击动画分类

不按卡牌 ID 做 39 套动画。按**攻击类型**分类，每类做 1-2 套：

| 类型 | 包含卡牌举例 | 动画描述 | 复用次数 |
|---|---|---|---|
| 🗡️ 利刃斩击 | 血刀大法、魔刀·泣血、祭血连环斩 | 横斩/竖劈，刀光弧线 + 血红色拖尾 | 12 张 |
| 👊 体术重击 | 狂骨碎岩拳、舍身撞 | 前冲重拳/肩撞，地面裂纹扩散 | 6 张 |
| 🎯 暗器投射 | 透骨钉、阎王帖、血滴子、子母追魂胆 | 手部甩出暗器 + 直线飞行命中 | 8 张 |
| ☯️ 内力爆发 | 纯阳无极剑、真武七截剑、武当基础剑 | 气劲爆发 + 太极光圈 + 蓝色粒子 | 7 张 |
| 🌀 毒雾/阵法 | 修罗化血阵、毒瘴功、万蛊噬心 | 范围毒雾扩散 + 地面符文亮起 | 4 张 |
| ✨ 心法/特殊 | 聚气诀、纯阳心法诀、天魔解体 | 角色自身发光 + 内力汇聚特效 | 8 张 |

**总动画资产**：6 类 × 2 套 = 12 套攻击动画，覆盖全部 39 张卡牌。

### 攻击时序（每张牌）

```
00:00 ─ 00:00.2   卡牌从手牌飞入出招区（高速直线）
                   - 音效：出牌确认音
00:00.2 ─ 00:00.5   角色蓄力 pose
                   - 根据攻击类型切换 pose
                   - 蓄力时角色周身粒子汇聚
00:00.5 ─ 00:00.8   击出！Hit Stop（关键帧暂停 3 帧）
                   - 攻击动画执行
                   - 刀光/拳风/暗器从角色位置发出
                   - 命中瞬间画面暂停 3 帧 + 震屏（3px）
                   - 音效：打击音 + "嘭！"
00:00.8 ─ 00:01.2   对手受击/防御反馈
                   - 对手执行防御动画：手臂护脸/侧身闪避/后仰受击
                   - 受击时角色微微后移（2-3px）
                   - 盾牌/格挡粒子在接触点爆开
00:01.2 ─ 00:01.5   收招 + 战力更新
                   - 出招方归位到待机 pose
                   - 战力条更新，数字变化
                   - 若出招带来资源变化（内力消耗/破绽变化），UI 同步更新
```

### 连招加速

如果劣势方连续打出同类型卡牌：
- 第 2 张开始省略「蓄力 pose」（节省 0.3 秒）
- 攻击动画叠加：前一击的刀光还没散，下一击已经斩出
- Hit Stop 缩短为 1 帧
- 效果：**看起来像连招 combo**，参考鬼泣的 JC（Jump Cancel）取消硬直

### 特殊效果动画

某些卡牌需要在出招基础上叠加特效：

| 效果 | 视觉表现 |
|---|---|
| 震伤触发 | 对手手牌区划过黑色爪痕，一张牌破碎消失 |
| 淬毒叠层 | 对手身上绿色毒素标记 +1，数字跳动，毒雾蔓延 |
| 毒发爆血 | 淬毒 3 层 → 全屏绿色闪屏 2 帧 → 对手爆出绿色血雾 → HP 大掉 |
| 拆招触发 | 时间凝固 0.3 秒 → 灰度滤镜 → 拆招方特写 → 效果执行 → 恢复色彩 |
| 血战到底 | 血刀自伤：刀刃反向划过自身 → 血红色破绽标记浮现 → 嘴角流血 |
| 秘术检索 | 除外区的牌燃烧消失（黑色火焰）→ 额外卡组发光 → 选中的牌飞入手牌 |

### 镜头

出招阶段镜头以劣势方为主视角（约占画面 60%），优势方在画面另一侧防御。
双方位置：横版 layout（左 vs 右），类似格斗游戏。

### 参考

| 作品 | 借鉴元素 |
|---|---|
| 鬼泣 5 | Hit Stop 3 帧 + 慢动作 + 震屏 |
| 罪恶装备 Strive | Counter Hit 时画面暂停 + 大字 + 镜头 zoom |
| Slay the Spire | 卡牌使用后的弃牌堆飞行轨迹 |
| 只狼 | 弹刀瞬间的金属火花 + 短暂停 |

## Beat 5：审判一击 ⚡（2.5 秒）— Juice 炸弹 #2

### 视觉目标
这是**整回合的最高潮**。劣势方宣告放弃 → 终审判定 → (大概率)受伤。这里投的每一帧特效都会让玩家记住你的游戏。

### 分镜序列

```
——— 劣势方宣告 Pass ———

00:00 ─ 00:00.3   劣势方"放弃"pose
                   - 角色退后一步，低头/垂手
                   - 武器下垂，气息散逸

00:00.3 ─ 00:00.8   镜头切到优势方
                   - 慢动作 push in（zoom 到面部特写）
                   - 嘴角上扬、蔑视一笑（关键帧！）
                   - 参考 Vergil 的"Foolishness"或 Dante 的"Jackpot"

00:00.8 ─ 00:01.2   优势方蓄力反击
                   - 角色进入反击 pose
                   - 周身能量/粒子向拳头或武器汇聚
                   - 音效：嗡鸣 crescendo

00:01.2 ─ 00:01.5   审判一击！
                   - Hit Stop 5 帧！（比正常出招更长）
                   - 全屏 flash：阵营色闪屏（魔教暗红/武当靛蓝/隐堂墨绿）
                   - 震屏 5px + 镜头 shake
                   - 劣势方角色后仰飞出（如果有 ragdoll 物理更好）

00:01.5 ─ 00:02.0   劣势方受创落地
                   - 角色单膝跪地/踉跄
                   - 「破绽+1」大字从角色身上弹出（红色，仿印章）
                   - HP 血条震动 → 如有掉血则数字滚动减少

00:02.0 ─ 00:02.5   镜头归位 + 结算信息
                   - 镜头回到对峙视角
                   - 补牌动画：卡牌从主卡组飞入双方手牌
                   - 结算阶段卡片清场动画（判定区+出招区→弃牌堆）

```

### 特殊情况：劣势方逆转！

如果劣势方通过出牌成功反超战力，这是**整局游戏最爽的瞬间**，需要特殊的逆转动画：

```
1. 战力条推过中线 → 屏幕边缘阵营色渐变（劣势方颜色蔓延推回对手颜色）
2. 逆转方角色执行"反击 pose"（原本颓势 → 突然爆发）
3. 字幕特效大字：「逆转！」（书法字体，金色描边）
4. 音效：铜钹一击 + 战吼
5. 原优势方变劣势方后执行"震惊"表情（瞳孔缩小、后退半步）
6. 然后回到 Beat 4——新劣势方现在要出牌了
```

### 优势方大笑/蔑视的表情规格

这是游戏特色——不同角色有不同的"审判表情"：

| 角色 | 审判表情 | 台词/字幕 |
|---|---|---|
| 🔴 血刀 | 舔刀口，眼神疯狂 | 「哈哈哈哈！再来！」 |
| 🔵 无极道人 | 拂尘轻摆，闭眼微笑 | 「承让。」 |
| 🟢 夜修罗 | 面具下的眼突然亮起绿光 | （无声冷笑） |

### 劣势方受伤 Pose

| 角色 | 受击 Pose |
|---|---|
| 🔴 血刀 | 单膝跪地，刀插地面支撑，嘴角渗血 |
| 🔵 无极道人 | 后退两步，拂尘下垂，衣袍被气劲吹起 |
| 🟢 夜修罗 | 身体被击飞旋身落地，单手撑地，面具出现裂纹 |

### 参考

| 作品 | 借鉴元素 |
|---|---|
| 鬼泣 5 | Vergil 的"Judgement Cut End"——全屏切裂 + 敌人静止后崩解 |
| 街霸 6 | CA 最后一击的慢动作 zoom + 全屏闪 |
| 罪恶装备 Strive | 决胜局结束时的那一下特写（如 Ky 的 Ride the Lightning 终结镜头） |
| 怪物猎人 | 怪物部位破坏时的镜头停顿 + 粒子爆散 |
| Inscryption | Leshy 拿走你的牌时那个缓慢的动作 + 烛火熄灭 |

## 全局 Juice 系统

### Hit Stop 规格表

| 场景 | 暂停帧数 | 震屏幅度 | 闪屏 |
|---|---|---|---|
| 普通出牌命中 | 3 帧 | 3 px | 无 |
| 克制加成触发 | 3 帧 | 4 px | 金色 |
| 审判一击 | **5 帧** | 5 px | 阵营色 |
| 毒发爆血 | 4 帧 | 6 px | 绿色 |
| 拆招成功 | 4 帧 | 2 px | 灰度→恢复 |
| 角色死亡 | **8 帧** | 8 px | 红色→黑白 |

### 震屏（Screen Shake）

- 使用 Perlin Noise 驱动的多方向震动，不要单纯上下/左右
- 振幅衰减：100% → 0% 在 0.3 秒内
- 审判一击时叠加镜头旋转（±2°）

## 镜头系统

### 默认构图

横版 16:9，双方角色各占画面左右 1/3，中间为判定区/战力显示。

```
┌──────────────────────────────────────────────┐
│                                              │
│  [HP/内力]                           [HP/内力] │
│  血刀  ○==========●  无极道人              │
│        判定区  出招区                        │
│                                              │
│  [手牌]                            [手牌]    │
└──────────────────────────────────────────────┘
```

### 镜头切换规则

| 阶段 | 镜头模式 | 备注 |
|---|---|---|
| 回合开场 | 对峙（双方均在画面内） | — |
| 盖牌暗放 | 对峙 + 微推未盖牌方 | Zoom +3% |
| 翻牌 | 对峙 + 中心微缩 | Zoom -5%，留空间给战力数字爆出 |
| 劣势出招 | **劣势方特写**（占 60%）| 偏左或偏右 depending on 哪方劣势 |
| 审判一击 | 优势方面部特写 → 全屏 | Push in 到特写再拉回 |
| 逆转 | Split zoom：双方各占一半做反应 | 参考斯巴达三百勇士的 split panel |

### 禁止事项

- ❌ 不要频繁切镜头（同一阶段最多切 2 次）
- ❌ 不要让角色出画（出招时如果超出画面加边界限制）
- ❌ 不要使用单纯的匀速 zoom（所有镜头移动带缓动曲线）

## 实现路线图

### Phase 1：骨架（1-2 周）

- [ ] 横版战斗 layout + 双方角色站位
- [ ] 卡牌飞入/翻牌基础动画（无特效）
- [ ] 战力计算 → 数字显示
- [ ] Beat 2（盖牌）→ Beat 3（翻牌）→ Beat 5（审判）基础流程
- [ ] 验收标准：可以完成一次"盖牌→翻牌→判劣势→Pass→结算"循环

### Phase 2：血肉（2-3 周）

- [ ] 6 类攻击动画（每类先做 1 套）
- [ ] 防御/受击动画
- [ ] Hit Stop + 震屏系统
- [ ] 粒子系统（共用池 6 种）
- [ ] 镜头切换系统
- [ ] 验收标准：一场完整对战（含出牌阶段）可以看完所有动画

### Phase 3：灵魂（2-3 周）

- [ ] 审判表情特写（3 角色）
- [ ] 克制特效（四象图标 + 金色爆炸）
- [ ] 逆转特效
- [ ] 特殊效果动画（震伤/淬毒/毒发/拆招/秘术）
- [ ] 音效集成
- [ ] 验收标准：对局看起来"很帅"，非玩家也能被吸引驻足

### Phase 4：雕刻（持续）

- [ ] 每个角色第 2 套攻击动画变体
- [ ] 角色死亡动画
- [ ] 漫画速度线/Manga Lines
- [ ] BGM 动态切换（普通→紧张→决胜）
- [ ] 验收标准：录屏发推特能获得"这是什么游戏？"的回复
