# 【魔教】卡组详解

## 流派定位

资源转化（以血代蓝）/ 战力碾压（Midrange）/ 手牌破坏。

## 宗师角色

**血刀**（HP：4+1初始破绽）（主霸 / 副诡）

### 被动：血战到底

在【出牌阶段】，你可以主动获得1个[破绽标记]，选择一项：
- ①本回合[震伤]触发后的弃牌数+1
- ②本回合下一张[魔教]牌的消耗-2

（每回合限1次）

### 震伤词条说明

对方在[战力比拼]中因战力低于你而获得[破绽]时，若你的出招区中存在有带[震伤]词条的卡牌，可以丢弃对方一张手牌，这个效果不会因为带[震伤]词条的卡牌数量增加而增加。

## 核心策略

1. **血战时机**：最优在准备阶段后、判定区为空时触发——此时破绽收益最大且不会污染判定
2. **修罗饮血功 + 血战**：主动获破绽触发修罗饮血功内力+1 → 多出的内力用于霸系大费牌
3. **舍身撞**：对手建丹田时响应，拆核心心法（如纯阳心法诀）
4. **魔刀·泣血**：后期对手弃牌堆积累大量费用后打出，战力爆炸
