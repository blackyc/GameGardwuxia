## Part 2: 敌人 ENEMIES（60个）

### 分类与数量
| 分类 | 数量 | 出现区域 | danger 范围 |
|------|------|---------|------------|
| 妖 | 12 | 山林/荒野/古宅 | 1-4 |
| 鬼 | 14 | 墓地/义庄/鬼域/子夜城中 | 2-5 |
| 邪修 | 10 | 全图偶遇 | 2-4 |
| 怪 | 10 | 荒野深处/禁区 | 3-5 |
| 精魅 | 8 | 城中暗处/寺庙道观 | 1-3 |
| 人祸 | 6 | 城外/官道/山径 | 1-2 |

### 命名规范
纯聊斋风，参考聊斋志异 + 倩女幽魂。示例（可用但鼓励原创）：
- **妖**：狐面书生、蛇婆、蜘蛛娘子、槐中妖、虎伥、白鲤妖、狼妖、獐子怪、蝠童、藤妖、石中蟾、枯木精
- **鬼**：吊死鬼、水鬼、饿鬼、纸人新娘、无头将军、画皮、产鬼、殇童、缢鬼、溺鬼、回煞、拘魂使、落水鬼、夜哭郎
- **邪修**：走火入魔的散修、尸解仙(失败品)、血祭邪修、夺舍残魂、采补道人、炼尸匠、蛊师、咒杀客、饲鬼者、剥皮修士
- **怪**：山魈、魍魉、泥俑、石人、镜中影、瓮中女、枯骨僧、人面蛛、会走的树、岩腹子
- **精魅**：琵琶精、画中仙、灯中女、镜妖、墨精、砚妖、棋鬼、笔仙
- **人祸**：山匪头目、水匪、拐子、采生折割者、黑店掌柜、盗墓贼

### 每个敌人的格式
```javascript
'狐面书生': {
  hp: 55, atk: 10, def: 6, exp: 25, gold: 18,
  type: '妖',
  realmHint: '炼气以上可见其真容',  // 可选字段：什么境界才能看破伪装
  desc: '青衫折扇，面目清秀的书生。他说话时从不眨眼——不是不眨，是没有眼皮。他笑的时候，嘴角的弧度先于笑容出现。你低头看见他影子——影子的头，是朝后的。'
}
```

**desc 铁律（1+1+1）**：
1. 视觉：第一眼看到什么（正常部分）
2. 反常点：哪里不对（一个不解释的异常细节）
3. 行为暗示：它做了什么或将要做什么

**数值梯度（60个）**：
| 危险级 | hp | atk | def | exp | gold | 数量 |
|--------|-----|-----|-----|-----|------|------|
| 1(弱) | 20-40 | 6-10 | 3-5 | 10-18 | 5-10 | 14 |
| 2(中弱) | 35-55 | 8-14 | 5-7 | 18-25 | 10-20 | 16 |
| 3(中) | 50-80 | 12-18 | 7-10 | 25-38 | 18-35 | 15 |
| 4(中强) | 70-130 | 18-26 | 10-14 | 38-55 | 30-55 | 10 |
| 5(Boss) | 120-220 | 24-40 | 14-20 | 55-120 | 50-100 | 5 |

> Boss 级敌人（danger=5）各附一句掉落提示，如 `lootHint: '可能掉落：妖丹/XXX'`。

## Part 3: 物品 ITEMS（120个）

### 分类与数量
| 分类 | 数量 | 说明 |
|------|------|------|
| 丹药 | 22 | 修炼/治疗/临时buff |
| 符箓 | 18 | 战斗/防御/探索/封印 |
| 法宝 | 18 | 武器/防具/辅助 |
| 阴物 | 18 | 诡异来源的物品，佩戴有代价 |
| 杂物 | 26 | 任务道具/消耗品/钥匙 |
| 特殊 | 18 | 罕见材料/Boss掉落/任务奖励 |

### 命名规范
**名称必须正常**——禁止在物品名中加入"鬼/妖/魔/邪/血/死/尸"等字。诡异留在 desc 里。

丹药类：培元丹、筑基丹、凝神丹、护脉丹、续命丹、洗髓丹、聚气散、辟谷丸……
符箓类：镇尸符、驱邪符、引魂符、辟火符、隐身符、金刚符、疾风符……
法宝类：桃木剑、铜钱剑、八卦镜、墨斗、镇魂铃、招魂幡、缚妖索、降魔杵……
阴物类：人骨念珠、旧嫁衣、古铜簪、无字牌位、裹尸布残片……
杂物类：金疮药、干粮、火折子、绳索、香烛、纸钱、罗盘、朱砂、雄黄……
特殊类：千年灵芝、万年何首乌、妖丹、魂玉、舍利子、龙脉石……

### 每个物品格式
```javascript
'筑基丹': {
  type: '丹药',
  desc: '龙眼大的丹丸，表面泛着淡淡的金光。但若在月光下细看——丹丸内部有一丝游动的暗红，像一条极细的虫，在金光里缓缓翻身。',
  effect: '修炼速度+30%，持续1时辰',
  price: 500,
  danger: 1       // 使用风险：1=无风险, 2=轻微副作用, 3=明显代价
}
```

**desc 铁律（1+1）**：
1. 外观（正常描述，写实）
2. 异常属性/代价（一个让修士不安的细节，不解释）

### 阴物特殊规则
阴物类物品必须标注 `curse` 字段（使用该物品的隐秘代价）：
```javascript
'人骨念珠': {
  type: '阴物',
  desc: '一百零八颗骨珠，串在一根乌黑的牛筋上。每一颗珠子上都刻着极小的经文——但字是反的。',
  effect: '道心-1/时辰(佩戴中)，但抵御鬼类攻击+15%',
  curse: '佩戴超过三日后，开始听见不属于你那间屋子的呼吸声',
  price: 1200,
  danger: 3
}
```
