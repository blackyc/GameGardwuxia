## 一、世界观架构

### 1.1 三层世界

```
┌─ 平静层 ─────────────────────────────────────┐
│  凡人日常：应天府/顺天府/开封府              │
│  酒馆、药铺、铁匠铺、码头、街市              │
│  百姓不知道灵修存在                          │
│  武修低境界(0-2)只能隐约觉察不对劲            │
├─ 侵蚀层 ─────────────────────────────────────┤
│  武修宗师(3-4)开始看穿表象                    │
│  察觉"有些东西不是江湖功夫能解释的"           │
│  遗物、人祸往事开始浮现                      │
│  灵修从另一面看同一世界                      │
├─ 不可名状层 ─────────────────────────────────┤
│  灵修1-5层：灵视看见、畸变加深               │
│  天道不是空的——里面有东西                    │
│  每个灵修宗门对应一位克苏鲁外神              │
│  修炼=渐进异化，飞升=被祂同化                │
└──────────────────────────────────────────────┘
```

### 1.2 世界观约束（铁律）

| 规则 | 说明 |
|------|------|
| **凡人不知灵修** | 应天府/顺天府/开封府等凡人城市中**不得出现**修真概念（灵修、灵气、灵石、法器、符修等） |
| **店名纯古风** | 酒馆/药铺/铁匠铺/当铺/绸缎庄/茶馆/码头/街市/客栈，不得含灵/诡/冥/怨/煞 |
| **武修禁修真词** | 武修文本禁止出现：灵气、灵脉、界隙、神识、灵视、道基 |
| **灵修禁武侠语** | 内力→灵力，真气→灵气，招式→术法 |
| **三层描述递进** | desc_vague（主观不确定）→ desc_percept（物理确定）→ desc_awakened（修真术语） |
| **恐怖在文本** | 恐怖不在名字里，在叙事文本中。金庸式基底+克苏鲁式侵入 |
| **禁止现代/赛博词** | 广播、AI、芯片、基因、电子、网络、信号、频道、程序、数据、监察等全部清除 |

## 二、七个层次的叙事Build目标

叙事驱动玩家Build的七层递进设计，从最低级的"信息残缺"到最高级的"自我定义"。

| 层 | 名称 | 核心机制 | 玩家心理 | 驱动效果 |
|----|------|---------|---------|---------|
| **L1** | 信息残缺 | NPC说半句吞半句 | "他话没说完——下半句是什么？" | 驱动探索 |
| **L2** | 身份排斥 | 内门外门、门派辈分区别 | "凭什么我不能进去？" | 驱动提升地位 |
| **L3** | 疑虑 | NPC说"这不对""这不该" | "到底是什么不对？" | 驱动怀疑世界 |
| **L4** | 跨代共鸣 | NPC说"你让我想起一个人" | "那个人是谁？我跟他什么关系？" | 驱动追溯血脉/轮回 |
| **L5** | 恐惧质问 | NPC说"你知道自己在变成什么吗？" | "我在变成什么？" | 驱动面对选择 |
| **L6** | 镜像倒影 | NPC说"你已经不是你了" | "我不是谁？" | 驱动身份危机 |
| **L7** | 自我定义 | 玩家用行动回答"我是谁" | "这就是我。这是我的路。" | Build完成——结局分叉 |

### 2.1 叙事层与境界对应

| 路径 | 境界范围 | 可达到的叙事层 | 描述方式 |
|------|---------|--------------|---------|
| 武修 | 凡人~武师(0-2) | L1-L2 | desc_vague：主观不确定 |
| 武修 | 宗师~天人(3-4) | L3-L5 | desc_percept：物理确定，不用修真术语 |
| 灵修 | 炼气~化神(1-5) | L3-L7 | desc_awakened：修真术语，完整看见 |

### 2.2 NPC叙事层定位

每个NPC标注可达成的最高叙事层。武修低境界接触L3+ NPC时，NPC的对话会被裁剪到L1-L2版本：

| 叙事层 | NPC数量 | 典型NPC |
|--------|--------|---------|
| L1-L3 | 6 | 守门人、驿厨、木匠——日常角色，初启怀疑 |
| L1-L4 | 12 | 长老、执事——知道一些但只说一些 |
| L2-L5 | 12 | 掌门、教头——深谙秘密但不全说 |
| L3-L6 | 4 | 宗主、深度畸变者——接近真相的人 |
| L4-L7 | 2 | 净尘、渊主——已经越界的人 |

### 3.3 武修→灵修转职（Hidden Path）

每个武修宗门都有一段被封印的"灵修往事"。人祸之后，宗门以武修重新建立，灵修根源被封存。但遗物还在——等待宗师境界的弟子发现。

**转职条件**：
1. 宗门弟子+realm≥3（宗师）
2. 在HQ深处感知遗物异常
3. 触发人祸回忆 → 发现真相
4. 选择：封印遗物（留武修）vs 继承遗物（转灵修，道心-20）

**转后**：宗门标签→`[原宗门名]·灵脉`，继承宗门灵修前身的部分技能。

## 四、主线故事框架：天道有创

### 4.1 核心命题

> "修道修到最后，你还是你吗？"

天道的真相：**天道不是空的。天道里面有东西。** 修炼不是获得力量——是向那个"东西"靠近。到了"那一步"（悟道），会发现：要么被它选中，要么被它擦掉。

### 4.2 四幕结构

| 幕 | 阶段 | 叙事目标 | 玩家认知 |
|----|------|---------|---------|
| **第一幕** | 初入江湖 | 建立身份，熟悉门派，体验正常武侠 | L1-L2：信息残缺 + 身份排斥 |
| **第二幕** | 裂痕初现 | 遗物异动，人祸往事碎片浮现 | L3-L4：疑虑 + 跨代共鸣 |
| **第三幕** | 不可名状 | 灵修路径开放，畸变加速，直面外神 | L5-L6：恐惧质问 + 身份危机 |
| **第四幕** | 各自的答案 | 修行终点，六条平行结局分叉 | L7：自我定义 |

### 4.3 六条平行结局

| 结局 | 命名 | 路径 | 条件 | 描述 |
|------|------|------|------|------|
| E1 | **封刀归隐** | 武修 | 道心≥80，不做任何灵修转职 | "够了。"回到凡人世界。不是逃避——是选择。知道那些不该知道的事，选择把这个秘密埋了。 |
| E2 | **飞升·不** | 灵修 | 道心归零，拒绝最后一课 | 听闻召唤但拒绝入化神。用最后的道心说"不"。灵脉碎了，变回凡人的肉身。但你记得。这是最沉重的完美结局。 |
| E3 | **承志** | 武修 | 道心≥60，转职但回武修 | 见过灵修的世界，选择回来。用武侠的方式守住边界——不让那边的东西过来。被弟子尊为"铁门"。 |
| E4 | **归一** | 灵修 | 化神·道心>0 | 成为同类——但不被祂奴役。你不是祂的子嗣，也不是祂的工具。你是祂的对等存在。一个新的、不完全的、但自主的"它"。 |
| E5 | **封天** | 任意 | 发现天道真相，选择对抗 | 不止一次说"不"。组织所有还清醒的人，在天道之外布下封印。代价：永远驻守在封印边缘，和想进来的东西对视。 |
| E6 | **各自归零** | 灵修 | 道心归零（宗门特定结局） | 六宗各一条参悟结局（见3.5节）。不是赢——是到达了不该到达的地方。 |

## 五、罗生门式叙事框架

### 5.1 双版本叙事原则

同一个世界、同一个NPC、同一个事件——但在武修和灵修的眼中**完全不同**。

**五条铁律**：
1. 武修文本永不出现修真概念词
2. 武修用自然语言描述异常（"太规则""冷得不正常""说不清的存在感"）
3. 灵修描述直接用修真术语
4. 同一NPC在武修面前假装凡人，灵修面前不装
5. 任务真相仅灵修能完整理解；武修道心<30概率看到不该看的东西

### 5.2 任务模板

```js
// 罗生门任务：城外破庙里的哭声
QUEST_CROSS_PATH = {
  id: 'cross_001',
  name: '城外庙里的哭声',
  stages: [{
    // 武修视角：自然主义怀疑
    desc_wu: "庙里空无一人。神像背后的墙上有些痕迹——不太像人抓的。也许是野兽蹭的。",
    // 武修宗师视角：物理确定但不用修真术语
    desc_wu_percept: "墙上的痕迹是指甲——沟槽太深，人做不到。神像在看你。死木不该有目光。",
    // 灵修视角：完整灵视
    desc_ling: "神像背后坐着一个没有脸的女人。她在哭——哭声从墙上抓痕里渗出的灵气在震荡。",

    // NPC对话自动分轨
    npc_dialogues: {
      wu: [{ npc:'老货郎', text:'那庙荒了很久。大概是山里风声作怪。你们练武之人去看看，赶走就是了。' }],
      ling:[{ npc:'老货郎', text:'你也是去看她的？她等了很久了。不要跟她说话——她等的人不是你。' }]
    }
  }]
};
```

## 八、Build与双循环驱动

### 8.1 当前立场

游戏已有自然的叙事闭环：
- **战斗→搜刮→修炼→变强→打更强的敌人**（战力循环）
- **探索→发现不对劲→追溯真相→身份危机→选择**（叙事循环）

两个循环是同一根绳子：**变强让你看到更多不该看到的东西，看到更多迫使你选择，选择定义你是谁。**

### 8.2 七层Build在游戏机制中的锚点

| 叙事层 | 机制触发 | UI反馈 |
|--------|---------|--------|
| L1 信息残缺 | NPC截断对话 | 对话框显示"……" |
