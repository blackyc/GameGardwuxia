# 诡仙录 · 身份系统设计

> "你出生那一刻，命运就已经掷了骰子。但骰子落在什么桌上——由你决定。"

---

## 一、设计哲学

### 1.1 身份 ≠ 战斗子系统

身份系统是**角色创建时的全局选择**，影响战斗、修炼、经济、社交、探索五大维度，而非战斗系统的子模块。

### 1.2 核心原则

- **roll点制**：创建角色时系统roll出3个身份，玩家从中选1个，不可重roll
- **终身制**：身份一旦选定不可更改
- **多维影响**：每种身份至少影响3个以上游戏维度
- **无废身份**：每种身份都有独特优势，不存在严格被支配的选项
- **风味优先**：身份名称和描述贴合聊斋+克苏鲁+武侠基底

### 1.3 与金庸群侠传X的参考关系

金庸群侠传X的出身系统提供了"选择题→多属性增减"的范式（商人之子得道具、名门世家加悟性、疯子加悟性减根骨等）。诡仙录在此基础上：
- 将单一选择题改为**roll点三选一**（增加随机性和重玩价值）
- 将属性增减扩展为**五维影响矩阵**（战斗/修炼/经济/社交/探索）
- 加入**身份×宗门交互规则**（某些身份在特定宗门有额外加成或惩罚）

## 二、身份总览（14种）

### 稀有度分级

| 稀有度 | 权重 | 身份数量 | 说明 |
|--------|------|---------|------|
| 常见 | 15 | 4种 | 普通出身，效果温和 |
| 普通 | 10 | 5种 | 有明显倾向的出身 |
| 稀有 | 5 | 3种 | 强力但偏门的出身 |
| 极稀有 | 2 | 2种 | 改变游戏体验的出身 |

> 权重总和 = 15×4 + 10×5 + 5×3 + 2×2 = 60 + 50 + 15 + 4 = **129**
> roll出3个身份时，每个身份被roll中的概率 = 权重 / 129

## 三、身份详解

### 3.1 【武学世家】（常见 · 权重15）

> "你家祖上出过一位剑客。没人记得他的名字，但阁楼里还挂着他那把锈剑。"

| 维度 | 效果 |
|------|------|
| **战斗** | 自带2个基础武学（拳掌·入门 + 兵刃·入门），武器熟练度获取速度+20% |
| **修炼** | 武修类功法领悟速度+10% |
| **经济** | 初始自带30铜钱 |
| **社交** | 问剑峰NPC初始好感+15；忘尘宗NPC初始好感-5（世家子弟被视为"执念深重"） |
| **探索** | 可辨识武器品质（普通/精良/稀有无需鉴定） |

## 五、身份选择机制

### 5.1 Roll点流程

```
角色创建
  ├─ 1. 输入角色名
  ├─ 2. 选择性别
  ├─ 3. 系统roll出3个身份（按权重随机，不重复）
  ├─ 4. 展示3个身份的名称 + 描述 + 五维影响摘要
  ├─ 5. 玩家选择其中1个（或放弃重创角色）
  └─ 6. 身份锁定，进入游戏
```

### 5.2 Roll点规则

- 3个身份之间**不重复**
- 极稀有身份在roll点时额外提示：「✦ 稀有身份出现！」
- 若3个身份中同时出现2个以上稀有身份，触发隐藏对话：「命运似乎在对你微笑——还是冷笑？」
- **不可重roll**——选择即终身

## 七、与战斗系统v3的对接说明

### 7.1 从战斗文档中移除的内容

原 `combat_system_v3_design.md` 3.6节"出身系统"中的10种出身（学徒/猎户/屠户/采药人/教头/酒者/送葬者/品菜人/搬桶者/焚香者）已被本文档的14种身份替代。

### 7.2 战斗系统如何读取身份

战斗系统在计算最终属性时，身份作为**全局被动修饰符**参与计算：

```
最终属性 = 基础属性 + 装备加成 + 铭文 + 功法 + 身份修饰
```

身份修饰仅影响战斗维度的部分（如暴击、闪避、伤害加成、护甲等），不涉及修炼/经济/社交/探索维度。

## 八、设计备忘

### 8.1 Dominance Check

所有14种身份已通过两两支配检测：
- 无任何身份在所有维度上严格被另一身份支配
- 每种身份至少在1个维度上有独占优势（其他身份无法替代的机制）
- 极稀有身份（庄周梦蝶、我乃天选）的总星级较高，但有显著负面效果平衡

### 8.2 后续扩展

- 可通过版本更新添加新身份（如「妖血」「半鬼」「梦行人」等），需重新校准权重
- 身份相关隐藏剧情线需在各宗门任务文档中单独设计
- 身份与奇遇系统的交互（如我乃天选的奇遇加成）需在奇遇系统文档中定义

### 8.3 数值平衡说明

- 常见身份总星级：5-7星（温和但有方向性）
- 普通身份总星级：6-8星（有明确倾向）
- 稀有身份总星级：8-10星（强力但有代价）
- 极稀有身份总星级：9-11星（改变体验但有风险）

星级不等于实际强度，实际强度取决于玩家如何利用身份优势配合build方向。
