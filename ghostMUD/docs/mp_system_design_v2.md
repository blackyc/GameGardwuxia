## 一、MP 系统设计

### 1.1 数值来源（v2.0 更新）

从 `combat_numerics_v3.md` 第二节提取新真气上限曲线：

| 境界 | 武修 maxMp | 灵修 maxMp | 说明 |
|------|-----------|-----------|------|
| 凡人(初始) | 50 | 60 | 基础，凡人回气极慢 |
| 武者/炼气 | 120 | 140 | 武者开始有像样的回气 |
| 武士/筑基 | 250 | 300 | 武士可维持中频施法 |
| 武师/金丹 | 400 | 480 | 武师回气够支撑轻击循环 |
| 宗师/元婴 | 800 | 960 | 宗师真气充沛，可支撑重击 |
| 天人/化神 | 2000 | 2400 | 天人真气如江河，几乎不竭 |

> v1.0旧值：凡人80/武者120/武师200/宗师240/天人280 — 凡人~天人仅3.5×差距，过于扁平。
> v2.0新值：凡人50/天人2000(武修) — 40×差距，与HP量级增长同步。

### 1.2 MP恢复速率（v2.0 更新）

| 境界 | 武修 mpReg | 灵修 mpReg | 恢复机制 |
|------|-----------|-----------|---------|
| 凡人(0) | 2/tick | 3/tick | 凡人回气极慢，打一波就空 |
| 武者(1) | 5/tick | 7/tick | 武者开始有像样的回气 |
| 武士(2) | 10/tick | 14/tick | 武士可维持中频施法 |
| 武师(3) | 18/tick | 25/tick | 武师回气够支撑轻击循环 |
| 宗师(4) | 35/tick | 50/tick | 宗师真气充沛，可支撑重击 |
| 天人(5) | 80/tick | 110/tick | 天人真气如江河，几乎不竭 |

> tick = 0.5s（战斗内）；战斗外每30s +5MP（保持v1.0不变）

### 1.3 战斗消费（保持v1.0结构，数值按新量级）

| 武学品阶 | 气耗范围(凡人) | 气耗范围(武师) | 气耗范围(天人) |
|---------|--------------|--------------|--------------|
| 凡品(轻击) | 3-6 | 25-45 | 100-180 |
| 良品(中击) | 10-18 | 70-110 | 280-450 |
| 珍品(重击) | 20-30 | 140-200 | 550-800 |
| 地品(绝学) | — | 280-400 | 550-800 |

> 气耗随境界同步放大，保持"一圈总气耗 ≈ maxMp的40-80%"的比例关系。

### 1.4 门禁经济学（保持v1.0不变）

| 选项 | 气耗 | 效果 | 适用场景 |
|------|------|------|---------|
| 调息 | 0(跳过) | +30真气 | 该式较弱时 |
| 服药 | 0(跳过) | +40真气(消耗道具) | 关键战斗 |
| 平斩 | 10 | 低伤害普攻 | 避免中断节奏 |
| 强行 | 全部 | 按比例打折出招 | 必须出招效果 |

> 注意：门禁固定值（+30/+40/10）不随境界放大，因为高境界真气池更大，固定值占比自然下降，这是设计意图——高境界门禁压力更小，玩家更自由。

### 1.5 非战斗恢复（保持v1.0不变）

休憩时 MP 每 tick(30s) 恢复 +5。
武修休憩 MP恢复：+5/tick
灵修休憩 MP恢复：+4/tick

### 1.6 MP消耗与恢复平衡验证

以武师(3)武修为例（maxMp=400, mpReg=18/tick, tick=0.5s）：

| 技能组合 | 一轮MP消耗 | 恢复时间(打空→回满) | 说明 |
|---------|----------|-------------------|------|
| 5轻击 | 5×35=175 | (400-175)/18×0.5≈6.3s | 轻击流几乎不会空蓝 |
| 3轻+1中+1重 | 3×35+90+170=365 | (400-365)/18×0.5≈1s | 几乎打空但恢复极快 |
| 2中+1重+2辅 | 2×90+170+2×55=440 | 超出40，需等MP | 需要在循环中插入调息 |

### 1.7 术语双轨（保持v1.0不变）

- 武修：内力（MP标签显示"内力"）
- 灵修：灵力（MP标签显示"灵力"）
- 代码中使用 `getTerm('power')` 动态获取

## 二、行动框架数值定稿（保持v1.0不变）

### 2.1 三种行动

| 行动 | 修为/tick | HP恢复/tick | MP恢复/tick | 道心变化/tick | 移动 | 时间 |
|------|----------|------------|------------|-------------|------|------|
| 修炼(cultivate) | +3(武修)/+4(灵修) | 0 | -2(消耗) | -1(武修)/按境界衰减(灵修) | ❌ 阻断 | toggle |
| 休憩(rest) | +1 | +3(武修)/+2(灵修) | +5(武修)/+4(灵修) | +1 | ❌ 阻断 | toggle |
| 练功(train) | +2/次 | 0 | 0 | 每10次-1/3 | ✅ 不阻断 | 主动点击 |

### 2.2 互斥规则

- 修炼/休憩不可共存（toggle互斥）
- 修炼/休憩阻断移动
- 练功不阻断移动，可随时点击

### 2.3 数值对比（5分钟产出）

| 行动 | 修为 | HP | MP | 道心 |
|------|------|-----|-----|------|
| 修炼5min | +180(武修)/+240(灵修) | 0 | -120 | -6(武修) |
| 休憩5min | +60 | +180(武修)/+120(灵修) | +300(武修)/+240(灵修) | +6 |
| 练功5min(约30次) | +60 | 0 | 0 | -1(每10次-1/3≈-1) |

> 修炼修为最优但有道心代价和MP消耗；休憩全面恢复但修为低；练功灵活无消耗但道心缓降。无dominance。

## 三、工程实现清单

### 3.1 state 字段（已实装，数值需更新）

```javascript
state: {
  mp: 50,           // 初始MP（v1.0=80, v2.0=50）
  maxMp: 50,        // 初始maxMp（v1.0=80, v2.0=50）
  // mpReg 不入state，由境界+心法+饰品动态计算
}
```

### 3.2 突破成长

```javascript

const MP_GROWTH = {
  wu: [0, 70, 130, 150, 400, 1200],   // 凡人→武者→武士→武师→宗师→天人
  ling: [0, 80, 160, 180, 480, 1440], // 灵修路径
};
// 突破时 mp += MP_GROWTH[path][newRealm]; maxMp += MP_GROWTH[path][newRealm];
```

### 3.3 定时器

```javascript
// 战斗内MP恢复 tick（0.5s）
setInterval(() => {
  if (state.inCombat) {
    const reg = getMpReg(); // 动态计算：基础mpReg + 心法加成 + 饰品加成
    state.mp = Math.min(state.maxMp, state.mp + reg);
  }
}, 500);

// 战斗外MP恢复（30s）
setInterval(() => {
  if (!state.inCombat && !state.isCultivating) {
    state.mp = Math.min(state.maxMp, state.mp + 5);
  }
}, 30000);
```

### 3.4 getMpReg() 函数

```javascript
function getMpReg() {
  const realm = state.realm;
  const path = state.path; // 'wu' or 'ling'
  const base = path === 'wu' 
    ? [2, 5, 10, 18, 35, 80]  // 武修 mpReg by realm
    : [3, 7, 14, 25, 50, 110]; // 灵修 mpReg by realm
  let reg = base[realm] || 0;
  // + 心法加成（每级心法 +2/tick）
  // + 饰品加成（固定 +X/tick）
  return reg;
}
```

```javascript
// renderer.js
function renderMp() {
  const pct = (state.mp / state.maxMp * 100).toFixed(1);
  const term = getTerm('power'); // "内力" or "灵力"
  document.getElementById('mp-label').textContent = `${term} ${Math.floor(state.mp)}/${state.maxMp}`;
  document.getElementById('mp-fill').style.width = pct + '%';
  // 真气条渐进色：蓝→紫→红
  const color = pct < 33 ? '#4a90d9' : pct < 66 ? '#9b59b6' : '#e74c3c';
  document.getElementById('mp-fill').style.backgroundColor = color;
}
```
