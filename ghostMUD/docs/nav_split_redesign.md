# 导航分层重设计方案 v2

> 日期：2026-07-07
> 状态：设计稿，待用户确认后执行

## 一、需求理解

用户的核心诉求：

1. **方位通路（东南西北等）从感知面板移到江湖页区域2**——放在`[人物]`区下方、`[感知]`/`[修行]`操作按钮区上方，作为常驻方向标记，直观显示"此处联通着xxx"
2. **非方位入口（酒肆/古井/铁铺等）收在[感知]面板中**——营造"仔细一瞧，此处还藏着xxx"的探索感
3. **副本感设计**：独立房间（如太白酒肆）入口挂在街道上，进入后内部子房间互相联通，退出时只能从大门回到街道——形成"世界地图→副本"的层次感

- 副本感缺乏数据层支撑——当前connections没有区分"主入口"和"内部通道"

### 3.2 exit-bar 视觉重设计

**设计目标**：让玩家一眼看到"从这里可以去哪里"

```
┌──────────────────────────────────────┐
│  ── 此处联通 ──                       │
│  [北] 应天府·北大街  [南] 应天府·南大街 │
│  [东] 应天府·东大街  [西] 应天府·西大街 │
└──────────────────────────────────────┘
```

- 增加标题行 `── 此处联通 ──`（淡墨色小字）
- 按钮横排自动换行，每个按钮：方向字（大）+ 目的地名（小）
- 已探索 → 正常墨色；未探索 → 半透明 + ？？？
- 无方位通路时（如副本内部）整个 exit-bar 隐藏

### 3.3 感知面板中的探索入口

**设计目标**：营造"仔细一瞧"的发现感

```
> 隐处可探
  酒肆 → 太白遗风·酒肆
  古井 → 应天府·古井巷
  铁铺 → 应天府·铁匠铺
```

- 标题改为 `> 隐处可探`（比 `> 隐处` 更完整）
- 每项：入口名（方向键原文）→ 目的地名
- 已探索正常显示，未探索显示 `???`

### 3.4 副本感数据层设计

**核心规则**：
- **街道/广场/大路**：connections 中用方位键（东南西北）连接其他街道 → 形成世界地图网络
- **商铺/酒楼/寺庙/景点**：入口用商铺简称（如"酒肆"、"古井"、"铁铺"）挂在街道的 connections 中 → 玩家从街道进入
- **副本内部**：子房间之间的连接用 方位键 或 动作键（如"上楼"、"后门"），但**退出只能回到入口街道**

**数据示例**：
```javascript
// 街道 → 世界地图网络
'应天府·西大街': {
  connections: {
    '东': '应天府·十字街口',  // 方位→另一条街
    '西': '应天府·石城门',
    '北': '应天府·鼓楼街',
    '南': '应天府·绫庄巷',
    '酒肆': '太白遗风·酒肆',   // 探索入口→副本
    '铁铺': '应天府·铁匠铺',
    '古玩': '鉴古斋·古玩铺'
  }
}

// 副本内部 → 子房间互联，退出回街道
'太白遗风·酒肆': {
  connections: {
    '出': '应天府·西大街',     // 只有一个出口回街道
    '上楼': '太白遗风·二楼',   // 内部通道
    '后院': '太白遗风·后院'
  }
}
```

**副本感体现**：
1. 玩家在西大街看到 `[出] 太白遗风·酒肆`（在感知面板中）→ 点击进入
2. 进入酒肆后，exit-bar 显示 `[出] 应天府·西大街`（唯一的方位通路）
3. 酒肆内部的 `[上楼]`、`[后院]` 等连接如果也是非方位键，则收在感知面板中
4. 如果酒肆内部有方位键连接（如二楼`北`→后院），则显示在 exit-bar 中

### 3.5 connections key 分类规则

| key 类型 | 示例 | 显示位置 | 说明 |
|----------|------|----------|------|
| 方位键 | 北/南/东/西/上/下/出 | exit-bar（常驻） | 世界地图通路 |
| 非方位键 | 酒肆/古井/铁铺/上楼/后院 | 感知面板（隐处可探） | 副本入口/内部通道 |

**CARDINAL_DIRS 集合**（已有，保持不变）：
```
['北', '南', '东', '西', '上', '下', '出', 'north', 'south', 'east', 'west', 'up', 'down', 'out']
```
