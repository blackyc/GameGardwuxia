# 行功战斗系统 · 技术方案

**版本**: v1.0  
**日期**: 2026-06-23  
**依赖**: rebuild_meridians.js / rebuild_seals.js / rebuild_builds_drops_corruption.js / combat_systems.json  
**引擎**: daogui_mud.html（现有回合制引擎）  
**改动级别**: 中度重构（战斗循环替换，不波及房间/对话/任务/地图）

---

## 一、概述

### 1.1 当前问题

经典回合制（玩家每回合选择：攻击/技能/物品/防御）在诡仙录中有三个结构性缺陷：

1. **Build深度未利用**：8脉×5品阶×35刻印×9流派 = 庞大的策略空间，但在手操模式下被压缩为「每回合选最优解 → 反复按同一个按钮」
2. **叙事断裂**：灵修畸变、道心崩塌的核心恐怖是「失控」，但手操战斗永远在玩家的完全控制之下 → 恐怖仅存在于房间描述中，不进入战斗层
3. **刷怪疲劳**：MUD中遭遇第20只蛇婆时，手操没有提供额外的策略乐趣，只是机械重复

### 1.2 设计目标

把战斗从 **「你选招式」** 变为 **「你设计一套行功→看着它运转→未知何时会失控」**。

### 1.3 核心机制：「行功」

> 行功者，气循经脉而周流，身随气转，不假思索。

**行功 = 预设式的战斗自动循环**。玩家在安全区（城镇/洞府/宗门）将招式填入5个行功位，进入战斗后角色自动按行功五式依次出招——不可手选。玩家保留三次干预权利（变式/服药/脱战），用完即进入纯行功状态。

## 二、行功五式

### 2.1 五式结构

```
┌──────────────────────────────────────────────────┐
│              行功图 · 五式                         │
│                                                  │
│  [一·起式] → [二·承式] → [三·转式] → [四·合式] → [五·归式]
│      ↑                                              │
│      └──────────────── 循环 ────────────────────────┘
│                                                  │
│  每走完一圈 = 完成一个小周天                        │
│  小周天累计影响：精元回复速率 / 暴击率 / 畸变判断    │
└──────────────────────────────────────────────────┘
```

### 2.2 各式设计倾向

| 式位 | 名称 | 定位 | 推荐内容 | 违规后果 |
|------|------|------|---------|---------|
| 第一式 | 起式 | 开局态势 | 增益/护身刻印、探测类武学、气势叠加 | 若放纯攻击：首击伤害-20%（起式不是用来打的） |
| 第二式 | 承式 | 主力输出 | 稳定伤害武学、破甲连击、dot上毒 | 无惩罚（最自由的槽位） |
| 第三式 | 转式 | 应变判断 | 条件触发类、削敌buff、属性转换 | 若放纯攻击：该式不会触发条件效果，视为普通攻击 |
| 第四式 | 合式 | 杀招释放 | 高精元消耗终结技、刻印爆发（修罗道/修罗道·极） | 无惩罚，但本式精元消耗×1.5（杀招就该费气） |
| 第五式 | 归式 | 回气收式 | 恢复类、清除debuff、蓄力为下一轮铺垫 | 若放纯攻击：下一轮起式效果减半 |

> **设计意图**：不是强制角色划分，而是「顺式而行效率更高，逆式而行也能打但吃亏」。高手可以故意在起式放杀招打心理战（牺牲20%伤害换取对手误判），这是高阶玩法。

### 2.3 行功图预设

每个角色最多保存 **3套行功图**：

```
行功图一「破邪谱」    行功图二「守心谱」    行功图三「搏命谱」
起: 天罡望气术(探测)   起: 金汤·坚壁(护)    起: 天罡附体(全buff)
承: 龙爪手(拳掌连击)   承: 天眼灵视(标记)    承: 修罗道(狂战)
转: 破军(混乱)         转: 铁布衫(固守)      转: 须臾(额外回合)
合: 万兵归宗(兵器技)   合: 回春(全恢复)      合: 修罗道·极(搏命)
归: 吐纳术(回气)       归: 生生·正骨(治疗)   归: 丹田引爆（⚠️）
```

战斗中可使用一次「变式」指令切换行功图。切换后从该图的起式重新开始。

## 三、ATB速度系统

### 3.1 速度条模型

```
角色速度条: [0 ─────────────────────── 100]
             ↑                              ↑
            每帧填充 speed/100           满100触发行动

速度 = 基础速度 × 脉位修正 × 状态修正
基础速度 = 10 + (追风脉品阶 × 3) + (身法属性 / 5)
```

### 3.2 速度来源

| 来源 | 数值 | 备注 |
|------|------|------|
| 追风脉·凡品 | +3 speed | 草上飞 & 踝关节反弯 |
| 追风脉·良品 | +6 speed | 梯云纵 & 蹼膜 |
| 追风脉·珍品 | +9 speed | 凌波微步 & 关节反曲 |
| 追风脉·仙品 | +12 speed | 神行百变 & 鸟骨化 |
| 追风脉·先天品 | +16 speed | 缩地成寸 & 虚影腿 |
| 天罡·神行术（刻印） | 移速+30%（临时） | 持续15回合 |
| 须臾（刻印） | 额外行动回合 | 不计入速度填充 |

### 3.3 速度条可视化

MUD文本模式下，每回合不显示完整速度条，而是用节奏感知替代：

```
[行功] 第一式·起式 → 天罡望气术
       你隐约感知到蛇婆的气息——还有第二条，藏在石后。

[蛇婆] 蛇婆弓身蓄力，鳞片摩擦声刺耳……（速度86/100）

[行功] 第二式·承式 → 龙爪手
       你右臂鳞甲怒张，五指如钩直取蛇婆七寸！-47HP
       蛇婆吃痛，蛇尾横扫——（格挡）——你以金刚脉硬接，-8HP

[蛇婆] 蛇婆喷出毒雾！你吸入一口，视野模糊……（中毒·3回合）
```

ATB决定了谁先动、动作间隔。但文本表现上不显示冰冷的数字，而是以叙事节奏体现「快」和「慢」——追风脉大成者感觉「抬手便有」，追风脉未修者感觉「每招都慢半拍」。

### 3.4 速度计算公式

```javascript
// 速度条填充
speedBar.fill(speed / 60, perSecond);  // 每秒填充 speed/60 点

// 行动触发
if (speedBar >= 100) {
  executeAction();     // 执行当前行功式位
  speedBar -= 100;     // 溢出保留（高速角色可直接连动）
  advanceGongSlot();   // 前进到下一个行功位
}
```

**高速连动**：若角色速度极高（追风脉先天品+天罡·神行术），可能在敌人一次行动间连出2-3式。这在叙事上表现为「身形一晃，三招已出」。

## 四、行功位的可填入内容

每个行功位可填入以下三类之一：

### 4.1 武学招式（来自八脉中的功法/异化）

```
第一式·起式 → 铁砂掌残篇（龙象脉·武修·凡品）
              效果: str+2, 拳掌+5, 持续3式
```

武修功法在行功中表现为固定数值招式。灵修异化在行功中表现为「身体自己动的动作」——描述文本随畸变等级变异。

### 4.2 神魂刻印（来自 rebuild_seals.js）

```
第三式·转式 → 须臾（ys_05）
              神识消耗: 35, 冷却: 12式
              效果: 获得1个额外行动回合
```

刻印在行功中的冷却单位为「式」而非「回合」。须臾冷却12式 = 走完两轮+2式后可再用。

### 4.3 丹药/法器（战斗中限用1次/法器）

```
（手动干预时使用，不占行功位）
```

> 行功位不能为空。5个位置必须填满才能激活行功图。新手初始行功图为宗门标配（华山剑宗=剑招起手，少林=拳掌起手，归墟=触须起手）。

## 五、畸变·行功失控

### 5.1 篡改触发条件

每式执行前，做一次畸变判定：

```javascript
篡改概率 = baseHijackRate + corruptionLevel × 10%
baseHijackRate = 0（畸变0级）→ 3%（畸变1级）→ 8%（畸变2级）
               → 15%（畸变3级）→ 25%（畸变4级）→ 40%（畸变5级）
```

| 畸变等级 | 篡改率 | 篡改内容 |
|---------|--------|---------|
| 0（常人） | 0% | 无篡改 |
| 1（初显） | 3% | 招式描述文本轻微变异（「龙爪手」写为「你的手指比心快了一步」） |
| 2（外显） | 8% | 描述变异+偶尔伤害值波动±20% |
| 3（半人） | 15% | 行功位被**替换为异化招式**（龙象脉·臂骨化龙骨→「你的右臂自己动了」） |
| 4（人皮） | 25% | 行功位被替换+有概率**跳位**（执行完起式后跳过承式直落到合式→杀招不受控制地提前放出） |
| 5（不可名状） | 40% | 行功图被**整体覆盖**为「祂的行功图」——五式全部变为不可名状技，效果随机（秒杀/反噬/虚空洞见/畸变加速/精元虹吸） |

### 5.2 叙事表现

```
[行功] 第二式·承式 → 龙爪手
       你运气至右臂，准备递出龙爪手——           
       但右臂没有出龙爪手。
       
       你的五指自行反转，掌心裂开一道竖缝，
       一根骨白色的东西从中探出，像是触须，又像是指节的延续。
       它不受控制地扫向蛇婆的面门——
       
       -82HP（畸变·异化自发：臂骨化龙骨）
       
       蛇婆发出一声你听不懂的声音，像是尖叫，又像是……
       某种你从未听过的语言中的一个音节。

       [道心判定] 你的手刚刚做了你没有让它做的事。
       道心-1（当前: 34/100）
```

### 5.3 灵修专属行功图

畸变≥3的灵修修士可以解锁**异化行功图**——主动将异化招式填入行功位。这套行功图威力极高，但：

- 每次完整循环（走完五式）道心-2
- 畸变篡改率翻倍（因为你在主动邀请）
- 不能被变式切换回武修行功图（需要回宗门「镇压」）

```
异化行功图「虫母礼赞」
起: 妖虫孵化（召唤3只共生妖虫）
承: 虫群号令（妖虫全体攻击）
转: 血肉通道（牺牲1只妖虫，精元全回复）
合: 虫母之触（int×5道心伤害，无视护甲）
归: 吞噬残余（吞噬所有死亡单位，精元/神识回复）
```

## 六、玩家干预系统

战斗中玩家保留**三类、各一次**的干预权：

### 6.1 变式（切换行功图）

```
> 变式 搏命谱
[行功中断] 你强行逆转行功路线，真气翻涌……
           精元-20（变式代价）
           起式·搏命谱 → 天罡附体
```

- 消耗：精元-20 + 当前式位被打断（该式效果取消）
- 新行功图从起式开始
- 冷却：每场战斗限1次

### 6.2 服药（紧急物品）

```
> 服药 护脉丹
[服药] 你咬碎护脉丹，药力随唾液渗入喉中……
       精元+50，畸变临时-5（持续10式）
       （战斗中限服药1次）
```

- 每次战斗限1次
- 丹药从行囊中选择（不占行功位）
- 灵修服用「镇畸丹」可暂时压住畸变篡改率，但有10%概率丹药被「祂」替换为「无名丹」（效果未知）

### 6.3 脱战（逃跑）

```
> 脱战
[脱战判定] 追风脉修正 +30%脱战率……
           你以神行百变身法后撤，蛇婆追之不及。
           → 脱离战斗
```

- 脱战成功率 = 基础30% + 追风脉品阶×5% + 身法修正
- 脱战失败消耗一个行动回合（敌人获得一次自由攻击）
- 灵修畸变≥4：脱战时20%概率「脚不听使唤」——追风脉被异化肢替代，逃跑方向随机（可能逃进更深处）

### 6.4 不干预时

若玩家不进行任何干预，角色纯按行功图执行。**道心≥50的武修**可以设置行功图内嵌条件（如「第三式·转式 若HP<30%则执行回春而非破军」），这算是武修的「神志清醒红利」。

## 七、与现有系统的桥接

### 7.1 A/(A+B)概率引擎（来自 combat_systems.json）

行功系统不替换底层概率模型，而是在其上叠加：

```
行功层（五式调度） → 动作为「龙爪手」
    ↓
概率引擎层（A/(A+B)）→ 龙爪手攻击 vs 蛇婆闪避/格挡
    ↓
伤害公式层（立方公式 + 护甲减免）
    ↓
叙事渲染层（文本输出 + 畸变篡改覆盖）
```

### 7.2 奇经八脉映射

| 脉位 | 行功中的影响 |
|------|------------|
| 龙象脉 | 每式攻击力修正：+str×(品阶/5) |
| 天眼脉 | 承式的命中率+per×2%；转式的条件判断范围扩大 |
| 金刚脉 | 对手行动时自动减伤：护甲×(品阶/5) |
| 追风脉 | 速度条填充速率；脱战成功率 |
| 命源脉 | 精元上限；合式精元消耗倍率（品阶越高倍率越低） |
| 灵台脉 | 刻印冷却加速；畸变篡改抵抗率+3%/品阶 |
| 百骸脉 | 承式伤害+weaponBonus×品阶 |
| 丹田异核 | 小周天完成后的特殊效果（详见7.3） |

### 7.3 小周天完成奖励

每走完一圈行功五式 = 完成一个小周天。完成时触发：

```
小周天·第N次：
  精元回复: 5 + 命源脉品阶×2
  丹田效果: 取决于丹田异核形态
  
  武修:
    聚气丹 → 下轮精元消耗-5%
    凝神丹 → 下轮免疫精元枯竭
    金丹初成 → 暴击率+10%（累计）
    元婴凝结 → 可选重置任一式位（限1次/战）
    不灭道种 → 道心+1（战斗中不跌）
    
  灵修:
    虫巢核心 → 妖虫孵化进度+20%
    孵化核心 → 若进度满则孵化1只妖虫
    界隙核心 → 小概率打开侵蚀层裂缝（放逐敌人/召来异物）
    旧神碎片 → 随机触发一种「不可名状之力」
    门 → 门开一缝。后果不明。
```

## 八、特殊机制

### 8.1 残式惩罚

若行功图中有空位（如只填了3式），该行功图视为「残式」：

```
残式惩罚:
- 每到空位时，角色陷入「气机中断」状态——该式跳过，且下一式伤害-30%
- 空3式以上 → 行功图无法激活
```

### 8.2 一式多用（高手向）

同一武学可在多个式位重复填入：

```
行功图「疯虎谱」:
起: 龙爪手（伤害-20%但开局直接上压力）
承: 龙爪手
转: 龙爪手
合: 龙爪手（×1.5精元消耗）
归: 龙爪手（下轮起式减半）
```

每式都出同一招 = 放弃策略深度换取纯粹压制。对低智敌人有效，对高智敌人会被预判闪避。

### 8.3 武修·灵修行功差异

| 维度 | 武修 | 灵修 |
|------|------|------|
| 行功位来源 | 功法（来自各脉武修线） | 异化（来自各脉灵修线） |
| 刻印使用 | 冷却正常 | 冷却-15%（灵台已异化） |
| 畸变篡改 | 无（除非曾为灵修后转回） | 有（按畸变等级） |
| 变式代价 | 精元-20 | 精元-20 + 畸变+2 |
| 行功图替换 | 安全区任意换 | 畸变≥3后不能换回纯武修行功图 |
| 道心锁定 | 可设内嵌条件 | 畸变≥3后条件可能被无视 |

### 8.4 BOSS特殊行功

部分BOSS拥有专属行功图，让BOSS的行为不再是「随机选技能」，而是有章法可循：

```
血禅寺方丈「血海谱」:
起: 血海结界（全场dot）
承: 血禅掌（吸血+自身回复）
转: 若HP<50% → 金刚伏魔（驱散玩家buff）
    若HP≥50% → 血海潮涌（dot翻倍）
合: 血佛降世（全场大伤害+自身HP减半）
归: 血禅诵经（回复+清除自身debuff）
```

玩家观察BOSS的行功规律 = 预判其合式回合、提前放护身刻印或变式逃逸。这比随机技能多了「观察→学习→对策」的层次。

## 十一、潜在风险与对策

| 风险 | 等级 | 对策 |
|------|------|------|
| 玩家感觉失去控制权（觉得在看动画） | 高 | 三次干预权+条件式+变式切换 = 关键决策点保留 |
| ATB计时在纯文本下体验不佳 | 中 | 不显示速度条数字，用叙事节奏（「你感到蛇婆的毒牙已经近了」）替代；或提供即时/加速模式 |
| 畸变篡改过强导致负面体验 | 中 | 初期篡改仅影响描述文本（叙事层），中期才侵入数值层，给玩家适应时间 |
| 行功位太少（5个）不够表达复杂策略 | 低 | 可通过小周天完成后的自由式（丹田异核效果）补足；或提供「贯通」机制——两个相邻式位融合为一个复合招式 |
| MUD传统玩家不接受 | 低 | 保留经典模式作为备选；行功模式设为「推荐但非强制」 |

## 十二、设计哲学（写给团队）

行功不是简化战斗——它是在换一种方式加深战斗。

经典回合制吸引人的是「每个回合我都做出最优选择」。行功吸引人的是「我设计了一套会自己运转的东西，然后看着它和敌人碰撞——有时候它按我的计划走，有时候它走到了我没预料到的地方」。

前者是**棋手的快乐**，后者是**造物者的快乐**。

在诡仙录的叙事框架里，「失控」是终极恐惧。道心会跌、畸变会涨、你身体里那些不是你的东西会替你行动——但如果战斗层永远在你的精确控制之下，这些恐怖就永远是纸面上的设定。只有当你在战斗日志里看到「你的右臂自己动了」——而它真的不是你命令的——这个恐惧才进了骨头。

这就是为什么行功系统不是「另一个战斗模式选择」，而是**将叙事恐怖从 room.desc 搬进 combat.function 的唯一路径**。
