## 一、设计来源

本方案融合四个游戏的战斗设计基因：

| 来源 | 贡献 | 层级 |
|------|------|------|
| **弈仙牌** | 顺序出招骨架（起→承→转→合→归）、8格→5槽映射、自动对战（Build完即挂机） | 底层机制 |
| **江湖悠悠** | 装备对战斗参数的深度影响（武器改变整套行功图伤害/气耗曲线）、装备鉴定+词缀随机 | 装备层 |

| **传统RPG** | 真气(蓝条)设定：与血条并列、上限可成长、战斗外恢复、战斗内可选牺牲出招补充 | 资源层 |

## 二、概述

### 2.1 核心理念

> 行功者，气循经脉而周流，身随气转，不假思索。

**行功 = 预设式的战斗自动循环。** 玩家在安全区将招式填入5个行功位，战斗开始后角色自动按起→承→转→合→归依次出招。每招消耗真气，真气不足时触发门禁选择。玩家保留三次干预权利。

**设计哲学**：把战斗从「你选招式」变为「你设计一套行功→看着它运转→真气不足时做一次关键决策」。

### 2.2 与v1.0的关键变化

| | v1.0（ATB速度系统） | v2.0（真气门禁系统） |
|---|---|---|
| 出招逻辑 | 速度条驱动，谁能动谁先打 | 简单顺序：起→承→转→合→归 |
| 资源管理 | 精元（每招消耗，战后回复） | 真气（蓝条池，每招消耗，战斗外回复） |
| 门禁机制 | 无（招式必出） | 真气不够时触发4选1决策 |
| 装备层 | 仅八脉品阶修正 | 江湖悠悠式装备+鉴定词缀 |
| 挂机友好度 | 中（需关注速度条连动） | 高（门禁有默认选项自动继续） |
| UI复杂度 | 中（速度条+精元） | 低（一条真气条+门禁弹窗） |
| 数值平衡 | 中（速度联动复杂） | 低（单变量：总气耗 vs 真气上限） |

## 三、真气系统（蓝条）

### 3.1 真气定义

```
真气 = 传统RPG法力池

· 与血条并列，拥有点数上限
· 每招消耗固定真气值
· 战斗内恢复方式：
  ├── 调息：牺牲该式位，跳过出招，恢复固定真气
  ├── 丹药：战斗内限服1次，如回气丹恢复40真气
  ├── 归式特殊：部分归式带有「回气」效果（下轮起式真气消耗减半等）
  └── 刻印被动：如「气海印」每圈周天结束后恢复N点
· 战斗外恢复：打坐/回气丹/休息 → 自然满
· 境界提升 → 真气上限成长
```

### 3.2 真气上限来源

| 来源 | 数值 | 备注 |
|------|------|------|
| 境界·凡人（基础） | 80 | 初始 |
| 境界·武者 / 炼气 | 120 / 100 | 武修体魄更足、灵修略少 |
| 境界·武士 / 筑基 | 160 / 140 | |
| 境界·武师 / 金丹 | 200 / 190 | |
| 境界·宗师 / 元婴 | 250 / 250 | 追平 |
| 境界·天人 / 化神 | 300 / 320 | 灵修反超（气海被灵窍撑大） |
| 丹田异核·凡品 | +10 | 八脉·丹田槽 |
| 丹田异核·灵品 | +20 | |
| 丹田异核·玄品 | +30 | |
| 丹田异核·地品 | +45 | |
| 丹田异核·先天品 | +60 | |
| ≥3同宗羁绊 | +20 | 宗门共鸣 |
| 刻印·气海印 | +25 | 刻印槽嵌入 |
| 刻印·气海印(灵品) | +40 | 品阶升级 |

> **真气上限是Build变量**：玩家可以投资丹田品阶、凑羁绊、嵌气海印来扩充真气池，也可以放弃这些投资、用更少的真气打更紧凑的行功图。

### 3.3 真气消耗

每招有独立气耗值：

```
劈风剑（凡品）  气耗=15   伤害=40
贯云势（良品）  气耗=22   伤害=55
崩山击（珍品）  气耗=35   伤害=90
回元诀（良品）  气耗=10   治疗=30
破阵枪（地品）  气耗=45   伤害=120
─────────────────────────────
一圈总气耗 = 127
```

## 四、行功五式（顺序出招）

### 4.1 五式结构

```
┌──────────────────────────────────────────────────┐
│              行功图 · 五式                         │
│                                                  │
│  [一·起式] → [二·承式] → [三·转式] → [四·合式] → [五·归式]
│      ↑                                              │
│      └──────────────── 循环 ────────────────────────┘
│                                                  │
│  每走完一圈 = 完成一个小周天                        │
│  小周天累计影响：精元回复 / 暴击率 / 畸变判定       │
│                                                  │
│  出招逻辑：                                       │
│    ① 轮到该式                                    │
│    ② 检查真气 ≥ 该式气耗？                        │
│       ✅ 够 → 正常出招 → 扣真气 → 前进到下一式      │
│       ❌ 不够 → 触发门禁（4选1）                   │
│    ③ 继续循环（起→承→转→合→归→起→...）            │
│    ④ 敌方回合 → 敌方按同样规则执行（有自己行功图）   │
└──────────────────────────────────────────────────┘
```

### 4.2 真气门禁（真气不足时的4选1）

当轮到某式但真气不足时，弹出选择：

```
┌─────────────────────────────┐
│  真气不足！破阵枪需要45气     │
│  当前真气：38                │
│                             │
│  ○ 调息    跳过归式，+30真气  │
│  ○ 服药    服用回气丹，+40   │
│  ○ 平斩    消耗10气，低伤害  │
│  ○ 强行    消耗全部38气，    │
│            伤害=120×(38/45) │
│            = 约101           │
│                             │
│  [若5秒未选择，自动执行「调息」] │
└─────────────────────────────┘
```

| 选项 | 气耗 | 效果 | 风险 |
|------|------|------|------|
| **调息** | 0（跳过该式） | 恢复30真气，下式正常延续 | 该式不出招=浪费1个式位的输出机会 |
| **服药** | 0（跳过该式） | 从行囊选丹药服用（限1次/战） | 耗尽本场服药权 |
| **平斩** | 10 | 普攻一刀（伤害=攻击力×0.5） | 放弃该式的武学效果（无附带buff/debuff） |
| **强行** | 全部剩余真气 | 按比例打折出招 伤害×(当前气/需求气) | 气耗效率低下，归零后下一式必出门禁 |

> **挂机模式**：若5秒未选择，默认执行「调息」。这意味着纯挂机党可以完全不看战斗、自动跳过门禁——代价是可能因为调息跳过关键招式而输掉，但这是Build深度的一部分（真气不够就别贪高耗招）。

### 4.3 各式设计倾向

| 式位 | 名称 | 定位 | 推荐内容 | 违式效果 |
|------|------|------|---------|---------|
| 第一式 | 起式 | 开局态势 | 增益/护身刻印、探测类武学、气势叠加 | 若放纯攻击：首击伤害-20%（起式不是设计来先手的） |
| 第二式 | 承式 | 主力输出 | 稳定伤害武学、破甲连击、dot上毒 | 无惩罚（最自由的槽位） |
| 第三式 | 转式 | 应变判断 | 条件触发类、削敌buff、属性转换 | 若放纯攻击：该式不会触发条件效果，视为普通攻击 |
| 第四式 | 合式 | 杀招释放 | 高真气消耗终结技、刻印爆发 | 无惩罚，但合式真气消耗×1.5（杀招就该费气） |
| 第五式 | 归式 | 回气收式 | 恢复类、清除debuff、蓄力为下一轮铺垫 | 若放纯攻击：下轮起式效果减半 |

### 4.4 行功图预设

每个角色最多保存 **3套行功图**：

```
行功图一「破邪谱」    行功图二「守心谱」    行功图三「搏命谱」
起: 天罡望气术(探测)   起: 金汤·坚壁(护)    起: 天罡附体(全buff)
承: 龙爪手(拳掌连击)   承: 天眼灵视(标记)    承: 修罗道(狂战)
转: 破军(混乱)         转: 铁布衫(固守)      转: 须臾(额外回合)
合: 万兵归宗(兵器技)   合: 回春(全恢复)      合: 修罗道·极(搏命)
归: 吐纳术(回气)       归: 生生·正骨(治疗)   归: 丹田引爆
   总耗: 110              总耗: 90              总耗: 185
```

战斗中可使用一次「变式」切换行功图。切换消耗真气-20，新图从起式重新开始。

## 五、真气曲线与Build哲学

真气系统创建了四种不同的Build策略：

### 5.1 爆发型（总耗 > 真气上限的130%）

```
真气上限180，总耗230+
前3-4招就烧空真气 → 每圈门禁频繁触发
玩家赌「强行运功」打折扣版合式/归式
→ 适合灵修畸变爆发流：我宁愿打折也要出这招
```

### 5.2 循环型（总耗 ≈ 真气上限的110-130%）

```
真气上限180，总耗200-230
每圈末固定触发1次门禁（通常发生在归式）
门禁默认选调息 → 放弃归式换回气 → 下圈顺利
→ 适合武修均衡流：按部就班，稳定循环
```

### 5.3 周转型（总耗 ≈ 真气上限的80-100%）

```
真气上限180，总耗140-180
基本不触发门禁，每圈5式全出
但打完一圈真气所剩无几 → 第二圈可能出事
→ 适合快剑流：第一圈压死你，压不死我就认了
```

### 5.4 充盈型（总耗 < 真气上限的50%）

```
真气上限250，总耗<125
永不触发门禁，5式平稳输出
代价：全是低耗低伤招式 → 战斗拖很久
→ 适合肉盾抗伤流/奶妈辅助流：我不急，你急
```

## 六、装备系统（江湖悠悠式）

### 6.1 武器对行功图的参数影响

武器不只是伤害数字，它改变整套行功图的参数曲线：

| 武器 | 品阶 | 效果 |
|------|------|------|
| 玄铁重剑 | 地品 | 剑宗招式伤害+12%，但所有招式气耗+15% |
| 柳叶快刀 | 良品 | 承式出招后有30%概率自动追加一次普攻 |
| 暗影短匕 | 灵品 | 起式+承式伤害+20%，合式+归式伤害-10% |
| 紫檀杖 | 玄品 | 所有治疗招式效果+25% |
| 裂魂枪 | 地品 | 灵修招式气耗-20%，但每招自损3%血量 |
| 墨刃 | 珍品 | 归式若为攻击招式，追加一次归式(气耗翻倍) |
| 竹剑·残 | 凡品 | 新手初始武器，无特殊效果 |
| 蛟骨鞭 | 地品 | 转式效果翻倍(控制/debuff持续回合×2) |

### 6.2 鉴定与词缀随机

装备获得时为「未鉴定」状态，找藏剑阁老鉴定后揭示品阶和随机词缀：

```
获得：玄铁重剑 ★☆☆（未鉴定）
→ 找藏剑阁老鉴定 →
   玄铁重剑 ★★★（玄品）
   词缀：沉（气耗+10%，伤害+20%）
   词缀：锐（所有招式伤害+5%）
```

| 词缀 | 效果 |
|------|------|
| 锐 | 伤害+5% |
| 沉 | 气耗+10%，伤害+20% |
| 淬毒 | 承式附加3回合毒伤(3/turn) |
| 断刃 | 归式伤害+40%，起/承式伤害-5% |
| 克星 | 对畸变敌人伤害+25% |
| 残锋 | 起式可连续释放两次，第二次伤害-30% |
| 轻身 | 所有招式气耗-8% |
| 开锋 | 归式无视护甲 |

> **开箱快感**：鉴定出双词缀地品武器的体验 = "我这build要改一改了"——和江湖悠悠拿到新装备后重新构建装备体系的节奏一致。

### 6.3 八脉装备映射

| 脉位 | 装备类型 | 对行功的影响 |
|------|---------|-------------|
| 龙象脉 | 武器/臂甲 | 每式攻击力修正：str×(品阶系数/5) |
| 天眼脉 | 额饰/目镜 | 承式命中率+per×2%；转式条件判断范围扩大 |
| 金刚脉 | 胸甲/护心镜 | 敌方回合自动减伤：护甲×(品阶/5) |
| 追风脉 | 鞋/腿甲 | 脱战成功率+品阶×5% |
| 命源脉 | 内甲/护符 | 真气上限+品阶×5 |
| 灵台脉 | 冠/发饰 | 刻印冷却-品阶×1式；畸变篡改抵抗+3%/品阶 |
| 百骸脉 | 饰品/戒指 | 承式伤害+weaponBonus×品阶系数 |
| 丹田异核 | 内丹/异核 | 真气上限加成(见3.2)；小周天完成时触发额外效果 |

## 八、畸变·行功失控

### 8.1 篡改触发条件

每式执行前，做一次畸变判定：

```javascript
篡改概率 = baseHijackRate + corruptionLevel × 10%
baseHijackRate = 0（畸变0级）→ 3%（畸变1级）→ 8%（畸变2级）
               → 15%（畸变3级）→ 25%（畸变4级）→ 40%（畸变5级）
```

| 畸变等级 | 篡改率 | 篡改内容 |
|---------|--------|---------|
| 0（常人） | 0% | 无篡改 |
| 1（初显） | 3% | 招式描述文本轻微变异（「龙爪手」写为「你的手指比心快了一步」） |
| 2（外显） | 8% | 描述变异+偶尔伤害值波动±20% |
| 3（半人） | 15% | 行功位被**替换为异化招式**（龙象脉·臂骨化龙骨→「你的右臂自己动了」） |
| 4（人皮） | 25% | 行功位被替换+有概率**跳位**（执行完起式后跳过承式直落到合式→杀招不受控制提前放出） |
| 5（不可名状） | 40% | 行功图被**整体覆盖**为「祂的行功图」——五式全部变为不可名状技，效果随机（秒杀/反噬/虚空洞见/畸变加速/精元虹吸） |

### 8.2 叙事表现

```
[行功] 第二式·承式 → 龙爪手
       你运气至右臂，准备递出龙爪手——           
       但右臂没有出龙爪手。
       
       你的五指自行反转，掌心裂开一道竖缝，
       一根骨白色的东西从中探出，像是触须，又像是指节的延续。
       它不受控制地扫向蛇婆的面门——
       
       -82HP（畸变·异化自发：臂骨化龙骨）
       
       蛇婆发出一声你听不懂的声音，像是尖叫，又像是……
       某种你从未听过的语言中的一个音节。

       [道心判定] 你的手刚刚做了你没有让它做的事。
       道心-1（当前: 34/100）
```

> **叙事文本规则**：每招只写一行招式名（「龙爪手」）。仅在以下情况追加叙事描写：①连续3式命中→追加「X招连贯，XXXX」②畸变触发→追加异化描写③敌方濒死→追加终结描写。其余时刻保持简洁。

### 8.3 灵修专属行功图

畸变≥3的灵修修士可以解锁**异化行功图**——主动将异化招式填入行功位。威力极高，但风险巨大：

```
异化行功图「虫母礼赞」
起: 妖虫孵化（召唤3只共生妖虫）
承: 虫群号令（妖虫全体攻击）
转: 血肉通道（牺牲1只妖虫，精元全回复）
合: 虫母之触（int×5道心伤害，无视护甲）
归: 吞噬残余（吞噬所有死亡单位，精元满）

· 每次完整循环道心-2
· 畸变篡改率翻倍（你在主动邀请祂）
· 不能被变式切换回武修行功图（需回宗门「镇压」）
· 真气消耗极高→门禁频繁→你大概率需要「强行运功」维持→打折+失控=双输螺旋
```

## 九、玩家干预系统

战斗中玩家保留**三类、各一次**的干预权：

### 9.1 变式（切换行功图）

```
> 变式 搏命谱
[行功中断] 你强行逆转行功路线，真气翻涌……
           真气-20（变式代价）
           起式·搏命谱 → 天罡附体
```

- 消耗：真气-20 + 当前式位被打断（该式效果取消）
- 新行功图从起式重新开始
- 冷却：每场战斗限1次

### 9.2 服药（紧急物品）

```
> 服药 护脉丹
[服药] 你咬碎护脉丹，药力随唾液渗入喉中……
       精元+50，畸变临时-5（持续10式）
       （战斗中限服药1次）
```

- 每次战斗限1次
- 丹药从行囊中选择
- 灵修服用「镇畸丹」暂时压住篡改率，但有10%概率丹药被「祂」替换为「无名丹」（效果未知）

### 9.3 脱战（逃跑）

```
> 脱战
[脱战判定] 追风脉修正 +30%脱战率……
           你后撤脱离，蛇婆追之不及。
           → 脱离战斗
```

- 脱战成功率 = 基础30% + 追风脉品阶×5%
- 脱战失败消耗一个行动回合（敌人获一次自由攻击）
- 灵修畸变≥4：20%概率脚不听使唤——逃跑方向随机

### 9.4 干预与真气门禁的关系

干预权和真气门禁是独立的两层：

1. **真气门禁**：真气不足时自动触发（4选1），默认5秒后选「调息」
2. **干预权**：玩家**主动**选择时机使用——你可以在真气够的时候照样吃药补满、在没出门禁的时候切行功图

## 十、BOSS行功图

BOSS不再随机选技能，而是拥有可预判的专属行功图：

### 10.1 血禅寺方丈 · 血海谱

```
起: 血海结界（全场dot，持续3圈）
承: 血禅掌（吸血，恢复伤害量50%）
转: 若HP<50% → 金刚伏魔（驱散玩家所有正面状态）
     若HP≥50% → 血海潮涌（dot伤害翻倍）
合: 血佛降世（全场大伤害+自身HP减半）
归: 血禅诵经（恢复自身15%HP + 清除自身debuff）

预判：合式是BOSS最弱时刻——血佛降世后HP减半→玩家的归式或下一圈起式是最佳击杀窗口
```

### 10.2 焰心教主 · 焰劫谱

```
起: 业火焚心（精神力压制，玩家灵台脉失效2圈）
承: 焰蛇缠身（单体大伤害 + 灼烧3回合）
转: 火海无涯（AOE + 推开玩家 → 跳过玩家下一式）
合: 涅槃（若HP<30% → 自爆AOE全场 + 自身濒死逃脱）
   　若HP≥30% → 焰心·极（蓄力1圈，下圈起式伤害×3）
归: 余烬回光（清除自身debuff + 恢复20%HP）

预判：涅槃自爆是演戏（教主濒死逃脱=不死）；真正需要防的是焰心·极的蓄力
```

### 10.3 设计意图

BOSS行功图的三个设计原则：

1. **可预判**：玩家观察1-2圈后能大概摸清BOSS的节奏（「她每到合式就放大招」）
2. **有对策窗口**：每个BOSS行功图存在1个「脆弱窗口」（如血佛降世后HP减半）
3. **不是背板**：条件分支（HP<X%时改变招式）保证了不同战斗展开不同节奏

## 十二、真气门禁 vs 经典回合制对比

真气门禁不是新增战斗系统，是**在顺序出招骨架上加了一个判断点**：

```
经典回合制：
  你选招式 → 角色打 → 敌人打 → 你选招式 → ...

弈仙牌式（纯顺序）：
  系统自动按行功图打 起→承→转→合→归→起→...

真气门禁版（本方案）：
  系统自动按行功图打
    ├── 每式检查：真气≥该式气耗？ ✅/❌
    ├── ✅ 正常出招 → 前进
    └── ❌ 门禁弹窗（4选1）→ 前进
  玩家只在门禁或干预时做决策
```

**一个回合 = 一方走完一整圈5式（或门禁终止）**。我方回合结束 → 敌方回合 → 我方回合，直到一方倒下。

## 十三、叙事文本渲染规则

### 13.1 基础规则


### 13.2 追加叙事（条件触发）

| 触发条件 | 追加文本 | 示例 |
|---------|---------|------|
| 连续3式全部命中 | 「三招连贯，枪出如龙！」 | 在第三式后插入 |
| 连续5式全部命中 | 「行功圆满，一气呵成！」 | 在归式后插入 |

## 十四、数值平衡框架

### 14.1 平衡变量

真气门禁方案的核心平衡变量仅三个：

```
① 单招气耗：每招消耗多少真气
② 单招伤害/效果：每招产生多少价值
③ 真气上限：角色总真气

系统的平衡方程：
  真气上限 ≥ 一圈总气耗 → 正常循环
  真气上限 ≈ 一圈总气耗×80-100% → 周转型
  真气上限 ≈ 一圈总气耗×60-80% → 循环型（每圈触发1次门禁）
  真气上限 << 一圈总气耗 → 爆发型（频繁门禁）
```

不像异步CD方案需要求解15+参数的多变量约束优化问题。真气门禁是单变量平衡：**总气耗 vs 真气上限**。

### 14.2 气耗定价指南

| 武学品阶 | 气耗范围 | 伤害/效果范围 | 效率比（伤害/气耗） |
|---------|---------|-------------|-------------------|
| 凡品 | 10-15 | 25-40 | 2.5-2.7 |
| 良品 | 16-25 | 40-65 | 2.5-2.6 |
| 珍品 | 26-40 | 65-105 | 2.5-2.6 |
| 灵品 | 30-50 | 80-130 | 2.6-2.7 |
| 玄品 | 35-55 | 95-150 | 2.7-2.8 |
| 地品 | 40-65 | 110-180 | 2.7-2.8 |
| 先天品 | 50-80 | 140-230 | 2.8-2.9 |

> 高阶品稍高效率比 = 奖励玩家追求高品阶武学 = 与境界锁配合（宗师才能用玄品以上）。

### 14.3 门禁的经济学

```
调息：损失1式输出 = 放弃伤害X，换取30真气 ≈ 下一个归式能正常释放
      → 经济学上：用1个式位的当前收益，换下一个循环的完整运行
      → 适合「该式本来就弱」的情况

平斩：消耗10气 = 伤害极低但不停转
      → 经济学上：避免循环中断，但放弃该式的武学效果
      → 适合「承式/转式」触发门槛后（这俩位置附带效果重要，平斩不打乱节奏）

强行：消耗全部气 = 伤害打折但招式的附带效果（如眩晕/破甲/毒）照常生效
      → 经济学上：用真气效率换「我必须出这招的效果」
      → 适合「归式是核心恢复技」的情况——宁可打折也要回血

服药：0气耗 = 消耗药品（珍贵资源）
      → 经济学上：用长期资源换短期战斗力
      → 适合「这仗必须赢」的关键战斗
```

## 十八、设计哲学

行功不是简化战斗——它是在换一种方式加深战斗。

经典回合制：**棋手的快乐**——每回合你都在做最优决策。
行功真气门禁：**造物者的快乐**——你设计了一套会自己运转的系统。真气是你的燃料，门禁是你设计失误（或故意选择）的后果。你看它跑起来，有时候按你的计划走，有时候真气不够时做出妥协——而那个妥协是你Build阶段就埋下的种子。

大招打八折也要放，还是调息等下一轮？这个选择不是系统塞给你的——是你的真气上限、你的5招总气耗、你的装备词缀决定了它是否出现。

在诡仙录的叙事框架里，「失控」是终极恐惧。道心会跌，畸变会涨，你身体里那些不是你的东西会替你出招——但如果战斗层永远被你精确控制，这些恐怖就永远停在房间描述里。只有当战斗日志里真的出现「你的右臂自己动了」——而你没有选那招——这个恐惧才进了骨头。
