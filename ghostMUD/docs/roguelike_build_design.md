# 诡仙录 · 肉鸽Build体系设计文档

**生成**: 2026-06-23  
**来源**: 基于 combat_systems.json（四MUD数值体系） + equipment_design.json（聊斋大明装备系统）重构  
**世界观**: 聊斋古风 + 克苏鲁灵异 + 金庸武侠基底  
**核心命题**: "每一具异化的肉身，都是一条不可回头的路"

## 〇、设计总纲

### 0.1 为什么需要肉鸽Build

传统MUD的成长是线性的——打怪→得经验→学技能→变强。但对于一个"武修vs灵修"双轨体系，线性成长的每一个节点都是"确定性的"，玩家没有"意外发现"的惊喜，也没有"build成型"的成就感。

肉鸽Build的核心价值：
- **每次死亡/重开后，随机掉落的奇物让你走上不同的路**
- **8个脉位×5个品阶 = 40+种选择，每次只能选8个 → 数千种组合**
- **道心下降/畸变加深的永久后果 → 每次选择都有重量**
- **Build成形那一刻的"啊，这个流派通了"的顿悟感**

### 0.2 设计哲学

| 原则 | 说明 |
|------|------|
| **奇物驱动Build** | 不是"我想玩剑修所以去练剑"，而是"我捡到了一把会说话的锈剑，它每晚在耳边低语……于是我成了剑修" |
| **两条铁轨** | 武修走装备路线（安全、可替换）、灵修走异化路线（高风险、永久改变） |
| **有限重开** | 脉位异化不可逆，但可以被更强的异化覆盖（旧的能力消失，畸变遗留） |
| **信息不对称** | 拿到奇物时不知道它到底是什么品阶、有什么隐藏效果——需要"开眼"后才能确认 |

### 0.3 术语映射（赛博大明 → 诡仙录）

| 赛博大明旧概念 | 诡仙录新概念 | 说明 |
|---------------|-------------|------|
**奇经八脉**（八个可被"异物"占据的经脉节点） | 修炼根基 |
 **奇物**（可融入经脉的异物） | 包括：古修遗物、妖丹碎片、异界寄生物、诅咒器物 |
 **神魂刻印**（刻在灵台上的术法印记） | 一次性/持续性的精神能力 |
**精元**（生命本源能量） | 驱动奇物的燃料 |
**神识**（灵觉广度） | 维持刻印和感知灵异的能力 |
 **异化反噬** | 奇物排斥肉体，造成永久畸变 |
**龙象脉**（主力量的奇经脉） | 武修→拳掌内功；灵修→异化肢体 |
**百骸脉**（主兵器操控的奇经脉） | 武修→兵器大师；灵修→血肉兵器 |
 **灵台脉**（主神识和刻印的奇经脉） | 刻印槽位+神识上限 |
**丹田异核**（主精元循环的核心脉） | 决定整体能量恢复速率 |

## 一、奇经八脉体系

### 1.1 八脉总览

武修和灵修共用八个脉位——但填充方式完全不同。

```
┌──────────────────────────────────────────────────────┐
│                    奇经八脉                            │
│                                                      │
│  [龙象脉]  [天眼脉]                                   │
│   力量      感知              武修 → 功法秘籍（可换）     │
│                              〓〓〓〓〓〓〓〓〓〓〓〓〓   │
│  [金刚脉]  [追风脉]          灵修 → 异化融合（不可逆）    │
│   防御      身法                                      │
│                                                      │
│  [命源脉]  [灵台脉]                                   │
│   精元      神识                                      │
│                                                      │
│  [百骸脉]  [丹田异核]                                  │
│   兵器      核心                                      │
└──────────────────────────────────────────────────────┘
```

## 二、神魂刻印系统

### 2.1 刻印概述

神魂刻印是刻在灵台上的"一次性/持续性法术"。类似原装备设计中的"神经灵石"，但完全剥离现代概念，改为修真体系。

刻印消耗**神识**激活，占用灵台脉提供的刻印槽位。激活后从记忆区中移除（一次性刻印）或在冷却期间不可用（循环刻印）。

## 三、肉鸽Build流派设计

### 3.1 流派总览

一个"Build" = 奇经八脉选择 + 神魂刻印组合 + 兵器选择 + 宗门武学。以下为预设的7大原型Build——实际游戏中玩家会混合搭配。

```
【武修六流】
  剑宗流    — 百骸脉(兵器)+天眼脉(感知)+追风脉(身法) → 暴击刺客, 高风险高回报
  拳禅流    — 龙象脉(力量)+金刚脉(防御)+命源脉(内息) → 阵地坦克, 低风险稳健
  枪阵流    — 百骸脉+龙象脉+命源脉 → 长兵器控场, 群体压制
  暗杀流    — 追风脉+天眼脉+百骸脉 → 潜行→破隐→一击必杀
  辅助流    — 灵台脉(刻印)+命源脉(续航)+金刚脉 → 多刻印切换, 团队增益
  宗师流    — 全脉均衡 → 无短板但无特长, 靠经验和武学深度致胜

【灵修三流】
  虫巢流    — 丹田异核(虫巢)+灵台脉(畸变脑)+命源脉(吞噬心) → 召唤共生妖虫, 军队式作战
  血肉流    — 龙象脉(异化臂)+金刚脉(外骨骼)+百骸脉(骨兵器) → 自身武器化, 肉体即兵器库
  虚空流    — 天眼脉(竖眼)+灵台脉(枕边低语)+追风脉(虚影腿) → 灵视常驻, 以神识杀人
```

### 3.2 完整Build示例：剑宗流

```
「剑宗流」武修Build范例

奇经八脉:
  [天眼脉·三重] 紫微斗数推演 — per+6, 预读1回合敌人行动
  [追风脉·四重] 神行百变    — spd+9, 闪避后30%概率额外行动
  [百骸脉·四重] 万兵归宗    — 所有兵器技能+15, 缴械40%, 破兵25%
  [命源脉·二重] 小周天功    — 精元上限+40, 恢复+2/时辰
  [灵台脉·二重] 清心普善咒  — 神识上限+30, 刻印槽+2

神魂刻印:
  seal_ys_01·隐龙诀  — 隐身+破隐双倍伤害
  seal_ys_05·须臾    — 额外回合

兵器:
  主: 青冥剑 (轻剑, 速度优先, 配合多次行动)
  副: 破甲短匕 (缴械+破隐一击专用)

玩法循环:
  隐龙诀→接近→破隐一击(×2.0)→须臾(额外回合)→连续普攻→
  闪避触发神行百变→再次行动→敌人护甲被万兵归宗削弱→
  缷下敌人兵器→收尾

Build成形关键: 追风脉四重(神行百变) + 百骸脉四重(万兵归宗)
→ "闪避即进攻"的正反馈循环
```

### 3.3 完整Build示例：虫巢流（灵修·归墟）

```
「虫巢流」灵修Build范例 — 归墟宗专属

奇经八脉:
  [丹田异核·二重] 孵化核心  — 每7天孵化一只共生妖虫
  [命源脉·三重]   吞噬心    — 吞噬敌人尸体回复全部精元
  [龙象脉·三重]   第二关节臂 — 攻击范围×1.5
  [灵台脉·二重]   颅骨第二脑 — 刻印槽+3, 双意志（有时自控失败）
  [金刚脉·二重]   角质皮肤   — 外观如树皮, NPC好感-30%

神魂刻印:
  seal_ys_04·天雷破 — 范围伤害（虫群围攻时清场）
  seal_ys_06·破军   — 单体道心攻击（控制敌方主力）

畸变后果:
  - 孵化妖虫后 NPC 对话: "你身上有股……下水道的味"
  - 灵台脉二重后: 角色有时会自言自语（第二个"你"在说话）
  - 吞噬敌人尸体后: 道心-3/次, 但归墟修士宣称"万物归墟, 吞噬即修行"
  - 长期后果: 妖虫越来越多, 开始不听指挥，某天醒来发现虫子把你围在中间

玩法循环:
  用妖虫群消耗敌人→天雷破清场→吞噬尸体恢复精元→
  继续孵化新虫→队伍像滚雪球一样变大→
  但每次吞噬都让"第二个你"更强大……

结局风险:
  如果妖虫数量超过20 → 触发事件"虫巢反噬"
```

### 4.2 获取的"信息不对称"设计

奇物刚获得时，玩家只知道：
1. 它的名字（可能是模糊的，如"一枚温热的鳞片"）
2. 它适配哪个脉位（可能不准确——"你觉得它应该是往胳膊上放的"）

需要经过"开眼"才能确定：
- **武修低境界(0-2)**：只能看到凡品/良品的真实效果，珍品以上显示"一股若有若无的能量在流动，你读不懂"
- **武修高境界(3-4)**：可鉴定珍品，仙品以上显示"这已经不是凡间之物"
- **灵修1-5层**：随着灵视加深，可逐步看清所有品阶。但灵视看到的东西可能是真的也可能是祂想让你看到的

## 五、畸变系统与Build联动

### 5.1 灵修畸变五级体系（Build版扩展）

灵修的每个脉位异化都会累积**畸变值**。畸变值与道心是两个相关但独立的指标。

```
畸变值 = Σ(所有脉位异化的畸变风险 × 异化深度)

畸变等级:
  0级 (0-15)  — 外表正常
  1级 (16-30) — 某些特征开始"不对": 瞳孔偶尔竖裂、指甲偶尔反光
  2级 (31-50) — 异化不可隐藏: 鳞片/蹼/角质皮肤, NPC开始回避
  3级 (51-75) — 部分失去人形: 双套关节、外骨骼、第三眼
  4级 (76-100)— 人皮之下: 外表尚可维持, 但"底下"已经完全是别的东西
  5级 (101+)  — 不可名状: NPC无法对你产生"人类"的对话选项
```

### 5.2 畸变等级对Build的影响

| 畸变 | 正面 | 负面 |
|------|------|------|
| 1级 | 灵视初开（免费获得desc_percept） | 武修同门开始怀疑你 |
| 2级 | 对妖/鬼类敌人10%威慑 | 凡人城镇商人拒绝交易; 铁匠铺/药铺/酒馆 NPC 对话变冷 |
| 3级 | 对妖/鬼类30%威慑; 灵修技能伤害+15% | 武修宗门可能驱逐; 凡人城镇卫兵会主动盘查 |
| 4级 | 威慑50%; 所有灵修技能冷却-20% | 除灵修宗门外所有NPC恐惧; 武修视为敌人 |
| 5级 | 道心锁定不降（道心对畸变不再有抑制意义）; 解锁"不可名状之力" | 结局锁定"飞升线"; 自我意识逐渐溶解 |

### 5.3 Build决策的"道心-畸变"博弈

每次获得奇物，玩家面临抉择：

```
「一枚温热的鳞片」
  适配脉位: 龙象脉
  武修用法: 碾碎淬炼拳套（str+1, 无副作用）
  灵修用法: 植入前臂（str+4, 畸变+5, 进阶至"整臂鳞化"）

选择权在你:
  - 武修安全, 但上限低
  - 灵修危险, 但这是你变强的唯一捷径
  - 你已经畸变3级了……再往后退一步就是不可名状。
    但前面那个BOSS你打不过……
```

## 六、武修专属的替换逻辑

武修不是没有"奇物"——而是武修的奇物是**可拆卸**的。

| 机制 | 武修 | 灵修 |
|------|------|------|
| 脉位填充 | 功法秘籍（书/卷轴） | 异化融合（血肉共生） |
| 替换代价 | 遗忘旧功法（技能经验损失20%） | 旧异化被覆盖（旧能力消失，畸变残留保留30%） |
| 拆除后 | 脉位变空，重新寻找功法 | 脉位变空，但留下的畸变疤痕永久存在 |
| 外观 | 不变 | 畸变等级累积，不可隐藏 |
| NPC反应 | 正常（甚至因佩戴名器而尊敬） | 随畸变变化 |

## 七、数值平衡基准

### 7.1 与combat_systems.json的对齐

现有的 A/(A+B) 概率模型是底层引擎，Build系统的叠加值直接参与AP/DP计算：

```
AP = skill_power(attack_skill) + 脉位加成 + 刻印加成 + 兵器加成
DP = skill_power('dodge', 'parry') + 脉位加成 + 刻印加成

脉位加成 = Σ(各脉位的str/per/def/spd加成)
最终伤害 = damage_formula(base_damage + 兵器damage, damage_bonus + 脉位str加成)
```

### 7.2 品阶与境界对应

| 品阶 | 境界要求（武修/灵修） | 说明 |
|------|-------------------|------|
| 凡品 | 无 | 开店即售 |
| 良品 | 武修≥3级 or 灵修≥炼气 | 府城可购 |
| 珍品 | 武修≥宗师 or 灵修≥筑基 | 门派兑换/稀有掉落 |
| 仙品 | 武修≥大宗师 or 灵修≥凝脉 | BOSS掉落/隐藏任务 |
| 先天品 | 无境界要求但使用风险极高 | 唯一物品/终局内容 |
