# ADR-0001: 房间 ID 命名规范

**Status**: Accepted  
**Date**: 2026-06-28  

## Context

项目房间 ID 不统一：83 间城市房间中 53 间不带 `·`（如 `东大街`），30 间带（如 `应天府·十字街口`）。渲染层需要区分大区和房间名，不统一的 ID 导致显示逻辑混乱。

## Decision

所有房间 ID 强制 `大区·房间名` 格式。子级房间前缀填直接父级（`薛家旧宅·古井底`），非根区域。渲染层 `split('·')` 提取大区和显示名。

## Alternatives Considered

- **裸名 + region 字段**：改 LOCATIONS 数据结构，每个房间加 `region` 属性。否决：侵入性大，所有房间数据都要改结构。
- **保持现状不统一**：否决：渲染层需要两套逻辑，后续维护成本递增。

## Consequences

- 现有 57 间不带 `·` 的房间需要批量加前缀
- 所有 `connections` 引用需要同步修改
- `src/game.js` 中硬编码的 `应天府·街口` 等 bug 需修正
- 新建 `docs/room_naming_convention.md` 供后续参考

# ADR-0002: 门派/秘境地图独立文件

**Status**: Accepted  
**Date**: 2026-06-28  

## Context

问剑峰新手引导需要 10+ 间门派房间。当前房间数据按 city/wild/dungeon 三类分文件，门派 HQ 没有专属文件。

## Decision

每个门派 HQ 和每个秘境副本各对应独立 JS 文件，命名 `work/rebuild_rooms_<name>.js`。问剑峰为 `work/rebuild_rooms_wenjianfeng.js`。

## Alternatives Considered

- **放入 wild 文件**：否决，问剑峰不是荒野。
- **放入 city 文件**：否决，门派 HQ 规模会越来越大，城市文件已 335KB。

## Consequences

- 后续 11 个门派 + N 个秘境各有独立文件
- `index.html` 需追加 `<script>` 引用
- `data_loader.js` 的 `collectData()` 需扩展收集新文件数据

# ADR-0003: TutorialManager 独立状态机

**Status**: Accepted  
**Date**: 2026-06-28  

## Context

黄金三章引导涉及多步骤、多区域、多NPC交互、视角切换、时间跳转，逻辑复杂度高。

## Decision

新建 `src/ui/tutorial_manager.js`，独立管理引导流程状态机。`game.js` 通过 `tutorial.next()` 和 `tutorial.isLocked(action)` 接口交互。引导数据放 `work/wenjianfeng_tutorial_data.js`。

## Alternatives Considered

- **塞在 game.js 里用 questStages**：否决，面条代码，难以维护。
- **硬编码在 TutorialManager**：否决，剧情文本量大，数据和逻辑应分离。

## Consequences

- 新增 2 个文件：`tutorial_manager.js` + `wenjianfeng_tutorial_data.js`
- 全程软引导（不硬锁移动），后续需要硬锁定时再加
- 对话台词严格 copy 设计原文，场景描述可自行发挥

# ADR-0004: 时间系统

**Status**: Accepted  
**Date**: 2026-06-28  

## Context

当前游戏无时间系统。问剑峰引导需要时辰推进（挂机5分钟=1时辰）、竹林深处入口限时（子时）、房间描述四时段变体。

## Decision

`state` 新增 `gameTime`（0-11循环）和 `realTimeAccumulator`（ms累计）。每 30 秒 idleTick 累加，满 5 分钟推进 1 时辰。存档保存两个字段。时辰→四时段映射：寅卯辰=清晨，巳午未=正午，申酉戌=黄昏，亥子丑=入夜。

## Alternatives Considered

- **真实时间映射**：用现实时钟映射游戏时辰。否决：玩家可能短时间多次进出，体验不一致。
- **每tick直接推进时辰**：否决，30秒一个时辰太快，破坏沉浸感。

## Consequences

- 影响所有按时辰变化的功能（竹林入口、描述变体）
- 存档/读档需处理时间字段
- 渲染层需显示当前时辰
