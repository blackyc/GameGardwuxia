## 一、设计哲学「壁画深处」

> 石窟深处，烛火映在剥落的壁画上。一块金箔的反光让你看清了菩萨的
> 半张脸——另一半已褪成素泥。颜料层的边缘渗出石青和赭石的混合色。
> 你隐约觉得壁画下面还有另一层画，颜色在裂隙里藏着。

这个美学服务于游戏的三层罗生门叙事：

| 叙事层 | 视觉表现 | 对应 UI |
|--------|---------|---------|
| 表层 · 阳光武侠 | 金箔朱砂 · 经变画的辉煌 | 日常页面的暖壁 + 金线框 |
| 夹层 · 灵异渗入 | 壁画剥落 · 露出下层线稿 | 畸变值上升时页面出现朱砂渗线 |
| 深层 · 不可名状 | 颜料完全剥离 · 只剩素泥底 | 灵修专属视角（暗窟方案，另见冷调归档） |

- **石窟壁即基底**：暖窟壁面 `#2e1a10`→`#3d2415` 替代宣纸泛黄——不是纸面上的墨，是壁面上的矿物颜料
- **敦煌矿物色做信息层级**：朱砂红 = 地名/标题/战斗，石青 = 感知/道法，石绿 = NPC/友善，金粉 = 贵重/可交互
- **边框即藻井**：面板框用方形嵌套结构（outline + box-shadow + inset shadow），四角忍冬/莲花角花
- **质感先于装饰**：没有 noise overlay、没有 flicker、没有全屏粒子——壁面本身的剥落感足够

## 四、全局布局

### 4.1 移动端（≤767px）

```
┌──────────────────────────────────┐
│                                  │
│         [全屏页面区域]            │

│     (100vh - 底部导航高度)        │
│                                  │

│                                  │
├──────────────────────────────────┤
│  灯笼  │  剑   │ 背包 │ 地图  │ 人物  │  ← 底部导航条

```

- 底部导航固定在 `position: fixed; bottom: 0`
- 页面区域 `height: calc(100vh - 48px); overflow-y: auto`
- 当前选中 Tab 图标亮朱砂红，未选中灰烬灰
- 导航栏背景：陈墨黑 + 顶部 1px 老宣纸半透线

│  ┌──────────────────────────────┐ │                        │

- 底部导航放在左栏底部（非全局底部），切换右侧面板而非全页面
- 舆图在桌面端可展开为右栏全高

## 十四、实现注意事项

1. **T9.1 多页面架构**：5 个全屏 div 用 `display: none/block` 或 `visibility` + CSS transition 控制，不用路由
2. **T9.2 感知系统**：感知展开数据来自 `game.getRoomPerception()` 方法，返回通路/NPC/搜索点/交谈对象的完整对象
3. **T9.3 底部导航+操作栏**：导航是页面级（fixed bottom），操作栏是江湖页内组件（relative），两层独立 DOM
4. **T4.1 桌面双栏**：用 CSS Grid `grid-template-columns: 2fr 1fr` 实现，左侧固定江湖页，右侧 `data-page` 属性控制显示
5. **T9.4 过渡动画**：优先用 CSS transition/Animation，战斗遮罩可用 JS + Canvas 做碎裂粒子效果
6. **兼容经典回合制**：战斗遮罩同样覆盖经典回合制模式
7. **优先移动端**：先实现移动端单页全屏架构，桌面端双栏作为增强（`@media (min-width: 768px)`）
