# 诡仙录战斗系统 v3.0 — 异步CD + 真气双门禁 + 装备放大器

> 基于"师傅快出招 Demo"数据逆向 + 用户双门禁DPS理论 + 弈仙牌顺序出招骨架

---

## 一、设计哲学

**核心矛盾**：单门禁（真气）系统下，玩家脑算即可得出最优出招序列，build空间为零。

**解决路径**：引入双门禁（真气 + CD），使"每秒伤害(DPS)"成为非平凡优化目标。不同技能排列方式产生不同DPS，玩家需多次尝试才能找到最优套路。

**三段驱动循环**：
- 门派任务 → 获取高级武学（build组件）
- 外出游历 → 刷怪刷装备（build放大器）
- 探索地图 → 经历剧情（世界观投入 + 特殊奖励）

## 二、从"师傅快出招"提取的关键设计

### 2.1 数值架构

| 维度 | 师傅快出招数据 | 诡仙录借鉴方式 |
|------|-------------|-------------|
| 战斗单位基础属性 | maxHp(36-59) atk(1-3) def(0) spd(5.5-9.5) critProb(0) critRate(150%) dodge(1-15) hpReg(1) | HP/atk/def/spd同量级，critRate=150%暴击倍率基准 |
| 等级成长 | lvAddMaxhp(8-14) lvAddAtk(0.3-0.65) lvAddSpd(0.18-0.33) per level | 每级HP+10 atk+0.5 spd+0.25，15级为标准上限 |
| 技能skillNum | 0(纯buff) 1-3(轻击) 35-50(重击) | 基础伤害=skillNum × (atk + 武器加成) |
| 技能等级成长 | skillNumLvAdd: 0.3(轻)~15(重) | 每级+skillNumLvAdd，区分轻击成长低/重击成长高 |
| 异常状态层数 | du:1-6 bleed:2-10 burn:2-10 ice:3-6 | 同量级，层数叠加机制保留 |

### 2.2 异常状态体系（直接借鉴）

"师傅快出招"有4种异常状态，每种都有独立的伤害系数和触发机制：

| 异常 | 层数范围 | 机制（从BuffConfig逆向） | 诡仙录映射 |
|------|---------|----------------------|-----------|
| 毒(du) | 1-6层 | 回合开始受到stack点伤害，触发后-1层 | 毒——持续DOT，递减型 |
| 流血(bleed) | 2-10层 | 出招和回合结束受到stack伤害，触发后减半，新回合清除 | 流血——爆发DOT，衰减型 |
| 灼烧(burn) | 2-10层 | 火伤+stack（增伤标记） | 灼烧——易伤型，放大火系伤害 |
| 寒冰(ice) | 3-6层 | 冰系叠加，触发蒸发后清除 | 寒冰——控制型，触发蒸发后冻结 |

**新增**：
- 呆滞：减少目标速度（延迟出招）
- 易伤：受伤+stack（通用增伤标记，不限属性）
- 血爆：暴击后触发额外伤害

### 2.3 装备词条系统（关键借鉴）

"师傅快出招"的装备有18种词条（AttrCitiaoConfig），通过BuffId关联到buff效果，有stackMin/stackMax范围和qz（权重）。

**词条分类**：
- 攻击类：攻击+、暴击+、暴伤+、火攻+、飞弹+
- 防御类：近战防护、飞弹防护、闪避+、近战格挡
- 辅助类：治疗+、受疗+、血量+、蒸发+

**诡仙录改造**：词条改为"铭文"，武器/饰品可携带1-3条铭文，品质决定条数

### 2.4 姿态系统（直接借鉴）

4种姿态切换战斗节奏：
- 猛击姿态：近战伤害+X%，破格挡+X%，追击率+X%
- 瞄准姿态：远程伤害+X%，丢失率-X%，追击率+X%
- 防御姿态：前N回合受伤减免X%
- 均衡姿态：伤害+X%，受伤减免X%

**诡仙录改造**：姿态改为"架势"，由武器类型决定默认架势，饰品可切换

### 2.5 身份系统（直接借鉴）

21种身份提供常驻被动：
- 学徒：练功获取心得概率+15%
- 士兵：战斗经验+3
- 教头：近战格挡+4%，远程格挡+3%
- 屠户：刀伤害+2，流血伤害+1
- 酒者：物理减伤+1，暴击概率+5%

**诡仙录改造**：身份改为"出身"，创建角色时选择，提供初始build倾向

### 2.6 功法（belong > 0的技能）

功法是被动触发型技能，不占出招序列：
- 反击(belong:19)：被攻击后触发
- 追击(belong:19)：攻击后概率触发
- 火球术(belong:24)：火系攻击后追加
- 雪球(belong:26)：冰系攻击后追加

**诡仙录改造**：功法保留，作为宗门特色被动链

## 三、战斗模型 v3.0

### 3.1 双门禁模型

```
技能释放条件 = CD就绪 AND 真气充足
```

**门禁1：真气（MP）**
- 基础真气上限 = 80 + 等级 × 8（1级=88，15级=200）
- 真气恢复 = 战斗外每tick +5（武修）/ +4（灵修）
- 心法加成：每级心法 +2/tick
- 饰品加成：固定 +X/tick
- 技能消耗：轻击 8-15 / 中击 20-35 / 重击 40-60 / 辅助 10-25

**门禁2：CD（冷却时间）**
- CD单位：秒（实时异步战斗）
- 轻击 CD: 1.5-2.5s
- 中击 CD: 3.0-4.5s
- 重击 CD: 5.0-7.0s
- 辅助 CD: 4.0-6.0s
- **CD在技能释放后立即开始计时，不需要等当前技能动画结束**

**顺序出招约束**：必须打出上一招才能打下一招（弈仙牌骨架保留），但CD是异步的——你打出A后A进入CD，同时你可以等B的CD好了打出B。

### 3.2 为什么双门禁产生build空间

**单门禁（仅真气）**：
```
总真气 = 200
技能A: 40伤害/20真气 → 效率 2.0
技能B: 60伤害/35真气 → 效率 1.71
→ 永远选A，无脑堆A
```

**双门禁（真气 + CD）**：
```
总真气 = 200, 战斗时长 = 30s
技能A: 40伤害/20真气/1.5s CD → 30s内打20次但真气只够10次 → 400伤害
技能B: 60伤害/35真气/3.0s CD → 30s内打10次但真气只够5次 → 300伤害
技能C: 55伤害/30真气/2.0s CD → 30s内打15次但真气只够6次 → 330伤害
→ A+B交替: A(20真气)→等1.5s→B(35真气)→等3s→A... 真气消耗节奏不同
→ A+C交替: 更紧凑的CD但真气消耗更快
→ 最优排列需考虑：真气恢复速率 vs 消耗速率 vs CD间隙利用率
```

**结论**：双门禁下，不同技能组合的DPS差异可达30-50%，且无法脑算最优解。

## 四、战斗流程

### 4.1 战斗初始化

```
1. 读取玩家build：技能槽(5) + 武器 + 饰品 + 功法 + 出身
2. 计算最终属性：基础属性 + 装备加成 + 铭文 + 出身
3. 计算羁绊：扫描技能标签，激活对应羁绊
4. 设置初始真气 = maxMp × 0.5（半管开局）
5. 所有技能CD归零（开局可立即出招）
6. 生成敌人：从遇敌池选取，按区域难度调整属性
```

### 4.2 回合循环（异步CD + 顺序出招）

```
while (双方存活):
    1. 真气恢复tick：mp += mpReg（每0.5s结算一次）
    2. CD tick：所有技能cdRemaining -= dt
    3. 玩家选择下一个技能：
       - 必须等上一招打出后才能选下一招
       - 技能CD就绪 AND 真气充足 → 可选
       - CD未就绪 → 灰显
       - 真气不足 → 红显
    4. 执行技能：
       - 扣真气
       - 技能进入CD
       - 结算伤害（skillNum × atk + 武器加成 - 目标def）
       - 结算异常状态（施加层数）
       - 结算buff（自身/敌方）
       - 检查羁绊触发（概率再动/额外层数）
       - 检查功法触发（反击/追击/火球术等）
       - 检查装备特效（轻剑三连/重剑阈值等）
    5. 敌人AI行动（按敌方spd排序，异步CD）
    6. 异常状态结算：
       - 毒：回合开始受到stack点伤害，-1层
       - 流血：出招和回合结束受到stack伤害，触发后减半
       - 灼烧：火系伤害+stack%，不独立造成伤害
       - 寒冰：累计达到阈值触发蒸发→冻结1s+冰伤，清除层数
```

### 4.3 DPS计算示例

```
玩家：5级武修，atk=15，maxMp=120，mpReg=5/0.5s

build A：全轻击流
  技能1: 快剑 25伤害/8真气/1.5s CD
  技能2: 刺击 30伤害/10真气/2.0s CD
  技能3: 弹指 20伤害/6真气/1.5s CD
  技能4: 摩拳 15伤害/5真气/1.5s CD (附带力量+1)
  技能5: 防护 0伤害/5真气/3.0s CD (附带def+5)
  
  30秒内DPS ≈ (25+30+20+15)/8.5s × 真气利用率
  真气消耗: 8+10+6+5+5=34/轮，恢复5/0.5s=10/s
  → 真气不是瓶颈，CD是瓶颈
  → DPS ≈ 90/8.5 ≈ 10.6/s

build B：轻重混搭
  技能1: 快剑 25伤害/8真气/1.5s CD
  技能2: 劈山 60伤害/30真气/4.0s CD (流血+5)
  技能3: 刺击 30伤害/10真气/2.0s CD
  技能4: 毒掌 40伤害/20真气/3.0s CD (毒+4)
  技能5: 防护 0伤害/5真气/3.0s CD
  
  30秒内DPS ≈ 复杂排列
  真气消耗: 8+30+10+20+5=73/轮
  → 真气成为瓶颈，需要在CD间隙等真气
  → 但流血和毒伤提供额外DPS
  → DPS ≈ (25+60+30+40 + 流血~30 + 毒~20)/约12s ≈ 17.1/s
  
  结论: build B的DPS远高于build A，但build A更稳定（不依赖异常状态叠加）
```

## 六、驱动循环嵌套

### 6.1 核心循环

```
门派任务线 ──→ 高级武学(新技能/功法) ──→ build组件扩充
     ↓                                      ↓
外出游历 ──→ 刷怪掉装备(武器/饰品/铭文) ──→ build放大器强化
     ↓                                      ↓
探索地图 ──→ 剧情事件(NPC/世界观/特殊奖励) ──→ 新区域解锁+隐藏build
```

### 6.2 挂机与主动

- **挂机**：自动按当前build出招，打普通怪，掉落凡品/良品装备和少量真气
- **主动**：手动排列技能顺序，打精英/Boss，掉落上品/极品装备和技能书
- **竞技**：用build与其他玩家的build对战（异步PVP）

### 6.3 装备刷新逻辑

```
武器掉落 = 基础类型(区域决定) + 品质(难度决定) + 铭文(随机) + 特效(品质>上品时)

示例：
- 凡间区域 → 轻剑/重剑/长枪 + 凡品/良品
- 灵异区域 → 毒刃/火扇/冰针 + 良品/上品
- Boss掉落 → 随机武器 + 上品/极品 + 固定特效
```
