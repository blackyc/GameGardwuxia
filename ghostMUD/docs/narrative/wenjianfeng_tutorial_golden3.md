## 1. 设计原则

### 1.1 基调约束

- **轻松诙谐为主**：不做恐怖悬疑，不硬塞 L1 世界观
- **"家"的依赖感**：通过重复劳作 + NPC 情感反馈建立归属
- **常规武侠文字冒险**：玩家在前三章感知不到诡仙录的灵异维度，所有"不对劲"是背景非焦点
- **L1 信息差全部退为背景**：不解释？？？、不解释残剑不拔剑，玩家可以完全忽略
- **黄金三章节奏**：一次性走完不穿插 idle 等待

### 1.2 画饼理论（吃饼理论）

> 来源：`novel-narrative-analyzer/references/pie-theory.md`

| 概念 | 定义 | 游戏设计对应 |
|------|------|------------|
| **饼** | 最吸引人的一幕 | 玩家亲手操作残剑师姐打退"？？？" |
| **口味** | 刺激哪条认知天性 | 慕强——"我也要这么强" |
| **画饼** | 告诉读者"等着吃" | 老蔡："取药回来，教你一招" |
| **护饼** | 有人跟你抢饼 | 下山取药路上遇到阻碍 |
| **倒推** | 从高潮往前设计 | 打？？？←野猪引出←砍竹触发←劳叔让砍竹 |

### 1.3 每个剧情节点必须满足"画饼管线"

```
明确目标 → 可见奖励 → 抢饼的人 → 吃到正反馈 → 旧饼吃完立刻引新饼
```

## 5. 第一章·上山

> **时长**: ~30分钟（阅读+操作）  
> **饼**: 建立"家"的初步印象  
> **口味**: 归属感  
> **操作教学**: 移动、观察环境、NPC初识  

### 5.1 开场

```
                        《诡仙录》
                  ——问剑峰·新手引导——

    你站在山脚下。一条青石阶蜿蜒入云。
    石阶很老了——有些台阶缺了角，有些长了青苔。
    但中间那一道被踩得很光。千百双脚走过的痕迹。

    「新来的？」
    一个声音从上面飘下来。
    苏小棠坐在第十三级台阶上，两条腿晃荡着看你。
    笑得一点也不像第一次见面。
```

### 5.2 剑阶·苏小棠

**场景**: 山门至剑阶，13级台阶

**苏小棠对话**:
```
「你也是来练剑的？太好了——这山上终于有比我晚来的了！」
「我叫苏小棠。来了一年半。暂时还打不过周碛——」
「——但是快了！真的快了！你先别笑——」
「……你叫什么名字？」
```

→ **玩家输入姓名**（游戏起始界面已输入，此处可以是确认/微调）

```
「名字还行。」她站起来，拍了拍衣服上的灰。
「走吧，我带你去见萧师叔——」
她走了两步，又回头。
「对了。山门口的值星会问你口令。今天的口令是「残月」。」
「记住了？」
```

### 5.3 山门·值星弟子

**场景**: 山门牌坊下

```
「口令！」
一个年轻弟子站在牌坊下面。剑横在身前。
苏小棠抢在你前面：「残月。」
值星弟子收了剑。「小棠姐。」看了一眼你。「新师弟？」
「比你早半个月！」苏小棠推着你往里走。

（从牌坊下穿过时，你注意到门楣上刻着两个字：「问剑」。
字迹很老了。被风雨磨去了棱角。
但每一笔都像是用剑尖刻的。）
```

### 5.4 门派巡礼（移动操作教学）

**此次巡礼由苏小棠领路**。每到一个区域，玩家学习一个移动方向指令。

```
苏小棠转过身，倒着走，一点都不怕摔。
「先把地方认一遍。跟着我——」
「前面是剑坪。除了吃饭睡觉，基本都在那。」
「左边——伙房。老蔡做什么都好吃。他要是凶你，你别怕——他凶谁都那样。」
「往上——洗剑池。剑用完了去洗。池子里有几把断剑，别碰，会被骂。」
「右边那条小路——后山竹林。劳叔在那，他话少。但是人是好人。和铁牛一样好。不要跟铁牛比力气。你比不过他。周碛也比不过。没人比得过。」
「往上那条岔路——药圃。阿青在那。她认识很多草——但是更多是她以为她认识。」
「最高的地方——剑冢。那是剑翁的地盘。他不下山吃饭。老蔡会送。以后可能轮到你送。」
「哦对了——我们住弟子房。你跟我住隔壁。周碛住对面。阿满住对面隔壁。」
```

> **操作**: 每到达一个区域，系统提示 "你学会了【往北走】/【往南走】等"，玩家跟随苏小棠移动。

### 5.5 配角台词（一句话认识所有人）

#### 路过剑坪
```
残剑师姐正在剑坪中央站着。剑未出鞘。她的姿势一动不动，
像一尊石雕。苏小棠放慢了脚步。
「残剑师姐——」她小声叫你：「你不用跟她打招呼。她不一定理你。但是别怕她——她只是不爱说话。」
走近时，残剑师姐微微点了一下头。
苏小棠瞪大了眼睛。
「她对你点头了？？？她对我点了半年才点头！！！」
```

#### 路过伙房
```
老蔡从灶台后面探出头。锅铲还在手里。
「新来的？——晚饭有你一份。别迟到。」
苏小棠小声：「他在跟锅铲说话还是跟我们说话？」
老蔡：「我都听见了。」
```

#### 路过药圃
```
阿青蹲在地上，拿树枝戳一条蛇。
「你走不走？你不走我采错草了你负不负责？」
看见你们路过，她抬头：「新师弟？——你认识蛇胆草吗？」
苏小棠拉着你走了。「不认识。走。」
```

#### 路过竹林
```
劳叔没抬头。
「新来的。」
「嗯。」
劳叔手里削竹丝的速度一点没变。「你走偏了。左脚往左三寸——那根竹子我留着做剑鞘的。」
你没碰到那根竹子。但你还是挪了一步。
苏小棠：「他怎么知道的——他在看你吗？他是不是在看你？他明明没抬头——」
劳叔还是没抬头。
```

#### 路过藏剑阁
```
门口坐着一个老人——在打盹。
苏小棠拉了你一把：「别吵他。虽然吵他也不会醒——但万一醒了呢。」
老人还是没动。
```

#### 路过剑冢
```
最上面。一片空旷的空地。插满了断剑。
有的剑只剩一截，有的锈得看不出形状。
还有一个独眼老人——坐在一把最大的断剑后面。

剑翁抬头看了你一眼。又看了一眼苏小棠。
「多了。」
苏小棠：「剑翁，这是新来的师弟——」
「我知道。」剑翁闭上了眼睛。「回去的时候别踩着剑。」
```

### 5.6 弟子房·分配宿舍

```
苏小棠把你领到一排木屋前。
「这是弟子房。你住这间——我住隔壁。周碛住对面。阿满住对面隔壁。」
「东西放好。晚饭还有半个时辰——你可以到处逛逛，也可以等着。」
她走了两步又回来。
「对了——老蔡要是给你加菜，你得分我一半。」
```

> **自由活动阶段**: 玩家可以在门派内自由移动（实际可去区域：剑坪、伙房、洗剑池、剑阶。藏剑阁和剑冢暂不开放）。每个区域有一个 NPC 可以说一句话。此为"观察环境"操作练习。

### 5.7 晚饭·老蔡的红烧肉

```
伙房里挤满了人。老蔡一个人在灶台后面忙，锅铲翻飞。
铁牛在搬碗筷。小荷在盛饭。

老蔡给你盛了一碗——碗底藏了一块红烧肉。
「昨天剩的。别跟别人说。」
苏小棠从你碗里夹走了半块。
「你说得分你一半的。」
周碛从对面看过来：「新来的都能分肉？老蔡你偏心。」
老蔡：「你上周偷吃了我三块肉。记账的。」
```
> 全体哄笑。周碛嘟囔了一句，继续吃饭。

## 6. 第二章·入门

> **时长**: ~45分钟  
> **饼**: 见残剑师姐打"？？？"，体验高级武学  
> **口味**: 慕强——"我也要这么强"  
> **操作教学**: 点击练功、体力管理、战斗系统  

### 6.1 清晨·剑坪·晨练

```

天还没亮透。剑坪上已经响起了脚步声。

萧远站在前面——一个看起来四十岁出头的中年人。
他的剑斜背在背后。剑柄上缠的布很旧了。
「新来的。」

所有人对齐。苏小棠在你左边，周碛在你右边。
「今天学两式。起式。承式。」
「看一遍。」
他没有慢动作。但你清楚地看到了——
不是看到剑。是看到剑过去之后空气还在一会儿后才跟上。
「练。」

【系统提示：行功图——起式+承式，两招排列】

玩家选择：起式→承式  /  承式→起式（尝试不同排列）
```

#### 苏小棠的失误
```
旁边传来一声闷响。苏小棠的剑气偏了三分——擦着她的肩膀飞过去，
打在地上，扬起一片土。
「啊啊啊——对不起对不起——」
萧远看了她一眼。「起式的时候左脚多迈了半步。承式追不上你。」
苏小棠：「我再试一次——」
周碛在旁边冷冷地：「就你这样的还敢教新人？」

苏小棠的脸红了。
```

> **操作**: 玩家练习行功图排列，直到萧远说"可以了"。此处为"点击练功"（选择招式排列→看战斗效果）的入门版。

### 6.2 上午·挑水

```
萧远收了剑。「上午的课完了。去伙房帮忙。」
周碛已经走了。苏小棠还在练那一式——这次似乎对了。

你去洗剑池挑水。
盲眼老妪坐在池边。她没看你。但她开口了。
「今天的水比昨天冷。池底的剑又多了一把。」
你往池里看——看不清。水太暗了。
老妪：「不用找了。新来的看不到的。」
```

> **操作**: 从洗剑池挑水到伙房。学习移动+体力管理（挑水时行动速度略微下降）。

**路上遭遇周碛**:
```
石阶上。周碛从上面走下来。
看见你挑着两桶水，他笑了。
「挺勤快嘛——」
经过你身边的时候，他肩膀一歪。
不重。刚好够碰掉你的平衡。
半桶水泼了出来，湿了一地。
「哎呀。不好意思。」
他头也不回地往下走了。
「你自己跟老蔡说。」

老蔡看到半桶水。叹了口气。
「又是他。」
「半桶也够。下次——你撞回来。」
他看了你一眼。那个眼神不像是开玩笑。
```

### 6.3 下午·砍竹

```
后山竹林。劳叔在削竹丝。

他把砍刀递给你。很沉。
「不着急。砍完就行。」

点击速度 = 砍竹速度。每根竹子需要 3-5 次点击。
```

**砍到第七根的时候——**
```
竹林深处一阵闷响。不是风。
劳叔手里的竹丝停了。
「……退后。」

一头黑鬃野猪从竹林中撞了出来。
不是普通野猪。它的眼睛不对——不是猪的眼睛。
它盯着你。
獠牙比你的剑还长。
```

### 6.4 野猪战斗

```
劳叔后退了一步。
「这东西偷吃竹笋的——但从来不会对人冲。」
「别慌。它比你快，但你没比它笨。」

【系统提示：战斗开始】
【敌人：黑鬃野猪】
【血量：正常 / 攻击：中等 / 速度：快】

（首次实战教学：
- 格挡：减少伤害
- 闪避：完全躲避
- 出剑：起式+承式连击
- 注意体力：连续攻击后需喘息）
```

**战斗产出的两种结果**:

**结果A·胜利**（玩家正常发挥）:
```

苏小棠从远处跑来：「你没事吧——」
```

**结果B·被撞倒**（玩家失误/血条击穿）:
```
野猪撞在你胸口——你直接飞了出去，摔在竹子上。
疼。
但你没死。那头野猪没有继续冲——它不知道为什么停住了。
劳叔一刀砍在它后腿上。野猪嚎叫着跑了。
「——回来！别追——」
你的胸口像裂开了一样。但你能站起来。
然后你听到了一声极轻的落地声。
残剑师姐不知道什么时候站在你旁边。
她什么都没说。扔给你一瓶金疮药。走了。
苏小棠哭着跑过来：「你被猪拱了——我不是在笑我真的不是在笑——」
```

## 7. 第三章·守夜

> **时长**: ~25分钟  
> **饼**: 老蔡画饼——取药→教招→打败周碛  
> **操作教学**: 跨区探索、放置等待、深度对话、物品管理  

### 7.1 老蔡的画饼（核心转折）

```
夜深了。伙房里只剩三个人——你，老蔡，还有灶台上留给守夜人的那盏灯。

老蔡背对着你洗碗。水声一下接一下。
「今天的猪是你打的。」
「嗯。」
「最后那个东西——」他停了一下。碗放下来。
「不是猪。」
「……我知道。」

老蔡转过身来。火光映在他脸上，表情和平时不太一样。
不是笑嘻嘻的伙房厨子。
那不是一张厨子的脸。但只有一瞬。他又笑了。

「剑翁腿上的旧伤——每年这个时候疼得最厉害。
药快没了。
你帮我去应天府回春堂跑一趟。」
他把一张折得发黄的药单推到你面前。「钱够。」

「你把药带回来——」他擦了擦手。
「——我教你一招。」
「不是什么高深武学。
但是你学会了——
下次周小子撞你的时候，」
他笑了一下。
「你能让摔的不是半桶水。是他自己。」

那张药单很旧。纸都发黄了。上面是三种药材——
你看不太懂。但你记住了老蔡最后那句话。
```

> **玩家获得物品**: [老蔡的药单] — 任务物品  
> **任务激活**: [支线·老蔡的药单] — 去应天府回春堂取药，限时7天（下山试的官方理由）  

### 7.2 第四天晨·萧远的嘱托

```
第四天清晨。剑坪。萧远已经在等着了。

「今天你下山。」
你一愣。
「是下山试。问剑峰的传统——每个入门弟子都要独自下山，
去应天府完成一件事。
老蔡的药单——就是你的下山试。
七天内回来。」
他从怀里取出一枚小小的令牌。木质。刻着一把剑。
「这是你的弟子令牌。在山下遇到麻烦，拿去给官府看。
不保证有用——但至少不会把你当流民抓起来。」
他把令牌放在你手里。
「去吧。」
转身走了一步又停住。
「回来的时候——教你第三式。转式。」
他头也没回。
```

### 7.3 NPC 告别（"家"的建立——三件小事）

#### 阿青
```
药圃。阿青正在翻土。看见你来，站起来拍拍手。
「你要下山？」
「嗯。」
「顺路的话，帮我去回春堂看看有没有蛇胆草的种子——没有就算了。」
她把一张纸条塞给你。上面歪歪扭扭画着一棵草——但更像一只三条腿的鸡。
「画的不像——但他们看得懂。应该。」
```

#### 小荷
```
伙房。小荷从灶台后面探出头。
「老蔡说你要去买药——」
她从围裙口袋里掏出一个油纸包。
「给你。早上新蒸的馒头。路上吃。」
纸包还是热的。
```

#### 藏剑阁老
```
藏剑阁门口。阁老和往常一样——在打盹。

你从他面前经过。他忽然开口了。
「左边第三排。最上面。那本剑谱。」
你愣住。他从来没跟你过话。而且他闭着眼。
「不是给你的。你给谁就行。你以后会给谁谁再给谁——总会有人要的。」
「带上。」
一本薄薄的册子。封面上什么字都没有。
「去吧。别让我睡着的时候想起你还没走。」
```

#### 剑翁
```
剑冢。剑翁站在最高的那把断剑前面。
「昨天那个东西——」他没看你。「以后还会来。」
你等着。
「她还能挡几次。」剑翁的声音很轻。「几次之后——就不一定了。」
他回头看了你一眼。
「别怕。那是以后的事。」
「下山去吧。」
```

#### 周碛
```
石阶上。周碛背对着你，正在往下走。
听见你的脚步声，他没回头。
「七天内回不来，我去找。」
「不是我关心你——老蔡的药不能丢。」
走了两步。
「山门口靠右走。左边那条石阶松了——上次我摔过。」
他把剑鞘在地上顿了顿。「别跟人说是我说的。」
```

#### 苏小棠
```
山门口。苏小棠已经等在那了。
「你怎么这么慢——」
她手里攥着个什么东西。犹豫了一下，塞给你。
平安符。红色的。上面歪歪扭扭绣着两个字：「平安」。
「我自己绣的。别细看——字太丑了。」
她看着你，突然就不笑了。
「早点回来。」
然后她把山门推开了。
「应天府的糖葫芦——两种馅的都要！」
```

#### 残剑师姐
```
你走出山门。回了一次头。

剑坪上，残剑师姐还在那。
和每一天早晨一样——手按在剑柄上，面朝剑冢。
她没有看你。但她站的位置——
你走了之后再回头看的时候，她还在那。

你低头系了一下鞋带。
鞋带上面多了一圈绑腿布——不是你系的。
那种卷法你没见过。但你觉得如果残剑师姐要绑，大概就是这样绑的。
```

### 9.2 关键对话分支

```
野猪战斗结果 → 分支A（胜利）/ 分支B（被撞倒）
  ├─ 分支A: 苏小棠崇拜 / 周碛沉默吃肉 / 全门派加餐
  └─ 分支B: 残剑送金疮药 / 苏小棠哭着笑 / 周碛拿着剑跑来
  
老蔡夜谈 → 强制触发（只要野猪战斗已完成）
  └─ 不接受药单？→ NPC不强制但第二天萧远会补上"下山试"框架

守夜 → 与剑翁的对话深度取决于玩家是否主动追问
  └─ 追问一次 → 剑翁说"她每年都去"
  └─ 追问两次 → 剑翁说"几年后就不是她去的事了"
  └─ 追问三次 → 剑翁说"别问了"
```
