## 一、设计哲学「石窟暗面」

> 石窟深处。岩壁只剩暗灰冷光。壁画在头顶高处残留一角石青色。
> 你不是在石窟入口的阳光里，你在石窟最深处——这里没有金箔反光，
> 只有矿物颜料渗进石壁后沉淀下来的颜色。

- **石窟暗面基底**：暗岩灰 `#13100e`，不是虚空黑，是「物质的实在感」
- **矿物色边框**：石青/石绿/金粉/朱砂——只在边框和强调文字上使用
- **藻井嵌套结构**：面板用多层 box-shadow + outline 模拟敦煌藻井的方形嵌套
- **壁画面纱**：右下角飞天残片剪影，opacity 0.06
- **统一冷调基底**：所有填充色 L 值控制在 6-12，色相偏冷灰，页间不跳色

## 七、与暖窟方案的核心差异

| 维度 | 冷窟（本方案） | 暖窟（当前采纳） |
|------|--------------|----------------|
| 基底色 | `#13100e` 暗岩灰 | `#1a0f08→#3d2415` 暖壁 |
| 氛围 | 冷峻克制的石窟深处 | 金箔朱砂的经变画窟 |
| 金粉占比 | 边框点缀 | 边框为主，更富丽 |
| 石青/石绿权重 | 镇场冷色 | 辅助冷色，调亮 |
| 朱砂比重 | 战斗/危险强调 | 每页均可做主框色 |
| 视觉温度 | 偏冷，距离感 | 偏暖，沉浸感 |
| 适合语境 | 灵修视角 / 畸变恶化 | 表层武侠 / 凡界叙事 |
