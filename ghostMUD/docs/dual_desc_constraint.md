# Ghost MUD v2.0 · 双描述系统转化约束（全Agent共享）

> 版本: v1.0 | 2026-06-21 | 约束所有rebuild改写Agent

## 一、目标

将全部rebuild文件中每个`desc`字段拆为双版本：
- **`desc`**：筑基前（realm 0~1），主观不确定表述，60+种标记随机选用
- **`desc_awakened`**：筑基后（realm ≥2），主观确定性表述，砍除"不是X"句式

---

## 二、R1：消除"不是X而是Y"句式

### 2.1 匹配模式
```
不是X，而是Y  →  砍掉X，保留Y
不是X，是Y    →  砍掉X，保留Y
并非X，而是Y  →  砍掉X，保留Y
不像是X      →  替换为推测性结论
不似X        →  替换为推测性结论
那不是X      →  砍掉X前半
```

### 2.2 具体替换
| 旧句式 | desc（筑基前） | desc_awakened（筑基后） |
|--------|--------------|----------------------|
| 不是木纹，是细密的刻痕 | …摸着像是某种刻痕，也许是刀尖刻的 | …不是木纹，是细密的刻痕 |
| 不像是风吹的 | …谁知道怎么断的，断口齐得蹊跷 | …不像是风吹的。那是里面的东西在拨弄 |
| 不是石头的味道，是「空」的味道 | …似乎有种说不清的空寂气息，很难形容 | …不是石头的味道，是「空」的味道 |
| 不是看见，是感觉到 | …也许是感觉到，而非亲眼看见 | …不是看见，是感觉到 |
| 不是轻，是在瓶壁上贴成了画 | …看着像是在瓶壁上自己贴成了简笔画，也许是错觉 | …不是轻，是在瓶壁上贴成了一幅简笔画 |

## 四、R3：desc_awakened 确定性版本

`desc_awakened` = 当前desc去除R1的"不是X"部分 + 去除全部R2主观标记 → 纯确定性表述。

主角筑基后"看世界不一样了"——所有诡异都能自信确认是真的。因此：
- ✅ `desc_awakened` 允许"不是X而是Y"句式
- ✅ `desc_awakened` 允许"是"、"那是"、"正是"等确定性系词
- ❌ `desc_awakened` 禁止R2表中的任何主观标记

---

## 五、R4：修辞丰富性要求

### 5.1 禁止连续复用
同一文件中连续3条`desc`不能使用同一标记类型。必须交替使用视觉推测 / 传闻引用 / 时间限定 / 触感推测等。

### 5.2 主语多样性
避免始终以"你"为感知主语。穿插使用：
- 无主句："隐隐约约，像是…"
- 泛指主语："路过的人常觉得…"
- 环境主语："风吹过时，仿佛…"
- 物品主语："那根柱子，看上去像是…"

### 5.3 句法多样性
交替使用：
- 前置标记：`听人说，这棵树…`
- 中置标记：`这棵树，据老人说，…`
- 后置标记：`这棵树的影子很长——也许是错觉。`
- 反问式：`谁知道那影子是不是比别的长一截？`

### 5.4 句式长短交替
避免每句都套模板。有些desc直截了当：
```
'远远望去，这巷子只是条寻常的死胡同。但打更人说，他曾在子时见过巷底多了一道门。'
```
vs 长句铺陈：
```
'这条巷子青砖墁地，两侧高墙夹道，墙上爬满了枯藤——乍一看是枯藤，凑近了才发觉那些藤条在砖缝里生了根，根须钻进墙里，不知钻了多深。'
```

## 六、R5：不可变项

| 字段 | 是否修改 |
|------|---------|
| `connections` / `danger` / `hp` / `atk` / `def` / `exp` / `gold` | ❌ 不动 |
| `type` / `realm` / `faction` | ❌ 不动 |
| NPC的 `id` / `name` / `dialogue` | ❌ 不动 |
| NPC的 `desc` | ✅ 加双版本 |
| 房间内items的 `id` / `name` | ❌ 不动 |
| 房间内items的 `desc` | ✅ 加双版本 |
| `events[]` 数组 | ❌ 完全不动 |
| `interaction` 字段 | ❌ 不动 |
| `result` 字段（氛围物品） | ✅ 如有"不是X而是Y"则加双版本 |

## 七、R6：STYLE 60/30/10 不变

- 60% 诡异暗示（不可名状的异常细节）— 仅R2主观标记降低确定性，异常内容本身不减
- 30% 武侠白描（场景、动作的精准描写）— 不变
- 10% 聊斋话本感（口语化、市井味、说书腔）— 传闻引用类标记天然增强此比例

## 十、输出规范

### 文件格式
直接覆写原文件，保持原有`const XXX = { ... };`结构不变。
仅替换每个`desc`为`desc + desc_awakened`双字段。

### NPC desc 也加 desc_awakened
```js
npcs: [
  { id: 'xxx', name: 'xxx', 
    desc: '看着像是个…', 
    desc_awakened: '一个…',
    dialogue: '…' },
]
```

### events 完全不动
```js
events: [
  '一个挑着糖人担子的老汉从东大街走来…',  // 原文不动
]
```

### 验证要点
- [ ] 每个对象有`desc`和`desc_awakened`两个字段
- [ ] `desc`中无无修饰的确定性"是"（纯白描场景如"吆喝声混成一片"除外）
- [ ] `desc_awakened`中无任何R2主观标记
- [ ] 结构字段（connections/danger/hp/atk等）完整保留
- [ ] JS语法正确（逗号、引号、括号全匹配）
- [ ] 字符数膨胀不超过30%
