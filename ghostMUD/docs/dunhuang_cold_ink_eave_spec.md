**版本**: v3.0-冷墨飞檐
**日期**: 2026-06-24
**关联 Demo**: `cold_ink_eave_demo.html`（workspace）
**关联规范**: `ui_color_border_spec_v2_20260624.md`

---

## 一、设计哲学「檐下读卷」

> 深夜，灯盏将尽。你在屋檐下翻一卷残书。墨迹深浅不一。
> 抬头能看到一角飞檐——冷峻的剪影嵌在墨蓝的天幕里。
> 翻页时，并不是纸在翻，是两团祥云合拢又散开，像有人在云后换了一张桌案。

- **檐下即界面**：右下角永远是那角飞檐剪影——不喧宾夺主，但总在你余光里
- **翻页非切换**：左右祥云合拢（0→400ms），在云后更新 DOM（400→700ms），云散开露新页（700→1100ms）
- **冷墨为骨**：所有基底色 L 值 5-12，统一冷调（色相偏蓝/紫/灰，不含暖色），页间不跳色
- **边框分区**：每功能区分独立边框色 + 角花，信息层级通过边框颜色传达，不是背景色

## 六、全局装饰元素

### 6.1 飞檐剪影（右下角）

- 位置：`position: fixed; bottom: 0; right: -5%`
- 尺寸：`width: 38vw; max-width: 320px; height: 30vh; max-height: 250px`
- 透明度：`opacity: 0.07`
- 交互：`pointer-events: none` 不阻挡点击
- 边缘：`mask-image: radial-gradient` 柔化边缘
- **原型实现**：纯 CSS（`linear-gradient` + `radial-gradient` 叠加模拟飞檐结构）
  - 檐顶斜线：`linear-gradient(-15deg, ...)`
  - 檐角上扬：`linear-gradient(-35deg, ...)`
  - 檐下阴影：`linear-gradient(0deg, ...)`
  - 瓦当：多个 `radial-gradient(ellipse ...)` 模拟瓦当圆点
- **正式版素材**：AI 生成纯黑剪影 PNG → 去底透明 → 替换 CSS 实现
- **生成提示词**：`纯黑剪影、中式古建筑飞檐翘角、单层檐、檐角微翘、极简、无背景、右上视角向下俯拍、黑色填充、白色背景、线条干净利落`

### 6.2 祥云转场

**时间线**：
```
0ms      → 左右云 translateX(-110%) / (+110%) 开始滑入
400ms    → 云合拢覆盖全屏（中间留 1-2px 暗缝）
400-700ms → 云保持合拢态，在遮罩下执行 DOM 更新
700ms    → 左右云向外滑出
1100ms   → 云完全退出，新页面露出 → 移除云层
```

**CSS 核心**：
```css
.cloud-left, .cloud-right {
  position: fixed; top: 0; z-index: 200; pointer-events: none;
  transition: transform 0.4s cubic-bezier(0.4, 0, 0.2, 1);
}
.cloud-left  { left: 0;   width: 55vw; height: 100vh; transform: translateX(-110%); }
.cloud-right { right: 0;  width: 55vw; height: 100vh; transform: translateX(110%);  }
.cloud-left.active  { transform: translateX(0%); }
.cloud-right.active { transform: translateX(0%); }
```

**JS 控制流**：
```js
async function pageTransition(toPage, updateFn) {
  left.classList.add('active');
  right.classList.add('active');
  await sleep(450);
  updateFn();
  await sleep(50);
  left.classList.remove('active');
  right.classList.remove('active');
  await sleep(450);
}
```

**性能**：`transform: translateX()` 仅触发 GPU composite，不触发 layout/paint。移动端 60fps。

**素材规格**：
- 格式：PNG（透明背景）或内联 SVG
- 左云：宽 ~55vw，右云：宽 ~55vw，高度均 100vh
- 云团颜色：`#1a1522`（与导航栏底同色）+ 微透明边缘
- **原型实现**：手写内联 SVG path（`ellipse` 堆叠云团轮廓，冷墨紫灰底色）
- **正式版素材提示词**：`中国传统工笔祥云、灰黑色墨染、云团饱满边缘自然不规则、白色背景、单朵云、适合做UI遮罩`

## 十二、视觉连贯性自查清单

每加一个新功能/新页面，问三件事：

1. ❓ 填充色的 L 值在 5-12 之间吗？（不在→改）
2. ❓ 填充色是冷调吗？（偏红/偏橙/偏黄→改）
3. ❓ 高饱和色只出现在文字/图标/border上吗？（出现在大面积填充→改）
