## Phase 8：双修体系 —— 武修/灵修分流 🔴 前置依赖（影响 Phase 0-1-2-6）

### 8.0 决策总纲 — 不分不统，双轨并存

武学与修真分化为两条玩家路径，共享同一个世界但看见不同深度的真相。

| 维度 | 武修（Martial Path） | 灵修（Spiritual Path） |
|------|---------------------|----------------------|
| **初始进入** | 初始6武修宗门可选 | 初始6灵修宗门锁定（预留接口，暂不开放） |
| **转职进入** | 隐藏剧情拜入对应灵修宗门 / 挖掘宗门灵修往事 | — |
| **境界上限** | 天人（=大宗师，元婴级） | 化神（高一级） |
| **战力** | 同级弱灵修~20% | 同级明显更强 |
| **道心风险** | 几乎不跌（仅特殊事件扣） | 从炼气起持续缓慢下跌 |
| **修炼曲线** | 平稳安全，有天花板 | 高风险高回报，走钢丝 |
| **货币** | 金银铜（凡间体系） | 灵石（修士体系） |
| **术语风格** | 武学（剑法/内功/真气/内力） | 修真（剑诀/心法/灵气/灵力） |
| **叙事认知层** | 三层递进——凡人~武师只能隐约觉察，宗师可看穿表象，天人明确知道界限 | 二层——炼气起即可灵视，元婴后完全看清 |
| **野外遇敌** | 仅遭遇 野兽 / 妖 / 邪 / 精怪（无鬼、无人祸） | 遭遇全部类型（含鬼、人祸） |

**核心诡计**: 当下12宗门中，6个是以武修面貌存在的**堕落灵修宗门**（曾发生人祸：宗主邪变→宗门遭大劫→幸存者封印灵修传承以武修重建），另外6个是幸存下来的隐世灵修宗门。同一个世界，武修看见"巷子里好像有东西"，灵修看见"那是界隙——它们在往外渗"。

### 8.2 武修三层认知递进（叙事核心）

同一扇门、同一条巷子——取决于你的境界，看到的东西不一样：

```
【旧烟馆，门缝里渗出微光】
凡人/练家子 → "里面大概住着人。也许是烛火。也许该走了。"
武师        → "烛火不会闪成这样的节奏。太规矩了——规矩得像在写字。"
宗师        → "门缝里不是烛光。是某种冷光，很淡。有人在里面——但不管是谁，进去的人出来以后都不太对了。"
天人        → "你不需要进去。你在门外已经'看见'了——那是灵脉被强制划破后残余的灵气泄露。里面的不是人。至少现在不是了。"
```

不是"非A而是B"的AI句式——武修的三层是通过**描述精度递进**来体现认知变化：
- 低境界：主观不确定（"大概/也许/似乎/像是"）
- 中境界：物理观察升级（"节奏不对劲/颜色不太对/不像XXX"）
- 高境界：确定性描述，但**不使用修真术语**——武修不认识灵气/灵脉/界隙等概念，只用自己的语言描述

**三重描述字段**:
```js
// 房间数据新增字段
desc_vague:   '里面大概住着人。也许是烛火。'                    // 武修 realm 0-2
desc_percept: '烛火不会闪成这样的。太规矩了——规矩得像在写字。'  // 武修 realm 3-4（宗师~天人）
desc_awakened:'门缝里不是烛火。是灵脉被划破后残余的灵气。'      // 灵修 realm 1-5（炼气+ 灵视）
```

**引擎层 getDesc(obj)**:
```js
if (state.path === 'ling' && state.realm >= 1) return obj.desc_awakened;
if (state.path === 'wu' && state.realm >= 3) return obj.desc_percept;
return obj.desc || obj.desc_vague;
```

### 8.3 道心机制差异化

#### 武修道心
- **不随修炼时间自然下跌**
- 仅在以下情况扣除：
  - 进入高灵异区域（某些副本/荒野深处）→ -1~3
  - 与精怪/邪战斗 → 战后 -2~5
  - 目睹特定诡异事件 → -3~8
  - 使用了不该用的东西（黑灵石等）→ -5~15
- **恢复**: 回城/寺庙/宗门打坐
- **道心归零**: 武功尚在，精神崩溃。"你不再出门了。墙上的影子越来越多。某天门开着——人已经不在了"

#### 灵修道心
- **从炼气起持续缓跌**: 每N tick -1
  - 炼气/筑基: 每30 tick -1
  - 金丹/元婴: 每20 tick -1
  - 化神: 每10 tick -1（加速）
- 额外扣除同武修（且灵修看得更清楚 → 部分事件扣2x）

### 8.6 双路径转职系统

#### 路径A：散修 → 灵修（通用路径）
- 条件：散修 + realm≥2（武师级）+ 触发暗巷引路人奇遇
- 流程：5步任务链——暗巷引路人→睁眼(道心-15)→第一次灵视→选择→转职
- 转职后：无宗门归属，灵修散人

#### 路径B：武修宗门弟子 → 灵修（宗门往事路径）
- 条件：宗门弟子 + realm≥3（宗师级）+ 触发宗门"人祸遗物"奇遇
  - **宗师才能看见遗物异常**——凡人~武师在遗物旁边只能感到不适，无法触发交互
- 流程（5步）：
  1. 在HQ深处发现遗物——宗师能感知到遗物上"不该属于这个世间的存在感"
  2. 触碰遗物→触发记忆碎片——展示人祸当天的场景
  3. 发现真相：宗门本为灵修→人祸→封印灵修传承→以武修重建
  4. 选择：封印遗物（留武修）/ 继承遗物（转灵修，道心-20）
  5. 继承后：自动拜入宗门的"灵修前身"，继承部分灵修技能
- 转职后：宗门标签变为 `[原宗门名]·灵脉`

#### 路径对比

| 维度 | 散修→灵修 | 宗门→灵修 |
|------|----------|----------|
| 触发境界 | 武师(realm=2) | 宗师(realm=3) |
| 道心冲击 | -15 | -20（发现宗门血腥真相） |
| 归属 | 无宗门 | 原宗门·灵脉 |
| 技能继承 | 从零修炼灵修技能 | 继承宗门灵修前身的部分技能 |
| 回退 | 不可 | 不可 |

### 8.7 野外遇敌按路径分层

```
武修遇敌池（仅四类）
  ├── 野兽: 山狼/毒蟒/棕熊/夜枭……（纯物理，无道心损耗）
  ├── 妖: 狐妖/蛇妖/树精……（道心-1~2）
  ├── 邪: 邪祟/阴煞/怨灵……（道心-2~4）
  └── 精怪: 石精/镜魅/火灵……（道心-2~5）

灵修遇敌池（全部五类 + 人祸）
  ├── 野兽/妖/邪/精怪（同上，扣更多道心）
  ├── 鬼: 饿鬼/厉鬼/摄魂鬼……（道心-3~6）
  └── 人祸: 异化修士/邪变宗主/灵脉畸变体……（道心-5~10）
```

**实现**: `getEnemy(location)` 按 `state.path` 从不同池中抽取。鬼与人祸仅灵修可见——武修在地点描述中可能感知到"空气格外沉重/战斗时有不该有的寒意"，但不会遭遇。
鬼与邪的区别，邪需要附体，而鬼可以直接独立存在。因此武修可以遭遇并攻击邪，而不可遭遇并攻击鬼。

### 8.8 交集任务：罗生门式信息差

当武修与灵修处理"同一个事件"时，双方看到不同的东西。

**范例：城外庙里的哭声**

```
武修接到: "城外破庙夜夜传出哭声，怀疑山贼藏匿，需去查看。"
NPC:      "那庙荒了很久。近来总有人听见哭声——大概是山里风声作怪。你们练武之人去走一趟，赶走就是了。"

武修实际看到:
  凡人~武师: "庙里空无一人。但神像背后的墙上有痕迹——不太像人抓的。也许是野兽。"
  宗师:       "墙上不是野兽痕迹。是指甲——沟槽太深，不是人能做到的。神像的眼睛在看你。那是死木，不该有目光。"
  天人:       "神像眼睛里有东西——你已经开始后悔了。"

灵修实际看到:
  "庙里不是空的。神像背后坐着一个女人——她没有脸，但确实在哭。哭声不是从喉咙出来的，是从墙上抓痕里渗出的灵气在震荡。她在等人——不是等你，是等一个她认识的、永远不会回来的人。"
```

**实现**: 每个交集任务定义两套 `stageDescs` / `npcDialogues` / `eventDescriptions`，按 `state.path` 分发。不在同一段描述中混用两个视角。

**信息差设计五原则**:
1. 武修文本中永不出现修真概念（"灵气/界隙/灵脉/神识"等词禁用）
2. 武修用自然语言描述异常（"颜色不该是这样""太规则不像天然""冷得不正常"）
3. 灵修描述可以直接使用修真术语解释现象
4. 同一NPC在武修面前假装凡人，灵修面前卸下伪装
5. 任务真相只有灵修能完整理解。武修道心<30时可能模糊看到一些本不该看到的线索（引擎随机概率）
