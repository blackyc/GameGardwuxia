# 鬼修MUD · 核心世界观

> 「世人以为自己在修炼。祂以为世人在敲门。」
>
> 核心调性：聊斋60% + 认知侵蚀30% + 不可名状10%
> 表面世界平静如常，阴影在暗潮下涌动。

---

## 一、世界结构：三层叠加

### 表层——凡人眼中

村镇县城，炊烟袅袅，集市喧嚷。凡人对"仙人"敬而远之——知道山里有宗门，偶尔有修士路过，御剑或骑鹤。低阶修士在此行走：修炼养生，延年益寿，偶尔斩妖除魔获得灵石丹药。**一切都正常。**

但已有不对劲的细节：
- 某村的老槐树，每年七月初七子时会滴血——村人说那是树汁
- 镇上王员外的小妾，三年前死了，但有人看见她在后花园浇花。王员外说那是新来的丫鬟，长得像而已
- 城隍庙的神像，前天被人发现面朝墙壁。道长说是风吹的

### 夹层——修炼者开始"看见"

修炼到一定境界（筑基后期起），修士的感知开始发生变化：
- 月光下的影子不再完全跟随主人的动作
- 功法的文字开始按另一种顺序排列——不是你看错了，是文字在"告诉你另一件事"
- 镜子里的倒影偶尔做出你没做的表情。别害怕。别对视。
- 有些地方"比较薄"：荒村废宅、古战场、枯井、老树根下、废弃的祠堂——在这些地方，两边的东西更容易互相看见

凡人偶尔也会闯入夹层——民间叫"撞客""鬼打墙""中邪""走了魂"。聊斋经典题材：书生夜读，窗外有女子叩门，开门却无人，只闻一缕幽香。回到桌前，砚台里的墨变成了红色。

### 深层——只有彻底异化者才能触及

这是"祂"所在的层次。不是神，不是魔，不是一个你可以理解的存在。"祂"是一个频率，一个方向，是所有修炼者最终会"对焦"的那个终点。

- 修炼越深，越接近祂的频率
- 越接近祂的频率，越容易被祂"发现"
- 被祂发现后，你会"被看见"——不是一个比喻，是一个物理过程：你的结构开始改变
- 彻底被同化的人，不再是人类形态，但仍保有部分意志——成为祂在世间的一只"眼睛"或一只"手"

## 二、"祂"——不可名状的定义

### 祂是什么

没有人知道祂是什么。不同宗派有不同的称呼：

| 宗派 | 对祂的称呼 | 理解 |
|------|----------|------|
| 忘尘宗 | 「真」 | 世间皆伪，唯祂为真——问题是见了真之后你还想活么 |
| 赤霞峰 | 「霞主」 | 那个霞光不是太阳照的，是祂的血在渗出 |
| 锈剑冢 | 「最后一次磨剑的人」 | 所有的剑都在等祂回来 |
| 丝狱 | 「织网者」 | 世界是一张网，祂在网上行走——震动，祂就来了 |
| 焚身道 | 「火源」 | 万物皆薪，唯祂是火——你得烧自己才能靠近祂 |
| 逍遥驿 | 「没出现的那位客人」 | 驿站的空房是留给谁的 |
| 药王谷 | 「不治之症」 | 最可怕的病不是死，是被祂看见 |
| 血禅寺 | 「镜中之血」 | 不是你的血。是祂的。镜子里倒映出的那一片红色 |
| 镜阁 | 「镜中人」 | 镜中的人是祂——你照镜子时祂也在看你 |
| 归墟 | 「入口」 | 不是墓。是入口。深处通往祂 |
| 青囊庐 | 「终极病理」 | 在祂面前，治病和制毒是一回事 |
| 傀坊 | 「待填之空」 | 傀儡不是工具，是容器——在等祂住进来 |

### 祂不是

- 不是你可以对话的对象
- 不是你可以击败的敌人
- 不是"邪恶"——祂没有善恶，祂只是"存在"，而祂的存在对修士而言就是毁灭
- 不是神——神需要信徒，祂不需要。祂甚至不知道你在拜祂

### 修士与祂的关系

| 修炼阶段 | 与祂的关系 |
|---------|----------|
| 练气-筑基 | 不知道祂 |
| 金丹初期 | 开始有重复的梦 |
| 金丹后期-元婴 | 开始"看见"——意识到有某种东西在观察 |
| 化神 | 与祂对视过一次——活着回来的人都不一样了 |
| 渡劫 | 不是天雷劈你。是祂在看你了。很深地看。 |
| ~~飞升~~ | 你没了。祂多了一只眼睛。 |

## 三、修炼本质：侵蚀，而非进化

### 灵气 = 祂的"信息素"

凡人以为灵气是天地精华。修士以为灵气是天地精华。他们都错了。

灵气是祂的**痕迹**——祂在世界这张纸上写字时，渗出的墨。

每一次修炼，每一次吐纳，你吸入的不是能量，是**祂的信息碎屑**。你越强，体内祂的碎片越多。等到碎片足够多、足够密集，你就成为一个"锚点"——祂可以通过你看到这个世界，也可以从这里伸出手。

### 修炼 = 敲门

每一个修士都在无意识地敲一扇门。他们以为是自己在修炼、在逆天、在与天争命。实际上：**每运转一个大周天，就是敲一次门。**

大多数人一辈子敲不开。少数天才敲开了。敲开之后——不是门。是眼睛。

## 四、凡人与修士：同一个世界，不同的厚度

### 凡人视角

- 世界是厚的、实的、可以被触摸和确认的
- 鬼怪是传说、故事、吓孩子的
- 修士是"仙人"，是高不可攀的存在
- 偶尔的"不对"——被解释为巧合、错觉、谎言

### 低阶修士视角

- 世界开始变薄——有些地方你"穿"不过去，但你能感觉到对面有东西
- 鬼怪不是传说——但你斩妖除魔时，妖在死前看你的眼神像是在说"你早晚也一样"
- 修炼让你更强，但也让你更孤独——因为普通人不再能理解你看到的东西
- 有些功法里有隐藏的"真言"——按某种顺序读，文字不再是文字

### 中阶修士视角

- 世界已经很薄了——你不需要进入"鬼域"就能看见夹层的东西
- 你的影子偶尔不太对劲。你选择不低头看。
- 你会发现你的同门里，有些人"换过"——你可能也是
- 修炼不再是修炼——是在抵抗：抵抗太快接近祂

### 高阶修士视角

- 你已经分不清哪些是自己，哪些是祂的碎片
- 你的影子不是影子——是一个方向，一个洞口
- 你说话时偶尔会发出不属于任何人类语言的声音——不是你在说。是祂在说。
- 你还要修炼么？不修=退化=死。修=接近祂=不是你。这是死结。

## 五、鬼、怪、精、妖——"祂的四种碎片"

世间一切超自然之物，追根溯源，都是祂的信息在不同介质中的"折射"：

### 鬼——信息的残留
- 人死后留存的意志碎屑，沾染了灵气（=祂的痕迹）
- 鬼不是自己愿意存在的——祂的信息让他们"复读"生前的某个瞬间
- 有些鬼无害，只是夜晚在旧宅里反复做同一件事
- 有些鬼知道自己死了，他们很难过。别同情——同情让你的灵气更接近他们的频率

### 怪——信息的扭曲
- 灵气侵入非人之物（树、石、水、火、旧物），使其发生形态与意志的异化
- 百年老槐成精不是成精——是祂的信息在树里"住了太久"，树开始模仿人的形态
- 怪一般没有恶意，但它们的存在本身就是扭曲——靠近久了，你也会扭曲

### 精——信息的凝聚
- 高浓度灵气在特定条件下形成的自主能量体
- 精是最接近"纯灵气"的东西——也就是说，最接近祂
- 不要和精做交易。他们给你的东西，不是他们愿意给的——是祂愿意给的

### 妖——信息的寄生
- 活物被灵气过度侵蚀后的形态：堕妖
- 妖保留了原体的部分本能，但被灵气驱策——吃人不是饥饿，是灵气需要更多肉体作为"锚点"
- 修士也可能堕化为妖——当侵蚀度超过道心承受极限

## 六、世界规则（硬设定）

### 规则一：灵气不守恒
灵气总量不守恒。祂的信息持续渗入世界——灵气在增加。这解释了为什么远古时代灵气稀薄，而近世越来越浓。**世界正在被祂慢慢填满。**

### 规则二：看见即被看见
当你感知到祂的痕迹时，那个痕迹也感知到了你。这不是规律，是物理。你的感知是双向的——看即被看，听即被听，想即——别想。

### 规则三：名字是钩子
不要给祂起名字。不要称呼祂。不要在心里为之命名。每一次命名都是一次呼唤。每一次呼唤都让祂的注意力在你身上多停留一瞬。一瞬够了。

### 规则四：镜与影是通道
镜子不反射——镜子是另一个方向。影子不是你——影子是你在这个世界上的"背面"，是祂"看"进来的角度。这就是为什么异常总是从镜与影开始。

### 规则五：遗忘是防御
忘尘宗的核心理念是对他们来说也有切实的操作价值——忘掉自己，祂就找不到你。但问题是：忘到哪一步？忘掉名字？忘掉长相？忘掉你是一个人？忘到祂也忘了你的时候——你也不在了。

## 七、世界观对游戏系统的映射

| 系统 | 世界观映射 |
|------|----------|
| 道心值 (sanity) | 你"还是你"的程度。越低，越接近祂 |
| 侵蚀度 | 你体内祂的碎片占比。高侵修士能力更强，但更不是自己 |
| 生死 | 死 ≠ 消失。死 = 你不再维持自己的形态，碎片归还给祂 |
| 战斗 | 战斗时灵气消耗 = 你在用祂的碎片做别的事——祂在看你用 |
| 修炼/突破 | 每突破一层境界，做一个"检测"——检测你体内祂的碎片比例。过高 = 突破失败 + 异化事件 |
| 奇遇 | 夹层裂缝的随机开启——你"走运"是因为你正好踩在祂视线经过的地方 |
