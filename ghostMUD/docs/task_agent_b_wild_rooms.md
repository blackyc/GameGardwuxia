## 三、按距离分层的写作策略

### 层级1：寺庙·道观（近城，18间）
- **氛围**：宗教场所 = 凡人与修士的过渡带。僧人道人日常正常——但偶尔的经文/仪式动作不太对。
- **描述**：白描为主。佛道场所的庄严感中穿插一个不该存在的小物件或痕迹。
- **danger**: 1-2。
- **嵌套特点**：藏经阁/丹房/地宫的嵌套入口 = 修士可感知，凡人根本注意不到。

### 层级2：城郊野外（8间，yt_suburb_*）
- **氛围**：聊斋味渐浓。自然景物为主，但山路/古道/废墟有微弱的不正常。
- **描述**：写实+暗示。如"山脚下有几间废弃的炭窑，窑口都塌了——只有一口窑，塌的方向是往里塌的。"
- **danger**: 2-3。

### 层级3：荒野深处（7间，yt_cemetery ~ yt_wild_peak）
- **氛围**：聊斋味全开。越远离人烟，越不正常。描述越写越不对，但不解释。
- **描述**：白描诡异现象。纯描述，零解释。义庄的棺材板自己在响；鬼道的雾里有人影但看不清。
- **danger**: 3-5。

## 四、核心约束（同上 Agent A，额外强调）

### §4.1 地名规则
- 寺庙道观名可带宗教色彩（寺/庙/庵/观/宫/殿/阁/塔/堂/祠），但禁用"鬼寺/妖塔/魔窟/邪观"。
- 城外地名允许轻微聊斋味（义庄/乱葬岗/鬼市外/鬼道），但避免过度的"血/尸/死"字前缀。
- 允许的城外地名模式：X山/X岭/X古道/X野渡/X坡/X径/X废墟/X庄/X林/X崖。

### §4.2 嵌套子房间
格式同 Agent A §3.4。本文件生成的嵌套子房间中：
- 预设条件以 `realm` / `daoxin` / `time` / `item` 为主（修士感知/道心门槛/时辰/法器）
- `skill` 类型次之（轻功/拳脚检查）
- **不给城市场景用 `composite`**（太复杂），但鬼域入口允许组合条件（如"子时+道心≥70"）

### §4.3 出口连接
- 寺庙道观 → 连接到邻近街道/山门路径
- `yt_suburb_*` → 彼此相邻，按地理方位连通。远端连接对应的城门。
- 荒野深处 → 彼此相邻，最远端（yt_wild_peak/yt_wild_river/yt_dragon_vein）为地图边界。
- **与Agent A的连接**：四门对应的城郊房间 id 需匹配 Agent A 的门方向。如 `yt_south_gate` 南通 `yt_suburb_s`（雨花台）。
