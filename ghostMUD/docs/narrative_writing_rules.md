# 古文剧情文本编写规则

> 适用范围：ghostMUD 全部剧情文本、对白、叙事描写、NPC对话、事件文案
> 生效优先级：全局最高，所有剧情生成必须遵守

---

## 一、文风总纲（金庸式正统武侠）

1. 语言以近代白话为底，半文半白，通俗流畅，不用生僻字、不堆砌华丽辞藻，追求"绚烂之极归于平淡"
2. 叙事重动作、轻描写，多用动词推动情节，少用形容词抒情，文字要有速度感，像镜头一样推进画面
3. 人物语言严格贴合身份：江湖草莽说话粗直爽快，书生说话文雅但不酸腐，武林前辈说话沉稳有分量，少女说话灵动明快，绝无千人一腔
4. 多用动作、神态、对话体现人物心理，禁止直白写"他心想""他感到很悲伤"，所有情绪藏在细节里
5. 对话短而有力，避免长段抒情，符合江湖人说话的干脆感；关键信息点到为止，留有余味

---

## 二、对白写作铁则

1. **每段对白必须伴随动作/神态描写**，例如"抱拳说道""冷笑一声""眉头一皱，沉声道"，不能光秃秃只有台词
2. **符合人物身份与当下处境**，危急时话短句快，闲谈时可稍舒缓，禁止任何时候都文绉绉拽辞藻
3. **禁用现代词汇、网络语、翻译腔**，多用"正是、岂有此理、好极好极"等传统白话表达
4. **江湖对话讲究分寸**，晚辈对长辈用敬语，平辈之间称兄道弟，符合武林规矩

### 对白格式规范（JSON 输出）

```json
{
  "dialogues": [
    {
      "id": "d001",
      "character": "角色名",
      "avatar": "头像编号",
      "line": "台词内容",
      "action": "动作/神态描写",
      "branch_to": "下一对话ID或分支跳转ID（可为null）"
    }
  ]
}
```

字段说明：
- `id`：对话唯一标识，格式 `d###`，三位数字递增
- `character`：角色名，须与 NPC 数据表一致
- `avatar`：头像编号，对应资源表中的头像 ID
- `line`：台词正文，遵守对白铁则
- `action`：伴随动作或神态描写，不可为空
- `branch_to`：流程跳转目标 ID，用于分支剧情；线性对话填下一句 ID，结尾填 `null`

---

## 三、叙事描写铁则

1. **环境描写点到为止**，三两句话勾勒氛围，不做长篇大段的景物堆砌
2. **打斗描写重招式、重节奏、重双方反应**，像武打镜头一样有来有回，不用抽象的"气势磅礴""惊天动地"
3. **不直接评判人物好坏**，通过言行让读者自行感知

---

## 四、绝对禁用表达（去AI味儿核心）

| 类别 | 禁用示例 | 替代思路 |
|------|---------|---------|
| 堆砌古风辞藻 | 眸若星辰、衣袂飘飘、风华绝代、盛世美颜 | 用具体动作/细节代替，如"她偏过头，发带扫过肩头" |
| 直白心理描写 | 他心中一痛、她暗自窃喜、他感到无比愤怒 | 用外在表现暗示，如"他攥紧了拳头，指节发白" |
| 现代逻辑词 | 综上所述、换句话说、其实、事实上 | 删掉，或用"说白了""依我看"等口语化表达 |
| 全员文雅腔 | 市井人物、武夫粗人咬文嚼字 | 粗人说粗话，"放屁""少废话""老子" |
| 空洞排比抒情 | 大段无意义的氛围感空话、排比句 | 删掉，用动作推进代替 |

---

## 五、参考样本（对标风格）

> 郭靖又惊又喜，反手搂住了她，叫道："蓉儿，真是你？你……你怎么到了这里？"黄蓉笑道："我怎么不能来？你能来杀蒙古鞑子，我就不能来帮你么？"郭靖只觉心中温暖无比，一时说不出话来。
>
> 欧阳锋冷笑道："黄老邪，你女儿打伤我侄儿，这笔账咱们今日便算一算。"黄药师斜倚在桃树之上，眼皮也不抬，淡淡地道："你要算，便算便是。"

**样本要点提炼：**
- 对话短促，一句一动作
- 身份感明确：郭靖憨直、黄蓉灵动、欧阳锋阴鸷、黄药师孤傲
- "眼皮也不抬""淡淡地道"——用极简神态传递性格
- 没有任何心理直述，情绪全在动作和语气里

## 六、剧情生成两步法（强制执行）

### 第一步：写骨架

生成【场景名称】的剧情骨架，**只输出以下内容，不写具体台词**：

1. **出场人物与各自身份、状态**
2. **核心冲突与情节走向**
3. **人物情绪变化节点**
4. **关键转折与结局**

骨架格式（纯文本）：

```
【场景名称】剧情骨架

出场人物：
- 角色A（身份/当前状态）
- 角色B（身份/当前状态）

核心冲突：一句话描述矛盾焦点

情节走向：
1. 开场情境
2. 矛盾升级
3. 转折点
4. 结局

情绪节点：
- 角色A：起始情绪 → 中段情绪 → 终局情绪
- 角色B：起始情绪 → 中段情绪 → 终局情绪

关键转折：一句话描述
结局：一句话描述
```

### 第二步：填内容

基于第一步的剧情骨架，按照本规则全部文风要求，扩写成完整剧情文本。

**输出格式为标准 JSON 数据表**，字段包含：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 对话ID，`d###`格式 |
| `character` | string | 角色名 |
| `avatar` | string | 头像编号 |
| `line` | string | 台词（遵守对白铁则） |
| `action` | string | 动作/神态描写（不可为空） |
| `branch_to` | string\|null | 分支跳转ID，线性序列填下一句ID，结尾填null |

**质量检查清单（生成后自检）：**

- [ ] 每句对白都有动作/神态描写？
- [ ] 不同身份角色的语气是否有区分？
- [ ] 有无现代词汇/翻译腔混入？
- [ ] 有无直白心理描写（"他心想"等）？
- [ ] 有无堆砌古风辞藻（"眸若星辰"等）？
- [ ] 打斗描写是否有招式有来有回？
- [ ] 环境描写是否控制在三两句内？
- [ ] JSON 字段是否完整、格式合法？

## 附：常用传统白话表达速查

| 场景 | 可用表达 |
|------|---------|
| 打招呼 | 久仰、幸会、别来无恙 |
| 告辞 | 告辞、后会有期、青山不改 |

| 怀疑 | 未必、怕是不然、此事当真 |
| 紧张 | 不妙、糟了、不好 |
| 轻蔑 | 哼、可笑、不自量力 |
| 惊讶 | 当真、竟有此事、这…… |
| 应承 | 且试试、包在我身上、定不辱命 |
| 拒绝 | 恕难从命、此事万万不可、不凑巧 |
