## 二、三层描述系统

### 2.1 设计逻辑

武修的"认知"是被动递进的，不是"突然开眼"——用描述精度递进代替修真概念解释。

| 路径 | 境界 | 认知层 | 数据字段 | 特征 |
|------|------|--------|---------|------|
| 武修 | 凡人~武师(0-2) | 隐约觉察 | desc_vague | 主观不确定 |"大概""也许""似乎""像是" |
| 武修 | 宗师~天人(3-4) | 看穿表象 | desc_percept | 物理确定，禁用修真术语 |
| 灵修 | 炼气~化神(1-5) | 灵视看见 | desc_awakened | 修真术语，解释现象 |

### 2.2 范例对比

```
【鼓楼西鬼市·悬浮的灯笼】
desc_vague:   "巷子尽头挂着一排灯笼。风明明很大——它们却一动不动。大概是挂得特别稳。也许是。"
desc_percept: "灯笼不是被挂住的。绳子上没有绳结——灯笼悬在空中，离绳子还有一指宽的距离。风绕着它们走。"
desc_awakened:"绳结早已朽尽。灯笼悬浮在半空——是鬼市主人随手划出的几道灵气缚线在托着它们。灵气从地下渗上来的，很淡，带了点不该有的温热。"
```

### 2.3 引擎层实现

```js
function getDesc(obj) {
  const s = state;
  if (s.path === 'ling' && s.realm >= 1 && obj.desc_awakened) 
    return obj.desc_awakened;
  if (s.path === 'wu' && s.realm >= 3 && obj.desc_percept)
    return obj.desc_percept;
  if (obj.desc_vague) return obj.desc_vague;
  return obj.desc; // 兼容现有单desc字段
}
```

### 2.4 行为约束

| 禁止 | 替代 |
|------|------|
| 武修文本出现"灵气/灵脉/界隙/神识/灵视/道基" | 用自然语言："不该有的颜色""太规则不像天然""冷得不正常""一种说不清的存在感" |
| "非A而是B"句式 | "不是X——是Y" OK；"不是X，而是Y"禁用 |
| 灵修描述混入武侠语 | "内力"→"灵力"，"真气"→"灵气"，"招式"→"术法" |

### 3.3 灵修畸变方向 —— 越修越不像人

**核心设定**：灵修的力量来源于靠近那些不该靠近的存在。灵修每突破一个境界，身体就会离"人"更远一分。仙与妖邪之间没有界限——灵修本身就是从人滑向妖邪的过程。修炼不是变强，是变成别的东西。

#### 畸变总表

| 宗门 | 克苏鲁原型 | 中式命名 | 畸变主题 | 源头隐喻 |
|------|----------|---------|---------|---------|

| 归墟 | 克苏鲁/大衮 | 深渊之嗣 | 深海化/异鳞 | 归墟不是海眼。归墟是活的——是祂的嘴 |
| 镜阁 | 哈斯塔 | 黄衣之王 | 镜像/分身/黄衣 | 镜子里的人不是你，从来都不是。他穿着黄衣——你是他的倒影 |

#### 六宗畸变详解

**① 忘尘宗 · 千面之混沌**

> "忘掉自己——祂就看不见你。"入门第一课。但没人告诉你后半句：你忘掉的自己，会有别的东西来填。

**畸变来源**：奈亚拉托提普（Nyarlathotep），外神三柱原神之一，"伏行之混沌"，千面之神。它没有固定形态，永远戴着面具行走世间——或者说，它就是面具本身。忘尘宗修炼的本质不是让自己变空，而是把"自我"一寸寸让渡出去，腾出空间。

**畸变进程**：

| 境界 | 畸变表现 | NPC/凡人感知 |
|------|---------|------------|
| 炼气 | 偶尔忘记刚做的事。镜子里第一眼觉得脸不太对——再看，没什么问题 | 无感知 |
| 筑基 | 连续忘记整段时间（半天、一天）。醒来时发现自己写了一些不认识的字 | 此人有些走神 |
| 金丹 | 脸上的表情开始滞后——还没决定要笑，嘴角已经动了。五官隐隐移位 | 这人长什么样来着？刚见过的…… |
| 元婴 | 五官趋于模糊，像一张未完成的面具。另一个声音偶尔借用你的嘴说话 | 不要看他的脸。不知道他是谁——他自己也不知道 |
| 化神 | 面具完成。你已经不记得自己原本长什么样了。镜子里是别人的脸——祂正朝你微笑 | 凡人看见的人不是你。武修宗师以上会察觉"此人不是人" |

**道心归零特殊结局**（忘尘宗）：
```
你不记得自己的名字了。不记得自己为什么在这里。不记得自己是谁。
但你感觉很好。很轻。很空。
有一张新的脸正从你空出来的脸上长出来——不是你的，但很合适。
你朝空无一人的方向笑了笑。那个方向有人在等你——不是你认识的人，但认识你的人。
```

**② 紫霞山 · 门之钥**

> "紫气东来——看清天道纹理。"紫霞山的入门口诀。紫气不是气，是祂目光的颜色。你看得越清楚，祂也把你看得越清楚。

**畸变来源**：犹格·索托斯（Yog-Sothoth），"万物归一者"、"门之钥"，居于时空之外，知晓一切过去未来。它不是神——它是连通所有时间与空间的"门"本身。紫霞山弟子以"眼看"为修行核心——但眼越多，门越开。

**畸变进程**：

| 境界 | 畸变表现 | NPC/凡人感知 |
|------|---------|------------|
| 炼气 | 眼白偶尔闪过一圈极淡的紫晕。自己照镜子看不出来 | 无感知 |
| 筑基 | 闭眼时偶尔能"看见"不该看见的东西——隔壁的屋子、地下的东西。紫晕固定 | 此人目光让人不舒服 |
| 金丹 | 第三只眼——不在额头，可能在后颈、手心、肋侧。它闭着——但你能感知到它在看 | 他身上多长了一只眼睛 |
| 元婴 | 全身多处开口——眼睛，但也不是眼睛。每一只都能看见不同的时间。有的看见过去，有的看见将来 | 不要看他——他身上的眼睛也在看你 |
| 化神 | 你成为一扇半开着的门。你身上任何一道裂口都是门——通向不该存在的地方。里面有什么正在往外看 | 凡人靠近会短暂失忆。灵修看见门的另一边是紫色的虚空 |

**道心归零特殊结局**（紫霞山）：
```
你身上的所有眼睛同时睁开了。你看到了全部——从天地初辟到万物终结。
然后你看到了门那边的一切。祂就在那儿。一直在那儿。
你的身体开始透光——紫色的、冷的、不属于此界的。
你最后用自己原本的眼睛看到的是：你身上的裂口已经不是裂口了，是门。门里有东西在往外爬。
```

**③ 归墟 · 深渊之嗣**

> "海眼之下——有比深渊更深的什么。"归墟本是神话中四海之水汇聚之地。归墟宗告诉你：归墟不是传说，归墟是活的。是祂的嘴。

**畸变来源**：克苏鲁（Cthulhu）+ 大衮（Dagon）。克苏鲁沉睡于海底拉莱耶，大衮是其从者、深潜者之父。归墟宗的畸变不是变成鱼——是变成深渊的一部分。

**畸变进程**：

| 境界 | 畸变表现 | NPC/凡人感知 |
|------|---------|------------|
| 炼气 | 喜欢水边。汗水带了极淡的咸腥——不是普通汗味 | 无感知 |
| 筑基 | 手指间长出极薄的半透明蹼膜。皮肤变滑，不再出汗——改渗咸液 | 手怎么那么凉？皮肤有点怪 |
| 金丹 | 颈侧开裂——鳃。不是鱼的鳃，是深海才有的那种结构。能在水下呼吸，但离开水会疼 | 有明显的异类感。渔夫会本能避开 |
| 元婴 | 身体表面开始覆盖鳞片——不是任何已知鱼类的鳞。骨刺从脊椎往外顶。瞳孔变圆形，不聚光 | 这东西不是人 |
| 化神 | 你已经不再需要陆地。你的血液是冷的盐水。你听见海底传来声音——你听懂了一部分。祂在等你下去 | 凡人看见你会想起淹死的噩梦。灵修能在你瞳孔深处看见拉莱耶的倒影 |

**道心归零特殊结局**（归墟）：
```
你走向最近的水。不是走——是滑进去的。水是你身体的一部分。
你向下沉。越深越冷。越冷越安静。越安静越清楚——
你听见了祂的声音。从海沟最深处。不是梦。祂醒着。一直醒着。
你最后看见自己的手——已经完全不是人的手了。
那是深海之嗣的手。那是回家。
```

**④ 镜阁 · 黄衣之王**

> "镜子不骗人——照出来的不是你的脸。"镜阁的核心修法是"对镜"：面对镜子修炼，看镜子里的自己，看久了就能看见别的东西。

**畸变来源**：哈斯塔（Hastur），"黄衣之王"、"不可名状者"。哈斯塔不像克苏鲁那样巨大——他更安静、更阴郁、更接近你。他会从你能想象到的任何地方出现——尤其是镜子。

**畸变进程**：

| 境界 | 畸变表现 | NPC/凡人感知 |
|------|---------|------------|
| 炼气 | 镜子里的倒影偶尔慢了半拍——你转头，它转得晚了。你不在乎——"眼花" | 无感知 |
| 筑基 | 镜中倒影开始做你没做的事。偶尔嘴角翘一下。偶尔眼睛看向你身后的角落 | 此人照镜子的表情让人不适——像是在确认对面是谁 |
| 金丹 | 倒影走出来——不是经常，但有过。它不说话。只是站在房间另一头，穿着与你一模一样的衣服。然后消失 | 此人身边偶尔多出一个一模一样的背影 |
| 元婴 | 镜子里不再是你。不是你变丑了——是镜中人穿的衣服不对。黄色的。你没穿过那件黄衣。但它很合身 | 不要去他家的镜子前。镜子里有人在等你 |
| 化神 | 你已经不确定镜子这边的是不是本体了。也许你才是镜像。黄衣穿在你身上——你不知道什么时候穿上的，但不想脱 | 凡人看你时眼晕。灵修能看见你的身形轮廓边缘有第二圈——更淡，更宽，像是黄色长袍的边 |

**道心归零特殊结局**（镜阁）：
```
你最后走进了一面镜子。不是打碎的——是走进去的。
镜子的另一边没有房间。只有无尽的、黄色的雾。
你看见远处有个身影朝你走来——穿着黄衣。
你低头看见自己——穿的是破布。你不确定哪一件才是该穿的。
那个身影走到你面前。它摘下面具——下面是你的脸。
它微笑。说："你来了。坐。演出马上开始。"
```

**⑤ 肉慈斋 · 森之黑山羊**

> "肉身成圣——肉泥孕人。"肉慈斋的开宗经文。肉身是最忠实的载体——但不是载你，是载祂的子嗣。修炼让肉体变得丰饶。过于丰饶。

**畸变来源**：莎布·尼古拉丝（Shub-Niggurath），外神三柱原神之一，"孕育千万子孙的森之黑山羊"。她是生命的源头——但"她的生命"不是人类的生命。肉慈斋的畸变是所有宗门中最直观的：你的身体开始生产不属于人类范畴的活物。

**畸变进程**：

| 境界 | 畸变表现 | NPC/凡人感知 |
|------|---------|------------|
| 炼气 | 伤口愈合快得不正常。肉的味道让你更饿——不是饥饿，是"生长的冲动" | 这人皮肤有些浮肿 |
| 筑基 | 身上出现赘生物——不是肿瘤，结构太规整了。有的几乎像是未发育完全的器官 | 他身上长了什么东西……最好别看 |
| 金丹 | 赘生物脱落后独自存活了一段时间——没有嘴，但会动。肉慈斋弟子学会了沉默地处理这些东西 | 此人身上总有一股淡淡的腥甜味 |
| 元婴 | 从自己身上取下一块肉，它自己在碗里发育成了一只小东西——不认得的物种。它抬头看你。你知道它在叫你母亲 | 他的影子不对——他的影子像是有一群东西在蠕动 |
| 化神 | 你是行走的子宫。任何从你身上脱离的组织都会自己发育成独立的、不完整但活着的生命体。它们跟着你。它们服从你。它们饿了 | 凡人看见他会呕吐。灵修看见他被一群微小的黑山羊状的影子包围 |

**道心归零特殊结局**（肉慈斋）：

**⑥ 青囊庐 · 缠尸之神**

> "生死之间——看见去处。"青囊庐修的是医道。但医道的本质不是延缓死亡——是理解死亡。理解得越深，离死亡越近。死亡不是一个状态，是一个地方。祂在那里。

**畸变来源**：莫尔迪基安（Mordiggian），"尸食教之神"、"缠尸之神"。他掌管死亡与尸体，但不是死神——他掌管的是"死后"。死后不是虚无，是他掌管的领域。青囊庐弟子修医道，却在不知不觉中成为他收割的镰刀。

**畸变进程**：

| 境界 | 畸变表现 | NPC/凡人感知 |
|------|---------|------------|
| 炼气 | 体温偏低。日出日落时会短暂地看见常人看不见的灰色轮廓——刚死的人，还没走远 | 这人手很冷 |
| 筑基 | 伤口流出的是透明的、略黏的液体——不是血。不需要呼吸那么频繁了 | 此人气色很差——像是病了很久 |
| 金丹 | 皮肤变灰，不具正常人的弹性。不需要进食——腐烂中的食物更让你舒服。能清楚地看见死者，死者也能看见你 | 他身上有墓土的味道。不要让他碰你 |
| 元婴 | 你的身体处于活体与尸身之间——不确定自己哪部分还活着。每一次救治都会在掌心留下黑色纹路——那是死者在感谢你 | 跟他待久了，家里的盆栽会枯。不是缺水——是被"带走了什么" |
| 化神 | 你不再需要区分生死。你站在槛上——一边是活人的世界，一边是祂的厅堂。死者从你身边经过，朝你点头。你知道他们的名字——你第一次见到他们就知道了 | 凡人看不见这个人——他们会绕过去，不知道为什么。灵修看见他身后跟着一支沉默的队伍——都是他治死的人 |

**道心归零特殊结局**（青囊庐）：
```
你最后一次背上青囊出门——但你不知道是去救人还是去收割。
后来的人说那晚看见一个背着药囊的身影走进了乱葬岗——没有再出来。
乱葬岗的土翻新了几处。像是底下有什么东西被放出来了——或者有什么东西自己走了进去。
青囊还在。挂在枯树上。上面爬满了不属于此界的苔藓。
```


**UI表现**:
- 灵修角色面板增加 "畸变" 一行，显示当前畸变等级名称
- 畸变名称按宗门不同：忘尘宗tier5显示"完成·千面"，肉慈斋tier5显示"完成·黑山羊之嗣"
- 凡人NPC对高畸变灵修的反应：筑基以上概率出现"回避/恐惧/震惊"对话，金丹以上概率触发"拒绝交易/驱赶/报官"
- 武修宗师(realm≥3)能感知灵修畸变，对应NPC对话改变

**畸变不可逆**: 灵修的路没有回头。降低境界不会逆转肉体畸变——你的身体已经变了，修为的高低只影响控制力，不影响外观。

**畸变与道心的关系**: 畸变本身不扣道心——但道心<30时，灵修开始听见祂的声音。不是幻觉。是真实的、来自各自"源头"的低语。每个宗门的低语内容不同，但都在说同一件事：来。

## 四、双路径转职

### 4.1 路径A：散修 → 灵修

- **触发**: 散修 + realm≥2 + 应天府暗巷奇遇
- **5步链**: 暗巷引路人 → 睁眼(道心-15) → 第一次灵视 → 选择 → 转职
- **转后**: 无宗门，灵修散人

### 4.2 路径B：武修宗门弟子 → 灵修（新增）

- **触发**: 宗门弟子 + realm≥3（宗师） + 在HQ发现遗物异常
  - 凡人~武师在遗物旁只能感到"不舒服/脖子发凉"，无法触发交互
  - 宗师能感知"遗物上有一种不该属于这个世间的存在感"→可交互触发
- **5步链**:
  1. **发现**: 宗师在HQ深处感知到遗物异常，走向它
  2. **触碰**: 触发记忆碎片——人祸当天场景回放（文本视觉化叙述）
  3. **真相**: 发现宗门本为灵修→人祸→封印→以武修重建
  4. **选择**:
     - 选项A: 封印遗物，"当作没看到过"→留武修，道心-5
     - 选项B: 继承遗物，"我要走下去"→转灵修，道心-20
  5. **转职**: 宗门标签→`[原宗门名]·灵脉`，继承宗门灵修前身的部分技能
- **转后**: 有宗门归属，可修灵修技能

### 4.3 对比表

| 维度 | 散修→灵修 | 宗门→灵修 |
|------|----------|----------|
| 触发境界 | 武师(2) | 宗师(3) |
| 道心冲击 | -15 | -20 |
| 归属 | 无宗门 | 原宗门·灵脉 |
| 技能继承 | 无 | 继承部分灵修前身技能 |

## 八、道心归零双结局

### 武修道心归零
```
你不再出门了。
墙上的影子越来越多。最开始只是窗外闪过的暗影——后来它们站到了墙角、床边、桌上。
它们有的像人，有的不像。有的在看你，有的在模仿你。

里面没有人。墙上的影子还在——比之前多。
```

```
道心崩碎的那一刻，你感受到了"注视"。
不是任何人的目光。是一股不可抗拒的、来自天穹之上的力——它在拉你。
不是比喻。你的神识被扯离了身体。你向上飞，飞到不该到达的高度。
你看见了天道。
天道不是空的。
天道里有东西也在看你。
然后你就不在了。不是死了——是从来没有存在过。你的名字和记忆从世间消失了，像被一只手从纸上抹掉的墨迹。
```
