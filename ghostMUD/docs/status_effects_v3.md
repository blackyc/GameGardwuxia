# 诡仙录 · 异常状态系统 v3.0 — 宗门锚点制

> 七种异常状态，各绑一个锚点宗门。非独占——其他宗门亦可施加，但锚点宗门效果略强。
> 名字取自中式古风，兼有金庸的凌厉、古龙的写意、聊斋的诡谲。

---

## 一、设计原则

1. **望名知门**：看到状态名即可联想锚点宗门的核心意象
2. **非独占性**：锚点宗门不是唯一施放者，任何宗门只要有合理叙事路径均可施加
3. **锚点加成**：锚点宗门施加该状态时，额外 +1 层或 +10% 效果（视状态类型而定）
4. **状态交互**：七种状态之间存在组合反应，增加战斗 build 深度
5. **叙事优先**：每种状态有聊斋风格叙事文本，恐怖在文字里，不在名字里

## 三、各状态详细规格

### 3.1 尸蛊（毒）

| 维度 | 规格 |
|------|------|
| **锚点宗门** | 药王谷 |
| **层数上限** | 99 层 |
| **每层伤害** | 1 点 / tick（每 0.5s 结算一次） |
| **衰减规则** | 每次结算 -1 层 |
| **技能施加范围** | 2-6 层 |
| **锚点加成** | 药王谷施加时额外 +1 层；若目标已有尸蛊，药王谷的施法有 30% 概率不触发衰减（蛊虫自补） |
| **叙事描述** | 「尸蛊蚀骨，筋脉中似有千百虫蚁噬咬。皮肤下隐隐隆起，蠕动如活物——那是蛊在吃你。」 |

**可施加宗门**：
- **药王谷**（锚点）：淬灵毒功、暗器淬蛊
- **归墟**：深海异毒，咸腥腐肉之蛊（毒 + 凝渊双重施加者）
- **青囊庐**：以医入毒，死门毒术——治人即杀人
- **傀坊**：机关淬毒暗器，无机之蛊

---

### 3.2 裂伤（流血）

| 维度 | 规格 |
|------|------|
| **锚点宗门** | 血禅寺 |
| **层数上限** | 99 层 |
| **每层伤害** | 等于当前层数（层数越高单次越痛） |
| **衰减规则** | 出招时结算一次 → 减半；回合结束再结算一次 → 清除（下一轮重新叠加） |
| **技能施加范围** | 3-10 层 |
| **锚点加成** | 血禅寺施加时额外 +1 层；血禅寺的裂伤不受"回合结束清除"规则——改为衰减至半数保留（血引之术，血不止） |
| **叙事描述** | 「裂伤如壑，皮肉翻卷处不见血——血已被引走了。伤口在长大，像有什么东西从里面往外撑。」 |

**可施加宗门**：
- **血禅寺**（锚点）：以血引灵入体，掌法撕裂血肉
- **问剑峰**：剑法凌厉，快剑割裂经脉
- **逍遥驿**：点穴截脉，内伤外发
- **肉慈斋**：肉体增生撕裂自身组织，异化裂创

---

### 3.3 业火（灼烧）

| 维度 | 规格 |
|------|------|
| **锚点宗门** | 焰心教 |
| **层数上限** | 20 层 |
| **每层效果** | 火系伤害 +10%/层（增伤标记，不独立造成伤害） |
| **衰减规则** | 不衰减，持续到战斗结束或被交互清除 |
| **技能施加范围** | 2-4 层 |
| **锚点加成** | 焰心教施加时额外 +1 层；焰心教的业火额外使物理伤害也 +5%/层（圣火焚一切，不止火系） |
| **叙事描述** | 「业火附身，不见焰苗只见烟。皮肉焦黑处不痛——痛的是骨头在烧。那是你欠的债，一条一条在还。」 |

**可施加宗门**：
- **焰心教**（锚点）：圣火为灵火，掌法携火
- **血禅寺**：血引之火，嗔怒业燃
- **镜阁**：镜中人持火，虚焰灼魂（黄衣之火）
- **问剑峰**：剑气化焰，纯阳剑火（少数剑修分支）

### 3.4 凝渊（寒冰）

| 维度 | 规格 |
|------|------|
| **锚点宗门** | 归墟 |
| **层数上限** | 30 层 |
| **每层效果** | 累计达到 10 层时触发「渊冻」：冻结目标 1 秒 + 造成层数 × 2 冰伤，清除全部凝渊层数 |
| **衰减规则** | 不自然衰减；仅通过「渊冻」触发或交互清除 |
| **技能施加范围** | 3-6 层 |
| **锚点加成** | 归墟施加时额外 +1 层；归墟的「渊冻」触发阈值降为 8 层（深海归渊，冻得更快） |
| **叙事描述** | 「凝渊侵体，四肢渐沉如坠深海。呼吸吐出白雾，眼角结霜——不是冷，是有什么东西在水底拉你的脚踝。」 |

**可施加宗门**：
- **归墟**（锚点）：深海冷寂，异鳞寒气
- **紫霞山**：紫气凝霜，门之钥的冷是"时间停了"的冷
- **青囊庐**：尸冷入骨，亡者之寒
- **逍遥驿**：梦行寒魄，梦中冻魂

## 四、状态交互规则

### 4.1 交互总表

| 组合 | 交互名 | 效果 | 叙事描述 |
|------|--------|------|---------|
| 尸蛊 + 凝渊 | **冻蛊** | 凝渊冻结毒素：尸蛊 DOT 暂停（不结算不衰减），层数保留。凝渊触发渊冻时，冻结的尸蛊层数一次性爆发结算，伤害 ×1.5 | 「蛊虫被冻住了——但没死。冰碎的那一刻，它们饿了一整冬。」 |
| 业火 + 凝渊 | **蒸发** | （保留原有机制，更名）凝渊层数清零，业火层数减半，造成一次蒸发伤害 = (凝渊层数 + 业火层数) × 3。附带 2 层破罡 | 「渊水遇业火，蒸为白雾。雾中什么都看不见——但什么都看得见你。」 |
| 裂伤 + 逆血 | **血涌** | 逆血触发时，额外结算一次裂伤伤害（用当前裂伤层数）。若裂伤因此清零，逆血额外 +2 层 | 「伤口被血冲开，又被血填上。填上的是别人的血。你不想知道是谁的。」 |
| 迷魂 + 破罡 | **碎魂** | 迷魂状态下，破罡效果翻倍（每层 +2 伤害而非 +1）。但迷魂持续时间减半（神魂既碎，速速醒来） | 「罡气碎了，魂也碎了。疼得清醒——清醒得来不及后悔。」 |
| 尸蛊 + 业火 | **焚蛊** | 业火引燃蛊虫：尸蛊层数减半，每减少 1 层造成 2 点火焰伤害。业火层数不变。触发后目标获得 3 层业火（蛊虫烧起来的烟也是毒） | 「蛊虫烧着了。皮下的蠕动变成了痉挛——然后是焦味。烟钻进肺里，咳出来的不是痰。」 |
| 裂伤 + 凝渊 | **冰裂** | 凝渊使裂伤冻结：裂伤 DOT 暂停，层数保留。渊冻触发时，冻结的裂伤层数转化为冰伤（1:1），并额外施加 2 层破罡（冰碎裂伤，罡气同碎） | 「血冻在伤口里，把伤口撑得更大。冰碴子扎进肉里——那是你自己的血在割你。」 |
| 迷魂 + 逆血 | **心魔** | 迷魂状态下暴击率 +15%（神魂恍惚，不按常理出招 → 更容易打中要害）。但逆血触发时，施法者自身也受到 30% 的逆血伤害（心魔反噬） | 「忘了自己在流血。忘了疼。拳打得更狠了——但每次出拳，胸口都闷一下。不是你的心在跳。」 |
| 破罡 + 业火 | **焚甲** | 破罡使业火的增伤效果也作用于非火系伤害。即：业火每层使所有伤害 +10%（而非仅火系），但仅对已破罡的目标生效 | 「护体的最后一层气碎了。火不只是烧皮了——烧进了骨头缝里。什么属性都挡不住。」 |

### 4.2 交互优先级

当一个目标同时存在多种状态且触发交互时，按以下优先级结算：

```
1. 蒸发（业火 + 凝渊）      — 最高优先级，蒸发瞬间清除两种状态
2. 冻蛊（尸蛊 + 凝渊）      — 凝渊与其他 DOT 的冻结交互
3. 冰裂（裂伤 + 凝渊）      — 同上
4. 焚蛊（尸蛊 + 业火）      — 主动引燃型交互
5. 焚甲（破罡 + 业火）      — 被动增伤型交互
6. 血涌（裂伤 + 逆血）      — 暴击触发型交互
7. 碎魂（迷魂 + 破罡）      — 被动增伤型交互
8. 心魔（迷魂 + 逆血）      — 暴击触发型交互
```

**规则**：同一 tick 内一个状态只能参与一次交互。若多个交互同时可触发，按优先级取最高者，其余交互在本 tick 内不触发。

### 4.3 交互触发条件汇总

| 交互 | 触发时机 | 触发条件 |
|------|---------|---------|
| 冻蛊 | 凝渊 DOT 结算时 | 目标同时有尸蛊 ≥1 层 + 凝渊 ≥1 层 |
| 蒸发 | 业火增伤结算时 | 目标同时有业火 ≥1 层 + 凝渊 ≥1 层 |
| 血涌 | 逆血暴击触发时 | 目标同时有裂伤 ≥1 层 + 逆血 ≥1 层 |
| 碎魂 | 破罡增伤结算时 | 目标同时有迷魂 ≥1 层 + 破罡 ≥1 层 |
| 焚蛊 | 尸蛊 DOT 结算时 | 目标同时有尸蛊 ≥1 层 + 业火 ≥1 层 |
| 冰裂 | 凝渊 DOT 结算时 | 目标同时有裂伤 ≥1 层 + 凝渊 ≥1 层 |
| 心魔 | 逆血暴击触发时 | 目标同时有迷魂 ≥1 层 + 逆血 ≥1 层 |
| 焚甲 | 业火增伤结算时 | 目标同时有破罡 ≥1 层 + 业火 ≥1 层 |

### 6.3 交互引擎接口

```javascript
// 状态交互引擎伪代码
const STATUS_INTERACTIONS = [
  {
    name: '蒸发',
    priority: 1,
    trigger: (target) => target.yehuo > 0 && target.ningyuan > 0,
    resolve: (target) => {
      const dmg = (target.ningyuan + target.yehuo) * 3;
      target.takeDamage(dmg, 'fire');
      target.ningyuan = 0;
      target.yehuo = Math.floor(target.yehuo / 2);
      target.pogang += 2;
    }
  },
  {
    name: '冻蛊',
    priority: 2,
    trigger: (target) => target.shigu > 0 && target.ningyuan > 0,
    resolve: (target) => {
      // 尸蛊暂停结算，层数保留
      target.shiguFrozen = true;
      target.shiguFrozenLayers = target.shigu;
      // 凝渊渊冻触发时一次性爆发
      if (target.ningyuan >= 8 || target.ningyuan >= 10) {
        const burstDmg = target.shiguFrozenLayers * 1.5;
        target.takeDamage(burstDmg, 'poison');
        target.shigu = 0;
        target.shiguFrozen = false;
      }
    }
  },
  // ... 其余交互
];
```

## 八、设计决策记录

| 决策 | 理由 | 状态 |
|------|------|------|
| 7种状态各绑1个锚点宗门 | 每种状态有"代言人"，强化宗门辨识度 | **已定** |
| 锚点加成为 +1 层 + 专属效果 | 单纯 +1 层太弱不够辨识，加专属效果让锚点宗门的该状态质变 | **已定** |
| 状态交互共8种 | 每种交互有叙事文本和独立机制，增加 build 深度但不至于过载 | **已定** |
| 交互有优先级 | 避免同一 tick 多重交互导致伤害爆炸 | **已定** |
| 凝渊参与4种交互 | 归墟作为"唯一不说谎的宗门"，凝渊的交互性最强，与 DOT 类状态都有冻结反应 | **已定** |
| 逆血参与3种交互 | 肉慈斋是深层反派，逆血的暴击触发机制天然适合与其他状态联动 | **已定** |
| 焚蛊交互使尸蛊减半而非清零 | 保持平衡性——如果清零等于免疫尸蛊太强 | **已定** |
| 碎魂交互使迷魂持续时间减半 | 避免碎魂成为无脑组合——破罡翻倍很强但有代价 | **已定** |
| 字段名改为拼音 | 与现有代码风格一致（中文游戏英文代码，拼音可读性优于缩写） | **已定** |
