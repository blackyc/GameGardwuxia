# 房间聊斋化迁移规格

## 风格参数
- 聊斋志怪：60%（市井人情 + 妖异氛围）
- 认知侵蚀：30%（描述轻微不可靠，偶尔第一人称视角滑移）
- 不可名状：10%（暗示修炼与异化的关系）

## 风格特征

1. **景物描写**：克制、精炼，避免堆砌
2. **冷幽默**：第三人称叙述偶尔露出淡淡荒诞感
3. **不可靠叙述**："你觉得是…"、"你数了数…可再数一遍又不是那个数"、"也许是…也许不是"
4. **古风核心**：所有比喻、意象来自中国传统志怪而非科幻
5. **修炼=异化**：越是修炼，越接近某种不可名状之物

## 示例转换

### 原文（赛博）：
> 文华殿的雕梁画栋间密布着天网府吏部天禄集团的监控终端阵列。殿中七十二根金丝楠木柱的表面覆盖着一层全息屏幕薄膜，每根柱子上实时滚动着对应城区的居民信用评分、义体注册信息和最近三次神经活动记录。

### 聊斋化：
> 文华殿中七十二根金丝楠木柱间隐有灵息流转——柱身以朱砂刻满禁制，每根对应一城百姓的命数、修为与最后三次入梦之迹。殿心供一方玉台，台上灵阵缓旋，每三十息掠过全城一次——你不太确定它在看什么，但你感觉得到那目光。
