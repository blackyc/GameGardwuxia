## 九、禁用词库（Blacklist）

以下词汇在所有文本中**绝对不能出现**。任何子 agent 如果生成了包含以下词的文本，视为质量不合格：

### 科技/赛博类
```
电路 芯片 算法 神经接口 天网 数据流 量子 节点 防火墙
服务器 数据库 下载 上传 安装 操作系统 程序 代码 终端
屏幕 键盘 鼠标 电池 充电 信号 频率 波段 扫描仪
纳米 基因 分子 细胞 染色体 克隆 突变
```

### 西式概念
```
公司 企业 股份 银行 贷款 保险
实验室 研究所 项目 方案 报告 记录
```

### 禁止的比喻
```
"像被格式化的硬盘"
"如电脑重启般"
"如同数据库查询"
任何含科技物的明喻/暗喻
```

## 十、命名规则速查

### 四个字改一个字，五个字改两个字

| 原 | 改 | 说明 |
|----|----|------|
| 梵网寺 | **忘**尘宗 | 忘字诀 |
| 紫霞山 | **赤**霞峰 | 霞→血 |
| 剑巢 | **锈**剑**冢** | 锈+冢=凋零+死亡 |
| 毒巢 | **药王**谷 | 毒巢→药王谷（反转） |
| 血镰 | **血禅**寺 | 镰→禅（武器→修行） |
