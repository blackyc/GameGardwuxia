# 鬼修MUD · 风格锚点

> 所有子 agent 生成/翻译文本时，必须将此文档注入 prompt
> 这是质量控制的最低门槛——不合格文本将被退回

---

## 一、调性比例（不可偏离）

```
█聊斋志怪████████████████████████ 60%
█认知侵蚀█████████████ 30%
█不可名状█████ 10%
```

### 60% 聊斋

- 诡异，但不完全是敌对的——有些鬼怪只是"在"
- 偶遇是日常的一部分。不是每一场遭遇都是战斗
- 世界的基本面和平：炊烟、集市、村民、走贩
- "不对"是藏在正常里面的
- 鬼怪有自己的逻辑——不一定是人类的逻辑，但不是"就是要害你"

### 30% 认知侵蚀

- 修炼者逐渐意识到：自己正在变化
- 功法里藏着不该有的文字
- 镜子不老实
- 影子不跟你同步
- 你"知道"了一些你不可能知道的事——从哪来的？
- 同门的变化你不敢问。因为你也变了。

### 10% 不可名状

- 祂不在描述中出现
- 祂偶尔在"空白"中出现——一个不该有名字的NPC、一个走不完的房间、一段完全无法理解的文字
- 祂的痕迹：渗液的墙壁、自己打开的窗户、不该响的钟
- 不解释祂。不描写祂。甚至不确认祂是不是"真实"的——留给玩家自己判断

## 四、叙事距离：近距离第三人称

### 规则

1. **你和主角一起发现，不是你告诉主角**
   - ❌ "他知道这里不对劲"
   - ✅ "他停下来。有什么不对。他说不上来——但他影子的动作慢了。"

2. **白描 > 解释**
   - ❌ "这是祂的痕迹，说明此地已被侵蚀"
   - ✅ "墙上的纹路不是水渍——是一只手，五指张开，昨天没有。"

3. **描写但不命定**
   - ❌ "他看到了一只百年老槐精"
   - ✅ "老槐树下站着一个穿青衣的老妇，天没黑，但树下的光很暗。他不知道她在看什么——他在看她之前，她已经在看他。"

4. **不说"恐惧""诡异""恐怖"——让人自己感到**
   - ❌ "一阵诡异的寒意爬上他的脊背"
   - ✅ "他的脊背上有什么在爬。不是冷风。是细碎的，一节一节的。"

## 五、对话风格

| 角色类型 | 说话方式 | 示例 |
|---------|---------|------|
| **凡人** | 口语化，市井味，偶有方言感 | "客官，这间房……您要不再换一间？这间西晒，夜里凉。" |
| **低阶修士** | 半文半白，矜持，话少 | "此山灵气有异。足下可曾觉否？" |
| **高阶修士** | 文言但"不对"——句子忽然中断，主谓错位 | "贫道修行三百载，见过……见过的东西。不能说。他也在听。" |
| **异化者** | 不说人话。用环境描述代替对话 | （他不会说话。他看着你。你的耳朵听见的不是他的声音——你听见的是自己昨晚的梦。） |
| **妖/鬼** | 逻辑通但错位的语言 | "我活着的时候也像你这样。别着急，你有的是时间。" |
| **祂** | **从不说话。不在文本中以任何可确认的形式出现。** | — |

## 六、文本节拍规范

### 房间描述（2+1 结构）
```
2-3 句环境描写（聊斋风：正常中埋着不正常）
1 句不对劲的细节（不解释）
0 句解释
```

### 敌人描述（1+1+1 结构）
```
1 句视觉：你看到了什么
1 句反常点：这个"人"/物哪里不对
1 句行为暗示：（可选）它可能要做什么——不确认
```

### 物品描述（1+1 结构）
```
1 句外观：朴素、带古意
1 句异常属性：使用后的代价/风险/不明效果
不解释来源
```

### 事件/奇遇描述
```
开头：正常/日常场景
中部：一个细节出现裂纹
结尾：裂纹扩大——但不完全翻开
留一扇没关死的门
```

## 七、去AI味硬约束

以下 AI 写作常见痕迹，每出现一处标记一次。超过阈值 = 退回重写：

### 禁止使用的AI高频表达（全文件扫描）
```
不禁 忍不住 不由得 下意识地 不由自主地
空气中弥漫着 他感到 她感到 你能感到
与此同时 另一边 时间来到了
不知为何 似乎在说 好像在说
温柔地 轻轻地 深深地 缓缓地
仿佛（每段限1次，超过退回）
```

### 段落均匀度约束
- 连续 3 段长度差异 < 10% → 警告，重写其中一段
- 连续对话超过 5 句无环境/动作/心理穿插 → 退回插入

### 情绪标签占比约束
- 情绪词（恐惧/害怕/诡异/恐怖/不安/紧张/惊讶）占比 > 1个/200字 → 退回

## 八、批量生成前的自检问题

子 agent 在生成每批内容后必须逐条自问：

1. ✅ 有没有赛博词混入？（黑名单扫描）
2. ✅ 有没有"解释为什么诡异"？（不是在写设定集）
3. ✅ 对话有没有角色辨识度？（凡人不像修士，修士不像异化者）
4. ✅ 有没有连续雷同句式？（三段同长=警报）
5. ✅ 有没有AI高频词汇？（"不禁""不由得"等）
6. ✅ 聊斋味够不够？（至少有一处"正常的日常中埋着不正常的细节"）
7. ✅ 祂有没有"出场"？（祂从不以任何可确认的形式出现在文本中）
8. ✅ 房间描述是否为 2+1 结构？
9. ✅ 敌人描述是否为 1+1+1 结构？
10. ✅ 道具描述是否为 1+1 结构？

## 九、风格评分卡

每批次产出抽样 10% 文本，按以下标准评分：

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 聊斋感 | 30% | 5=正常中暗藏诡异，白描不做解释；1=纯恐怖文 |
| 认知侵蚀 | 20% | 5=读者和主角一起困惑，逐渐意识到不对；1=没体现世界观的侵蚀性 |
| 去AI味 | 20% | 5=无AI高频词，段落节奏有变化；1=机械均匀 |
| 对话自然度 | 15% | 5=有角色辨识度，有潜台词；1=npc说话都一个样 |
| 术语准确性 | 15% | 5=无赛博残留，术语映射100%正确；1=有赛博词 |

**通过线：总分 ≥ 4.0 | 任一单项 < 2.0 = 该批次退回重写**
