## 一、设计哲学「融墨于画」

> 展开卷轴，一帧浅青色的山水先映入眼。远山叠在墨色里，
> 湖面留白只点几笔淡蓝。你刚要细看——画面里伸出一张半透的灰蓝
> 卡片，文字落在卡上，像本就该在那。卡角带着墨迹的毛边，
> 三个菱形腰牌从画卷下沿垂落，挂着金线流苏。
> 这不是 UI 叠在画上——这是画的一部分。

本美学以 jimeng 效果图为唯一锚点，服务于游戏的三层罗生门叙事：

| 叙事层 | 视觉表现 | 对应 UI |
|--------|---------|---------|
| 表层 · 烟火武侠 | 暖宣水彩 · 凡人市井的浅色调 | 日常页面：莫兰迪柔和 + 暖宣基底，如 jimeng「落月山庄」 |
| 夹层 · 灵异渗入 | 墨色从画面边缘渗入 · 朱砂渗线 | 畸变值上升：水墨晕染加重、朱砂红警示文字浮现（如 jimeng「江湖险恶…」） |
| 深层 · 不可名状 | 水墨全幅渲染 · 留白被吞没 | 灵修专属视角：冷墨调（见 `dunhuang_cold_cave_spec.md` 暗窟归档作为深层备选） |

### 核心原则

- **控件即画作**：UI 控件不是孤立的几何色块，而是画作本身的一部分。卡牌边缘=柔和纸张/墨迹边缘（非直角矩形），按钮=菱形徽章/宣纸贴纸/卷轴挂钩，与写意水彩背景深度融合
- **写意水彩背景**：背景占满全屏，是画作主体；卡片浮在画上而非独占屏幕；卡片用半透灰蓝圆角罩（似水彩晕染）既透出画面又保证文字可读
- **两套配色系统并存**：莫兰迪柔和色（日常点缀）+ 矿物高饱和色（战斗/强调），按情境动态切换比例（见二章 2.5）
- **场景即色板**：背景插画与配色随玩家所在大区动态变化（应天府 vs 问剑峰 vs 血禅寺 各不同，见十一章）
- **先 CSS 占位后插画**：v3.0 阶段背景插画先用 CSS 渐变（线性+径向叠层）模拟水彩，后期单独排期插入 svg/img 资产

## 二、色彩系统（莫兰迪 + 矿物双色板）

> **★核心变更**：v2.0 单一敦煌暖窟矿物色板 → v3.0 双色板系统。
> 莫兰迪柔和色负责「日常的诗意」，矿物高饱和色负责「冲突的张力」，二者比例随情境翻转。

### 2.1 莫兰迪柔和点缀色（日常主调）

用户指定色组，用于点缀、次要面板、低强度状态、日常卡片底纹：

| 名称 | 色值 | 用途 |
|------|------|------|
| 薄荷绿 `--mint` | `#A3C9A8` | 灵气/感知低强度、次要面板边框 |
| 暖桃粉珊瑚橘 `--peach` | `#E08E79` | 任务/奇遇、NPC 友善强调 |
| 天然木色 `--wood` | `#C5A059` | 卷轴/挂轴框架、中性暖底 |

### 2.2 矿物高饱和色（战斗/强调主调）

用户指定色组，用于战斗、强交互、关键强调：

| 名称 | 色值 | 用途 |
|------|------|------|
| 群青/靛蓝 `--lapis` | `#113F8A` → `#1B315E` | 战斗真气、武学高亮、深沉水面 |
| 朱砂/朱红 `--cinnabar` | `#B82F1E` → `#801414` | 战斗、伤害、警示（如 jimeng「江湖险恶…」） |
| 金箔/贴金 `--gold` | `#E6AF2E` → `#C2911B` | 贵重物品、菱形徽章边框、流苏 |
| 风化石白/沙土色 `--sand` | `#DFD3C3` → `#9F815B` | 未上色粗糙岩壁/地面，作高饱和红蓝的视觉缓冲 |

### 2.3 基底色（浅水彩基底，替代 v2.0 暖壁面）

不再是暗暖壁面，改为浅色调水彩基底（L 值 80-92）：

| 名称 | 色值 | 用途 |
|------|------|------|
| 暖宣纸 `--paper-warm` | `#EAE6DF` | 应天府等暖场景全局底 |
| 烟蓝宣 `--paper-mist` | `#C8D4DC` | 问剑峰等冷场景全局底 |
| 卡片灰蓝半透罩 `--veil` | `rgba(120,140,150,0.32)` | 所有卡片底（似水彩晕染，透出背景） |
| 卡片高亮态 `--veil-lit` | `rgba(226,230,220,0.55)` | 选中/悬停卡片（暖宣提亮） |
| 导航栏底 `--nav-base` | `rgba(40,38,42,0.78)` | 底部导航半透墨色 |

### 2.4 文字色（浅底高对比）

浅底配深字，与 v2.0 暖底白字相反：

| 名称 | 色值 | 用途 |
|------|------|------|
| 墨黑正文 `--ink` | `#2A2620` | 常规正文（落在灰蓝罩上） |
| 深灰次要 `--ink-soft` | `#5A5650` | 次要文字、冷却态 |
| 朱砂警示 `--ink-warn` | `#B82F1E` | 警示/强调（jimeng「江湖险恶」式） |
| 金箔强调 `--ink-gold` | `#9A6E1B` | 贵重物品名、数值 |
| 战斗伤害 `--text-danger` | `#C0301E` | 伤害数字（深朱砂） |
| 恢复绿 `--text-heal` | `#4A8A5A` | 治疗数字 |
| 灵修紫 `--text-spirit` | `#5A4A8A` | 灵石/畸变计数 |

### 2.5 配色比例规则（动态翻转）

| 情境 | 莫兰迪比例 | 矿物比例 | 说明 |
|------|-----------|---------|------|
| 日常（江湖页/行囊/人物） | 70% | 30% | 柔和为主，矿物仅作金箔点缀 |
| 战斗 / 强交互 | 30% | 70% | 朱砂群青主导，沙土缓冲 |
| 灵修视角（深层） | — | — | 切换至冷墨调（见冷窟归档） |

### 2.6 装备品级色（沿用语义，换浅底适配值）

| 品级 | 色值 |
|------|------|
| 凡品 | `#7A7268`（暖灰） |
| 良品 | `#2A2620`（墨黑） |
| 地品 | `#C2911B`（金箔深） |
| 天品 | `#D48030`（炽橙） |
| 灵品 | `#7A5AA0`（莹紫） |

### 2.7 边框体系（写意墨边，替代五页分区藻井）

不再用 v2.0 的方形嵌套藻井，改为 jimeng 风的**双线墨迹描边 + 不规则微透**：

| 区域 | 边框样式 | 说明 |
|------|---------|------|
| 通用卡片 | 双线墨边 `2px solid #4A4640` + 内侧 `1px solid rgba(74,70,64,0.4)` | 内外双线，似手绘 |
| 江湖·剧情卡 | 灰蓝半透罩 `rgba(120,140,150,0.32)` + 双线墨边 | jimeng 剧情文本卡质感 |
| 江湖·感知面板 | 暖宣底 `rgba(234,230,223,0.88)` + 双线墨边 | 宣纸贴纸感 |
| 武学·行功槽 | 金箔双线 + 当前槽金脉冲 | 保留 v2.0 行功槽语义 |
| 行囊·物品格 | 暖宣底 + 单线墨边，已装备=朱砂角标 | 包袱格 |
| 行囊·详情 | 宣纸贴纸感（暖米底 + 双线墨边 + 微阴影） | jimeng「落还君」式 |
| 舆图·画布 | 水彩毛笔笔触连线 | 节点=水墨圆点 |
| 人物·路引 | 金箔双线 + 星芒角花 | 路引卷轴感 |
| 战斗遮罩 | 朱砂 `#801414` 半透 + 菱格纹理 | 深朱砂聚拢 |
| NPC 对话 | 暖米宣底 + 双线墨边 + 顶部金线 | 弹窗 |

### 4.3 背景 CSS 占位规范（v3.0 阶段，后期替换插画）

未插入插画资产前，每场景用 CSS 渐变模拟浅色水彩（见十一章 11.4）：

```css
/* 应天府暖宣基底占位（示例） */
body[data-scene="应天府"] {
  background:
    radial-gradient(ellipse at 30% 20%, rgba(197,160,89,0.18) 0%, transparent 55%),
    radial-gradient(ellipse at 70% 80%, rgba(163,201,168,0.14) 0%, transparent 50%),
    linear-gradient(160deg, #EAE6DF 0%, #E2DED5 100%);
}
```

- 用 1 个线性渐变定基底色 + 2-3 个径向渐变叠留白与色块，模拟水彩
- 后期替换为 `<img>` 或内联 `<svg>` 写意水彩插画，保留 `data-scene` 驱动

## 十、过渡动画规范（T9.4）★新增「祥云帷幕」

### 10.1 ★祥云帷幕（页面切换核心动画）

每次底部导航切换页面，播放**完整祥云帷幕**：

```
阶段1 (0-300ms): 左云从左浮入 + 右云从右浮入 → 中央相遇遮挡全屏
阶段2 (300-400ms): 短暂停（遮挡状态，此刻在 DOM 切换页面内容）
阶段3 (400-700ms): 两云向两侧浮出 → 揭示新页面

  ┌──┐                              ┌──┐
  │云│ →→→→→        ←←←←←          │云│   阶段1: 向内浮入
  └──┘         ↓↓↓↓↓↓              └──┘
                    ┌────────┐
                    │ 遮挡    │             阶段2: 遮挡切换
                    └────────┘
  ┌──┐ ←←←←←                       →→→→→ ┌──┐  阶段3: 向两侧浮出
  │云│                                    │云│
  └──┘                                    └──┘
```

- 实现：两个伪元素云形 `div`（SVG 云轮廓 + 暖米半透填充 `rgba(234,230,223,0.92)`）
- 时长：总 700ms（浮入 300 + 停 100 + 浮出 300），移动端每次页面切换都播
- 缓动：浮入 `cubic-bezier(0.4, 0, 0.2, 1)` / 浮出 `cubic-bezier(0, 0, 0.2, 1)`
- 桌面端：仅右栏内容切换可播轻量祥云扫过（单云从右扫过，150ms），或直接跳过

## 十六、实现注意事项

1. **T9.1 多页面架构**：5 个全屏 div 用 `display: none/block` 或 `visibility` + CSS transition 控制，不用路由；背景层独立 `fixed` 不随页面切换
2. **T9.2 感知系统**：感知展开数据来自 `game.getRoomPerception()` 方法，返回通路/NPC/搜索点/交谈对象的完整对象
3. **T9.3 底部导航+操作栏**：导航是页面级（fixed bottom，页签图标条），操作栏是江湖页内组件（relative，菱形徽章），两层独立 DOM
4. **T4.1 桌面双栏**：用 CSS Grid `grid-template-columns: 2fr 1fr` 实现，左侧固定江湖页，右侧 `data-page` 属性控制显示
5. **T9.4 过渡动画**：祥云帷幕用两个伪元素云形 div + transform + opacity；战斗遮罩可用 JS + Canvas 做碎裂粒子
6. **T9.5 场景动态配色**：扩展 `renderer.js:445 updateLocationIcon()` → `resolveSceneStyle(room)`，设置 `body[data-scene]`，纯前端解析房间名「·」前缀
7. **菱形徽章**：仅江湖页内操作钮用，底部导航保留页签图标条
8. **兼容经典回合制**：战斗遮罩同样覆盖经典回合制模式
9. **优先移动端**：先实现移动端单页全屏架构，桌面端双栏作为增强（`@media (min-width: 768px)`）
10. **背景 CSS 占位优先**：v3.0 阶段所有写意水彩背景先用 CSS 渐变占位（见 4.3 + 11.4），插画资产后期单独排期插入
