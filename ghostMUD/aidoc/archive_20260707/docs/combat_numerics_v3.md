# 诡仙录战斗数值 v3.0 — 境界分层重建

> 基于用户指定的量级锚点，重建HP/ATK/DEF/MP/技能系数/敌人属性的完整数值体系。
> **设计日期**: 2026-06-25
> **依赖**: combat_system_v3_design.md (框架不变，仅替换数值层)

---

## 一、设计原则

1. **境界碾压原则**：高境界对低境界形成绝对压制。凡人打宗师 = 0%胜率，数值差距 > 50×。
2. **武修/灵修分化原则**：武修偏HP/ATK/DEF（肉搏型），灵修偏MP/异常状态效果（法术型）。同境界灵修HP约为武修80-85%，MP约为武修110-120%。
3. **倍数成长原则**：每个境界之间核心属性增长3-5×，确保跨境界战斗无翻盘可能。
4. **技能系数同步原则**：技能skillNum随atk量级同步放大，保持"轻击=atk×3-5倍"的比例关系。
5. **伤害类型区分原则**：武修默认物理伤害，灵修可打属性伤害，鬼/人祸类敌人完全免疫物理。

### 2.5 境界碾压验证

以凡人(0) vs 宗师(4)为例：

| 维度 | 凡人武修 | 宗师武修 | 比值 | 结论 |
|------|---------|---------|------|------|
| maxHp | 25 | 2000 | 80× | 凡人一击即碎 |
| atk | 3 | 400 | 133× | 凡人攻击刮痧 |
| def | 1 | 120 | 120× | 宗师近乎免疫凡人攻击 |
| 实际伤害/击 | 3×15=45 → 减def 120 = 0 | 400×800=320000 → 减def 1 ≈ 319999 | ∞ | 凡人0伤害，宗师一击万血 |

**结论**：凡人打宗师伤害为0（atk×skillNum < def），宗师一击秒杀凡人80次。数值碾压成立 ✅

```
技能伤害 = skillNum × (atk + 武器加成) - 目标def
```

保持"轻击skillNum ≈ atk的3-5倍"比例关系，确保轻击对同境界敌人有意义的伤害。

### 4.5 武修打鬼类敌人的解决方案

由于武修纯物理对鬼类敌人完全无效，提供以下出路：

1. **属性武器**：火扇/冰针/毒刃等属性武器自带属性伤害词条，武修装备后可打属性伤害（但系数远低于灵修）
2. **属性铭文**：焰心/淬毒等铭文提供附魔伤害，弥补武修对鬼类的无力
3. **组队**：灵修队友负责打鬼类，武修负责打凡间/修士敌人
4. **宗师突破**：宗师境界后武修可使用地品+绝学打出属性伤害，彻底解决
5. **消耗品**：符纸/灵符等消耗品提供一次性属性伤害手段

### 6.3 MP消耗与恢复平衡验证

以武师(3)武修为例（maxMp=400, mpReg=18/tick, tick=0.5s）：

| 技能组合 | 一轮MP消耗 | 恢复时间(打空→回满) | 说明 |
|---------|----------|-------------------|------|
| 5轻击 | 5×35=175 | (400-175)/18×0.5≈6.3s | 轻击流几乎不会空蓝 |
| 3轻+1中+1重 | 3×35+90+170=365 | (400-365)/18×0.5≈1s | 几乎打空但恢复极快 |
| 2中+1重+2辅 | 2×90+170+2×55=440 | 超出40，需等MP | 需要在循环中插入调息 |

**结论**：双门禁下MP恢复速率与消耗量的平衡关系成立，不同build有明显MP管理差异 ✅
