## 一、设计哲学

### 1.1 核心理念

> 战诀者，气循经脉而周流，身随气转，不假思索。
> 然气有缓急，招有顿挫——非一气呵成，乃呼吸之间。

**战诀 = 预设式的战斗自动循环 + 异步CD节奏管理。** 玩家在安全区将招式填入5个战诀位（A→B→C→D→E），战斗开始后按顺序出招，但每招有独立冷却时间（CD），形成双门禁约束：**CD就绪 AND 真气充足**，方可出招。

**设计哲学**：把战斗从「你选招式」变为「你设计一套战诀→CD节奏自动推进→真气不足时做关键决策」。双门禁使DPS（每秒伤害）成为非平凡优化目标——不同技能排列产生不同DPS，玩家需多次尝试才能找到最优套路。

### 1.2 设计来源

| 来源 | 贡献 | 层级 |
|------|------|------|
| **弈仙牌** | 顺序出招骨架（起→承→转→合→归）、5槽序列、自动对战 | 底层机制 |
| **江湖悠悠** | 装备对战斗参数的深度影响、装备鉴定+词缀随机 | 装备层 |
| **大巴扎** | UI视觉反馈：独立进度条、触发链流光连线、伤害/治疗数字上飘、状态堆叠可视化 | UI表现层 |
| **传统RPG** | 真气(蓝条)设定：与血条并列、上限可成长、战斗外恢复 | 资源层 |
| **师傅快出招** | 异步CD、异常状态体系、装备放大器（小丑牌鬼牌模式）、铭文词条 | 战斗深度层 |

### 1.3 与v2.0的关键变化对比

| 维度 | v2.0（真气单门禁） | v3.0（异步CD+双门禁） |
|------|-------------------|---------------------|
| 出招逻辑 | 纯顺序：起→承→转→合→归，无CD | 顺序+异步CD：A→B→C→D→E，但每招有独立CD |
| 门禁机制 | 单门禁：真气不足时4选1 | 双门禁：CD就绪 AND 真气充足 |
| Build空间 | 小（单变量：总气耗 vs 真气上限，脑算可解） | 大（双变量：CD节奏 × 真气消耗，DPS非平凡优化） |
| 开局状态 | 所有招式立即可用 | **所有招式同时开始读CD，开局无技能可用** |

| 姿态系统 | 无 | **已删除**（相关效果归入装备词缀） |
| 功法/被动链 | 无 | **已删除**（相关BUFF放进装备即可） |
| 出身系统 | 无 | **独立到identity_system.md** |
| UI | 真气条+五槽+门禁弹窗 | 真气条+五槽+**CD环形倒计时**+异常状态图标区 |
| 数值平衡 | 单变量（总气耗 vs 真气上限） | 双变量（CD节奏 × 真气消耗速率） |

## 二、概述

### 2.1 战诀循环

玩家在安全区将招式填入5个战诀位（A起→B承→C转→D合→E归），战斗开始后：

1. **所有招式同时开始读CD**（开局无技能可用，等CD转好）
2. **全自动释放**：CD转好+真气足够时自动出招，玩家无需手动点击
3. 按 A→B→C→D→E 固定槽序列出招，**不可跳槽**
4. 必须A出招后，B槽才解锁可释放
5. 若B和C的CD都已就绪，A打完可立即打B，B后立即可打C（**连打**）
6. 但必须先打B才能打C——不能跳
7. 每招检查双门禁：CD就绪 AND 真气充足 → 自动释放
8. 真气不足时自动触发门禁4选1（默认调息，玩家可手动干预选择）
9. 走完一圈（A→E）后从A重新开始循环
10. **玩家操作仅限**：预设战诀（战前）、变式/服药/脱战（战中干预）

### 2.2 核心循环示意

```
┌─────────────────────────────────────────────────────────┐
│              战诀 · 五式 · 异步CD版                     │
│                                                         │
│  [A·起式] → [B·承式] → [C·转式] → [D·合式] → [E·归式]    │
│      ↑                                                   │
│      └───────────── 循环 ─────────────────────────────────┘
│                                                         │
│  出招逻辑：                                              │
│    ① 战斗开始：所有技能同时开始读CD                       │
│    ② CD转好+真气足够 → 自动出招（无需手动操作）           │
│    ③ 轮到某式时检查双门禁：                               │
│       CD就绪 AND 真气≥气耗 → ✅ 正常出招                  │
│       CD未就绪 → 灰显等待                                │
│       真气不足 → ❌ 触发门禁（4选1）                      │
│    ④ 出招后该式进入CD                                    │
│    ⑤ A→B→C→D→E→A循环（全自动）                           │
│                                                         │
│  玩家操作：                                              │
│    · 战前：预设战诀（5式选择+排列）                    │
│    · 战中：变式（切换战诀）/ 服药 / 脱战              │
│    · 门禁：真气不足时自动触发，5秒窗口内可手动override   │
│                                                         │
│  顺序约束：                                              │
│    · 必须A出招后B才能出                                  │
│    · B和C的CD都转好时，A打完可连打B再连打C               │
│    · 但不能跳过B直接打C                                  │
└─────────────────────────────────────────────────────────┘
```

## 三、双门禁模型

### 3.1 门禁一：真气（MP）

**真气 = 传统RPG法力池**

```
真气定义：
· 与血条并列，拥有点数上限
· 每招消耗固定真气值
· 战斗内恢复方式：
  ├── 调息：牺牲该式位，跳过出招，恢复固定真气
  ├── 丹药：战斗内限服1次，如回气丹恢复40真气
  ├── 归式特殊：部分归式带有「回气」效果
  └── 装备铭文：如「回春」铭文每圈周天结束后恢复N点
· 战斗外恢复：打坐/回气丹/休息 → 自然满
· 境界提升 → 真气上限成长
· 战斗内以tick计算恢复：每0.5s结算一次 mpReg
```

### 3.2 门禁二：CD（冷却时间）

**CD = 异步冷却计时器**

```
CD定义：
· 单位：秒（实时异步）
· 技能释放后立即开始计时
· CD期间该式灰显，不可出招
· CD转好后该式高亮（就绪状态）

| 重击 | 5.0-7.0s | 低频高耗 |
| 辅助-防御 | 3.0-5.0s | |
| 辅助-治疗 | 4.0-6.0s | |

### 3.3 双门禁如何产生Build空间

**双门禁（真气 + CD）——非平凡优化**：
```
总真气 = 200, 战斗时长 = 30s
技能A: 40伤害/20真气/1.5s CD → 30s内CD够打20次但真气只够10次 → 400伤害
技能B: 60伤害/35真气/3.0s CD → 30s内CD够打10次但真气只够5次 → 300伤害
技能C: 55伤害/30真气/2.0s CD → 30s内CD够打15次但真气只够6次 → 330伤害

→ A+B交替: A(20真气)→等1.5s→B(35真气)→等3s→A... 真气消耗节奏不同
→ A+C交替: 更紧凑的CD但真气消耗更快
→ 最优排列需考虑：真气恢复速率 vs 消耗速率 vs CD间隙利用率
→ 不同组合DPS差异可达30-50%，无法脑算最优解
```

**四种Build策略**：

| 策略 | 特征 | 适合 |
|------|------|------|
| 爆发型 | 高CD重击+高气耗，前几招烧空真气，门禁频繁 | 灵修畸变爆发流 |
| 循环型 | 轻重混搭，每圈末触发1次门禁，调息续行 | 武修均衡流 |
| 周转型 | 全轻击，CD短气耗低，基本不门禁但伤害低 | 快剑流 |
| 充盈型 | 全辅助+轻击，永不门禁，伤害极低 | 肉盾/辅助流 |

### 3.4 顺序出招约束（详细规则）

**核心规则**：

1. **固定槽序列**：A(起)→B(承)→C(转)→D(合)→E(归)，不可跳槽
2. **解锁条件**：必须A出招后，B槽才解锁可释放；B出招后，C槽才解锁，以此类推
3. **连打机制**：若B和C的CD都已就绪，A打完可立即打B，B后立即可打C——无需等待
4. **不能跳**：必须先打B才能打C，即使C的CD已就绪而B的CD未就绪，也要等B的CD转好
5. **开局全CD**：战斗开始时所有招式同时开始读CD，**开局无技能可用**，等CD转好
6. **自动出招**：CD转好+真气足够时自动释放，玩家无需手动点击。CD最短的技能最先自动出招
7. **循环**：E（归式）打完后回到A（起式）重新开始

**时序示例**：
```
t=0.0s  战斗开始，所有技能开始读CD
        A(CD=1.5s) B(CD=3.0s) C(CD=2.0s) D(CD=5.0s) E(CD=4.0s)

t=1.5s  A就绪 → 自动出招A
        A出招 → A进入CD(1.5s) → B槽解锁

t=3.0s  B就绪（CD=3.0s从t=0开始）
        A刚出完，B已就绪 → 可立即出招B（连打）
        B出招 → B进入CD(3.0s) → C槽解锁

t=3.5s  A的CD转好，但当前在C槽位，A的CD就绪只是"可用"不代表"现在能打"
        需要走完C→D→E→A一圈后才能再打A

t=5.0s  C就绪（CD=2.0s从t=3.0s开始读？不——C的CD从t=0开始读）
        实际上C在t=2.0s就已就绪，但B在t=3.0s才打完
        所以C可立即出招（连打）

t=5.0s  C出招 → C进入CD(2.0s) → D槽解锁

t=5.0s  D就绪？（CD=5.0s从t=0开始 → t=5.0s就绪）
        是！D刚解锁且CD已就绪 → 可立即出招D（连打）

t=5.0s  D出招 → D进入CD(5.0s) → E槽解锁

t=4.0s  E就已就绪（CD=4.0s从t=0开始）
        但E槽在D出招后才解锁
        D出招后E已就绪 → 可立即出招E（连打）

t=5.0s  E出招 → E进入CD(4.0s) → 回到A槽

t=5.0s  A的CD转好了（t=1.5出招+1.5s CD = t=3.0s就好）
        → 可立即出招A → 新一轮循环开始
```

> **关键设计意图**：开局全CD意味着战斗不会立即开始，所有招式同时读CD。CD最短的技能最先自动释放，后续按顺序约束自动推进。玩家此时处于"观察期"——看CD转好顺序、看敌人战诀节奏，为后续干预决策积累信息。

## 四、战诀五式

### 4.1 五式结构

```
[A·起式] → [B·承式] → [C·转式] → [D·合式] → [E·归式]
    ↑                                           |
    └───────────── 循环 ──────────────────────────┘

每走完一圈 = 完成一个小周天
小周天累计影响：精元回复 / 暴击率 / 畸变判定
```

### 4.2 各式设计倾向

| 式位 | 名称 | 定位 | 推荐内容 | 违式效果 |
|------|------|------|---------|---------|
| A | 起式 | 开局态势 | 增益/护身、探测类武学、气势叠加 | 若放纯攻击：首击伤害-20% |
| B | 承式 | 主力输出 | 稳定伤害武学、破甲连击、DOT上毒 | 无惩罚（最自由的槽位） |
| C | 转式 | 应变判断 | 条件触发类、削敌buff、属性转换 | 若放纯攻击：条件效果不触发，视为普通攻击 |
| D | 合式 | 杀招释放 | 高真气消耗终结技、爆发伤害 | 无惩罚，但合式真气消耗×1.5（杀招就该费气） |
| E | 归式 | 回气收式 | 恢复类、清除debuff、蓄力为下一轮铺垫 | 若放纯攻击：下轮起式效果减半 |

### 4.3 真气门禁4选1（真气不足时）

当轮到某式、CD已就绪、但真气不足时，弹出选择：

```
┌─────────────────────────────┐
│  真气不足！劈山掌需要25气     │
│  当前真气：18                │
│                             │
│  ○ 调息    跳过该式，+30真气  │
│  ○ 服药    服用回气丹，+40   │
│  ○ 平斩    消耗10气，低伤害  │
│  ○ 强行    消耗全部18气，    │
│            伤害=60×(18/25)  │
│            = 约43            │
│                             │
│  [若5秒未选择，自动执行「调息」] │
└─────────────────────────────┘
```

| 选项 | 气耗 | 效果 | 风险 |
|------|------|------|------|
| **调息** | 0（跳过该式） | 恢复30真气，下式正常延续 | 该式不出招=浪费1个式位的输出机会 |
| **服药** | 0（跳过该式） | 从行囊选丹药服用（限1次/战） | 耗尽本场服药权 |
| **平斩** | 10 | 普攻一刀（伤害=攻击力×0.5） | 放弃该式的武学效果 |
| **强行** | 全部剩余真气 | 按比例打折出招 伤害×(当前气/需求气) | 气耗效率低下，归零后下一式必出门禁 |

> **挂机模式**：若5秒未选择，默认执行「调息」。

### 4.4 战诀预设

每个角色最多保存 **3套战诀**，战斗中可使用一次「变式」切换：

```
战诀一「破邪谱」    战诀二「守心谱」    战诀三「搏命谱」
A: 天罡望气术(探测)   A: 金汤·坚壁(护)    A: 天罡附体(全buff)

## 七、羁绊系统

### 7.1 概率型三档制

**设计原则**：羁绊不提供固定数值加成，而是提供**概率触发**，使战斗有随机性但不失控。同宗门武学数量触发共鸣：

| 同宗数量 | 档位 | 共鸣名 | 效果 |
|---------|------|--------|------|
| ≥2 | 入门 | 同气连枝 | 对应标签技能触发概率+20%（或真气上限+15） |
| ≥3 | 精通 | 一脉相承 | 对应标签技能触发概率+40%（或真气上限+25） |
| ≥5 | 大成 | 返璞归真 | 对应标签技能触发概率+60%；归式额外触发一次小周天效果（真气上限+50） |

## 八、畸变·战诀失控

### 8.1 篡改触发条件

每式执行前，做一次畸变判定：

```javascript
篡改概率 = baseHijackRate + corruptionLevel × 10%
baseHijackRate = 0（畸变0级）→ 3%（畸变1级）→ 8%（畸变2级）
               → 15%（畸变3级）→ 25%（畸变4级）→ 40%（畸变5级）
```

| 畸变等级 | 篡改率 | 篡改内容 |
|---------|--------|---------|
| 0（常人） | 0% | 无篡改 |
| 1（初显） | 3% | 招式描述文本轻微变异（「龙爪手」写为「你的手指比心快了一步」） |
| 2（外显） | 8% | 描述变异+偶尔伤害值波动±20% |
| 3（半人） | 15% | 战诀位被**替换为异化招式**（龙象脉·臂骨化龙骨→「你的右臂自己动了」） |
| 4（人皮） | 25% | 战诀位被替换+有概率**跳位**（执行完起式后跳过承式直落到合式→杀招不受控制提前放出） |
| 5（不可名状） | 40% | 战诀被**整体覆盖**为「祂的战诀」——五式全部变为不可名状技，效果随机 |

### 8.2 叙事表现

```
[战诀] 第二式·承式 → 龙爪手
       你运气至右臂，准备递出龙爪手——           
       但右臂没有出龙爪手。
       
       你的五指自行反转，掌心裂开一道竖缝，
       一根骨白色的东西从中探出，像是触须，又像是指节的延续。
       它不受控制地扫向蛇婆的面门——
       
       -82HP（畸变·异化自发：臂骨化龙骨）
       
       蛇婆发出一声你听不懂的声音，像是尖叫，又像是……
       某种你从未听过的语言中的一个音节。

       [道心判定] 你的手刚刚做了你没有让它做的事。
       道心-1（当前: 34/100）
```

### 8.3 畸变与CD的交互

畸变篡改时，CD规则发生变异：

| 篡改类型 | CD交互 | 叙事表现 |
|---------|--------|---------|
| 文本变异（1-2级） | CD正常 | 只是描述变了，战斗参数不变 |
| 战诀位替换（3级） | 异化招式使用**原招式的CD** | 替换的是招式内容，不是CD节奏 |
| 跳位（4级） | 被跳过的式位CD**强制重置为就绪** | 跳过的招式没出但CD被刷新，下一轮可立即使用 |
| 整体覆盖（5级） | 祂的战诀**忽略所有CD** | 不可名状技不受凡间规则约束，连续释放 |

> **设计意图**：畸变等级越高，对CD秩序的破坏越严重。1-2级只是"声音变了"，3级开始"内容变了"，4级"节奏乱了"，5级"规则没了"。这使畸变的恐怖从叙事层渗透到机制层。

### 8.4 灵修专属战诀

畸变≥3的灵修修士可以解锁**异化战诀**——主动将异化招式填入战诀位。威力极高，但风险巨大：

```
异化战诀「虫母礼赞」
A: 妖虫孵化（召唤3只共生妖虫）
B: 虫群号令（妖虫全体攻击）
C: 血肉通道（牺牲1只妖虫，精元全回复）
D: 虫母之触（int×5道心伤害，无视护甲）
E: 吞噬残余（吞噬所有死亡单位，精元满）

· 每次完整循环道心-2
· 畸变篡改率翻倍（你在主动邀请祂）
· 不能被变式切换回武修战诀（需回宗门「镇压」）
· 真气消耗极高→门禁频繁→双输螺旋
· 异化招式CD极短但自损严重
```

## 九、玩家干预系统

战斗中玩家保留**三类、各一次**的干预权：

### 9.1 变式（切换战诀）

```
> 变式 搏命谱
[战诀中断] 你强行逆转战诀路线，真气翻涌……
           真气-20（变式代价）
           起式·搏命谱 → 天罡附体
```

- 消耗：真气-20 + 当前式位被打断（该式效果取消）
- 新战诀从起式重新开始
- 冷却：每场战斗限1次
- **CD交互**：变式时所有式位CD减半（切换战诀打乱了原有节奏，但也给了一个喘息机会）

### 9.2 服药（紧急物品）

```
> 服药 护脉丹
[服药] 你咬碎护脉丹，药力随唾液渗入喉中……
       精元+50，畸变临时-5（持续10式）
       （战斗中限服药1次）
```

- 每次战斗限1次
- 丹药从行囊中选择
- 灵修服用「镇畸丹」暂时压住篡改率，但有10%概率丹药被「祂」替换为「无名丹」（效果未知）

### 9.3 脱战（逃跑）

```
> 脱战
[脱战判定] 追风脉修正 +30%脱战率……
           你后撤脱离，蛇婆追之不及。
           → 脱离战斗
```

- 脱战成功率 = 基础30% + 追风脉品阶×5%
- 脱战失败消耗一个行动回合（敌人获一次自由攻击）
- 灵修畸变≥4：20%概率脚不听使唤——逃跑方向随机

### 9.4 干预与双门禁的关系

干预权和双门禁是独立的两层：

1. **CD门禁**：CD未就绪时自动等待，无需玩家操作
2. **真气门禁**：真气不足时自动触发（4选1），默认5秒后选「调息」
3. **干预权**：玩家**主动**选择时机使用——变式（切换战诀）、服药、脱战。这些是双门禁自动循环之外的主动操作

D·合: 若HP<30% → 自爆AOE全场 + 自身濒死逃脱    CD: 6.0s
       若HP≥30% → 焰心·极（蓄力1圈，下圈起式伤害×3）CD: 6.0s
E·归: 余烬回光（清除自身debuff + 恢复20%HP）   CD: 5.0s

预判：涅槃自爆是演戏（教主濒死逃脱=不死）；真正需要防的是焰心·极的蓄力
      起式CD较短(3.5s)，BOSS会频繁压制灵台脉——需要带备用饰品应对
```

### 10.3 设计意图三原则

BOSS战诀的三个设计原则：

1. **可预判**：玩家观察1-2圈后能大概摸清BOSS的节奏（「她每到合式就放大招」），CD字段让节奏更清晰
2. **有对策窗口**：每个BOSS战诀存在1个「脆弱窗口」（如血佛降世后HP减半）
3. **不是背板**：条件分支（HP<X%时改变招式）保证了不同战斗展开不同节奏

## 十三、数值平衡框架

### 13.1 平衡变量

双门禁方案的核心平衡变量：

```
① 单招CD：每招冷却时间（决定出招频率上限）
② 单招气耗：每招消耗多少真气
③ 单招伤害/效果：每招产生多少价值
④ 真气上限：角色总真气
⑤ 真气恢复速率：每tick恢复量

系统的平衡方程：
  DPS = Σ(技能伤害) / Σ(有效出招时间 + CD等待 + 真气等待)

  真气上限 ≥ 一圈总气耗 → 真气不是瓶颈，CD是瓶颈 → CD压缩build更优
  真气上限 ≈ 一圈总气耗×80-100% → 周转型，偶尔门禁
  真气上限 << 一圈总气耗 → 真气是瓶颈，需要调息/服药补真气
```

### 13.5 门禁的经济学

```
调息：损失1式输出 = 放弃伤害X，换取30真气 ≈ 下一个归式能正常释放
      → 经济学上：用1个式位的当前收益，换下一个循环的完整运行
      → 适合「该式本来就弱」的情况
      → CD交互：调息期间该式CD照常转，调息结束后可能CD已好

平斩：消耗10气 = 伤害极低但不停转
      → 经济学上：避免循环中断，但放弃该式的武学效果
      → 适合承式/转式触发门槛后（附带效果重要，平斩不打乱节奏）

强行：消耗全部气 = 伤害打折但招式的附带效果（如眩晕/破甲/毒）照常生效
      → 经济学上：用真气效率换「我必须出这招的效果」
      → 适合归式是核心恢复技的情况——宁可打折也要回血

服药：0气耗 = 消耗药品（珍贵资源）
      → 经济学上：用长期资源换短期战斗力
      → 适合「这仗必须赢」的关键战斗
```

  结论: build B的DPS远高于build A，但build A更稳定
```

## 十五、风险与对策

| 风险 | 等级 | 对策 |
|------|------|------|
| CD+真气双约束导致战斗节奏过慢 | **高** | CD基准值偏低（轻击1.5-2.5s），真气恢复速率(mpReg)足够覆盖2-3个轻击的消耗；开局全CD期间玩家可观察敌方行动 |
| 开局全CD导致玩家感到"无事可做" | 低 | 开局CD等待时间≤1.5s（最短CD），自动出招后玩家进入观察模式；无需操作，关注敌方战诀节奏为后续干预做准备 |
| 装备鉴定开箱变肝 | 低 | 鉴定非强制——装备基础属性已生效，鉴定只揭示额外词缀和品阶 |
| 真气上限限制导致「好招用不起」 | 中 | 设计意图：境界锁+丹田投资=真气上限成长曲线，180-250气是正常中期范围 |
| MUD传统玩家抗拒自动战斗 | 低 | 保留经典模式；战诀模式设为「推荐但非强制」 |
| 门禁4选项选择困难 | 低 | 门禁经济学清晰（见13.5），且默认5s自动调息 |
| 异常状态叠加过于复杂 | 中 | 7种状态各自独立结算，交互规则限定为特定组合；UI图标区清晰展示 |
| 畸变篡改破坏CD节奏导致不可控 | 中 | 1-2级篡改不影响CD；3级用原招式CD；4-5级是高畸变后果，属于"你选择了这条路"的代价 |
| 双门禁平衡难度高于单门禁 | 中 | 用DPS模拟器(tools/dps_sim.js)离线验证build；数值占位由Agent 1产出后统一调试 |

## 十六、实施路径

### Phase 1：技能+装备数据建表（6h）
- 定义12宗门 × 5技能/宗门 = 60个武修技能（含cd字段）

### Phase 4：畸变+干预系统（4h）

## 附录A：已删除系统说明

以下系统在v3.0中**完全删除**，不再保留：

### A.1 姿态系统（v3.0文档 2.4节）
- 原设计：4种姿态切换战斗节奏（猛击/瞄准/防御/均衡）
- 删除原因：战斗深度已由双门禁+异常状态+装备放大器+羁绊提供，不需要再多一层系统
- 替代方案：相关效果（近战增伤/远程增伤/减伤等）归入**装备词缀**和**铭文**

### A.2 宗门被动链/功法系统（v3.0文档 2.6节、3.7节）
- 原设计：功法作为被动触发型技能，不占出招序列（反击/追击/火球术/雪球等）
- 删除原因：被动触发链增加了系统复杂度但build空间有限；装备放大器已提供类似的"改变战斗规则"体验
- 替代方案：相关BUFF效果放进**饰品特效**和**武器放大器**即可

### A.3 出身/身份系统（v3.0文档 3.6节）
- 原设计：21种身份提供常驻被动
- 删除原因：出身系统独立到 `identity_system.md`，不属于战斗系统范畴
- 详见：`D:\MUD\ghostMUD\docs\identity_system.md`（如有）
