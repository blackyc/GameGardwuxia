## 1. 房间命名规范

### 1.1 术语

| 术语 | 定义 |
|------|------|
| **房间 ID** | 代码层唯一标识，格式 `大区·房间名`，如 `问剑峰·剑坪` |
| **大区标识** | 房间 ID 的 `·` 前段，用于界面左上角显示，如 `问剑峰` |
| **房间显示名** | 房间 ID 的 `·` 后段，用于文本描述和移动面板，如 `剑坪` |
| **裸名 fallback** | 不含 `·` 的旧房间 ID，渲染时原样显示，大区标识为空或 `野外` |

### 1.2 命名规则（铁律）

- 所有新建房间 ID **必须**带 `·`
- 子级房间的大区前缀填**直接父级**，非根区域
  - 例：`薛家旧宅·古井底`（大区=薛家旧宅，显示名=古井底）
  - 例：`薛家旧宅·枯井·井底暗河`（大区=薛家旧宅，显示名=井底暗河）
- 现有不带 `·` 的房间 ID 须统一加前缀

### 1.3 渲染规则

```
大区标识 = location.split('·')[0]
房间显示名 = location.split('·').pop()
```

## 2. 门派/秘境地图文件规范

| 术语 | 定义 |
|------|------|
| **门派地图文件** | 每个门派 HQ 对应独立的 JS 文件，如 `work/rebuild_rooms_wenjianfeng.js` |
| **秘境副本文件** | 每个秘境副本对应独立的 JS 文件，命名 `work/rebuild_rooms_<name>.js` |

规则：一个门派/秘境 = 一个文件，不混放。

## 3. 新手引导系统

### 3.1 术语

| 术语 | 定义 |
|------|------|
| **黄金三章** | 问剑峰新手引导的三个章节：上山 / 入门 / 守夜 |
| **TutorialManager** | 独立状态机类，管理引导流程的章节进度、步骤触发、软引导 |
| **软引导** | 不锁定移动，NPC 提示方向，玩家可自由探索 |
| **视角切换** | 第二章 step 3，临时替换玩家角色为残剑师姐进行战斗，战后立即还原 |

### 3.2 引导数据层

| 术语 | 定义 |
|------|------|
| **引导数据文件** | `work/wenjianfeng_tutorial_data.js`，包含所有对话台词和步骤定义 |
| **对话台词** | `speaker` + `text` 结构，**严格 copy 设计文档原文，不改一字** |
| **场景描述** | `type: 'narration'` + `text`，设计文档有则用原文，无则自行发挥，遵循 narrative_design.md 规则 |

### 3.3 引导状态机

```
state: {
  chapter: 1 | 2 | 3,
  step: number,
  active: boolean,
  completedChapters: number[]
}
```

## 4. 时间系统

### 4.1 术语

| 术语 | 定义 |
|------|------|
| **gameTime** | 游戏内时辰数，0=子时 ~ 11=亥时，12 时辰循环 |
| **realTimeAccumulator** | 挂机累计真实毫秒数，每 5 分钟（300000ms）推进 1 个时辰 |
| **四时段** | 清晨/正午/黄昏/入夜，由 gameTime 映射，影响房间描述变体 |

### 4.2 时辰映射

| 时辰 | gameTime | 四时段 |
|------|----------|--------|
| 子 | 0 | 入夜 |
| 丑 | 1 | 入夜 |
| 寅 | 2 | 入夜→清晨过渡（归入清晨） |
| 卯 | 3 | 清晨 |
| 辰 | 4 | 清晨 |
| 巳 | 5 | 清晨→正午过渡（归入正午） |
| 午 | 6 | 正午 |
| 未 | 7 | 正午 |
| 申 | 8 | 正午→黄昏过渡（归入黄昏） |
| 酉 | 9 | 黄昏 |
| 戌 | 10 | 黄昏 |
| 亥 | 11 | 入夜 |

### 4.3 存档

`gameTime` 和 `realTimeAccumulator` 必须存入存档。

## 5. 问剑峰地图结构

### 5.1 房间清单（10 间）

| 房间 ID | 连接 |
|---------|------|
| `问剑峰·山门` | 上→剑阶 |
| `问剑峰·剑阶` | 下→山门，上→剑坪 |
| `问剑峰·剑坪` | 下→剑阶，东→伙房，西→藏剑阁，上→洗剑池 |
| `问剑峰·伙房` | 西→剑坪 |
| `问剑峰·洗剑池` | 下→剑坪，上→竹林 |
| `问剑峰·竹林` | 下→洗剑池，东→药圃，上→剑冢，深→竹林深处（仅子时） |
| `问剑峰·药圃` | 西→竹林 |
| `问剑峰·剑冢` | 下→竹林 |
| `问剑峰·藏剑阁` | 东→剑坪 |
| `问剑峰·弟子房` | 南→剑坪 |

### 5.2 弟子房（4 间）

| 房间 ID | 可交互 |
|---------|--------|
| `问剑峰·弟子房` | ✅ 玩家自己的房间，可感知发现床，可休息 |
| `问剑峰·苏小棠房` | ❌ 进入提示"这不礼貌" |
| `问剑峰·周碛房` | ❌ 进入提示"这不礼貌" |
| `问剑峰·阿满房` | ❌ 进入提示"这不礼貌" |

### 5.3 竹林深处迷宫

| 属性 | 值 |
|------|-----|
| 入口 | `问剑峰·竹林` → `问剑峰·竹林深处`（仅子时可见） |
| 结构 | 3-4 个相同"竹林深处"房间互相连接形成环 |
| 效果 | 玩家走几步发现地标重复，自然领悟"走不出去" |
| 出口 | 暂不做，暗示有秘密 |
