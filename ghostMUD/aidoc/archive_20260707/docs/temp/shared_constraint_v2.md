## 一、世界观基线

### 三层世界（见 worldview.md）
```
表层（凡间）：明代市井，一切正常。凡人看不见异常。
中层（修炼界）：修士可见。功法、丹药、灵气——但这些东西本身的来源不对。
深层（祂的领域）：不可名状。不在文本中以任何可确认形式出现。
```

### 核心哲学：金庸的皮 + 克苏鲁的骨
- **凡人视角**：正常古代世界。茶就是茶，算盘就是算盘。
- **低阶修士**：借诡异之物修炼，知其然不知其所以然
- **中阶修士**：身体在变，镜子里的人越来越不像自己——这条路不能回头
- **高阶修士**：知道真相。修行本身就是一场不可逆的交易
- **知识即诅咒**：越往上爬，看到的越多，付出的代价越大

### 3.2 叙事规则
1. **白描 > 解释**：描写现象，不写原因
2. **不说"恐惧""诡异""恐怖"——让人自己感到**
3. **你和主角一起发现，不是你告诉主角**
4. **祂从不以任何可确认的形式出现在文本中**
5. **对话要有角色辨识度**（凡人口语 vs 修士半文半白 vs 异化者不说人话）
6. **房间描述 2+1结构**：2-3句环境 + 1句不对劲的细节（不解释）
7. **敌人描述 1+1+1结构**：1句视觉 + 1句反常点 + 1句行为暗示
8. **物品描述 1+1结构**：1句外观 + 1句异常属性/代价
9. **连续3段长度差异 < 10% → 退回重写**

### 3.3 城市内房间特别约束
- 地名绝对干净（茶铺就是茶铺，一个"诡"字都不能有）
- 描述写实基底：金庸式白描，市井烟火气
- 但总有**一个**细节不对：
  - 茶铺掌柜算账时，算盘珠子上有不该属于它的纹路
  - 铁匠铺打铁的声音，在某个特定时辰会变成另一个节律
  - 布庄的某匹布，月光下会显现不是染上去的图案
  - 码头的水里，极深处偶尔有光——不是倒影
- **诡异在文本细节里，不在名字里**

## 四、数据格式规范

### 4.1 LOCATIONS（房间）
```javascript
const LOCATIONS = {
  '房间名': {
    desc: '环境描写，金庸式白描。城市房间写实中暗藏一个异常细节。城外房间聊斋味渐浓。',
    connections: { north: '隔壁房间名', south: ..., east: ..., west: ... },
    danger: 1-5,  // 城市1-2, 城外3-4, 远域4-5
    events: [
      '事件1: 日常中带着不对的细节',
      '事件2: 另一种异常',
      '事件3: ...',
      '事件4: ...'
    ]
  }
};
```
每个房间必有4个事件。事件是idle时随机触发的文本。

### 4.2 ENEMIES（敌人）
```javascript
const ENEMIES = {
  '敌人名': {
    hp: 数值, atk: 数值, def: 数值, exp: 数值, gold: 数值,
    type: '妖'|'鬼'|'邪'|'怪'|'精魅'|'人祸',
    desc: '1句视觉 + 1句反常点 + 1句行为暗示'
  }
};
```
遵循1+1+1结构。不写"它是xxx变的"这类解释性文字。

### 4.3 REALMS（境界）
```javascript
const REALMS = [
  {
    name: '境界名', cost: 修炼消耗, atk: 攻击, def: 防御, hp: 生命,
    daoxinThreshold: 最低道心要求,
    desc: '突破此境界后的身体/感知变化。要体现认知侵蚀的渐进——越往上越不对劲。'
  }
];
```
8个境界：凡人 → 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 合体 → 渡劫

### 4.4 ITEMS（物品）
```javascript
const ITEMS = {
  '物品名': {
    type: '丹药'|'符箓'|'法宝'|'阴物'|'杂物'|'特殊',
    desc: '1句外观 + 1句异常属性/使用代价',
    effect: '游戏效果简述',
    price: 价格,
    danger: 使用风险等级 0-3
  }
};
```

## 五、风笔者格采样（参考 rooms_ghost_all.js 已有干净房间）

干净的聊斋房间示例——新生成文本应达此水平：

> '巷子窄得只容两人并肩。青砖墙上覆着经年的苔痕——那苔藓是暗红色的，像渗进砖缝的旧血。头顶晾着几件衣裳，黄昏的光从衣裳缝隙里漏下来，光线里浮着细尘，像有人在上方筛着骨灰。一只黑猫蹲在墙头，眼是青的。它看了你一眼，张嘴打了个哈欠——嘴里的牙比寻常猫多了一倍。'

关键技巧：
- 前两句纯写实（窄巷、青砖、苔痕）
- 然后轻轻一推（"像渗进砖缝的旧血"——不说"就是血"）
- 再来一句日常（晾衣裳）
- 再推一把（"像筛骨灰"）
- 最后一句直接翻（猫牙多了一倍）
- 全程没有感叹词，没有"诡异""恐怖"标签
