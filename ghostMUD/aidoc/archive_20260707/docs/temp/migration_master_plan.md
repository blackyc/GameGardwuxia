## 三、世界观核心框架（W0 设计要点）

### 3.1 世界结构

```
表层世界（凡人、低阶修士所见）
├── 村镇县城：正常、平静、炊烟袅袅
├── 市井凡人：知道有"仙人"，但敬而远之
└── 低阶修士：修炼养生，延年益寿，偶尔斩妖除魔

夹层（中阶修士开始感知）
├── 修炼到一定境界后，能"看见"：月下的影不是影，庙里的佛不是佛
├── 功法中藏着"真言"——按某种顺序阅读，文本不再是你以为的意思
├── 有些地方"比较薄"：荒村废宅、古战场、枯井、老树根下
└── 凡人偶尔闯入：民间叫"撞客"、"鬼打墙"、"中邪"（聊斋经典题材）

深层（高阶修士 / 彻底异化者所见）
├── 修炼的终极真相：不是飞升，是"被看见"
├── 天之外有"祂"——不是神，不是魔，是不可名状的存在
├── 修士修炼越深，越接近祂的频率，越容易被祂"发现"
├── 飞升 = 彻底被祂同化，成为祂在世间的一只"眼睛"或一只手
└── 极度异化的修士：不再是人类形态，但仍保有部分意志（可选为敌/友）
```

### 3.2 修炼的代价

| 境界 | 能力提升 | 侵蚀表现 |
|------|---------|---------|
| 练气 | 感知灵气，延寿三十年 | 开始做重复的梦，梦中都是同一个场景 |
| 筑基 | 法术初成，百病不侵 | 影子偶尔不跟你同步 |
| 金丹 | 神通显现，寿逾二百 | 镜中倒影偶尔做出你没做的表情 |
| 元婴 | 元神出窍，移山填海 | 能"看见"不可见之物，但它们也看见你 |
| 化神 | 近于半神，一念千里 | 肉身开始"渗"——不是血，是一种你叫不出颜色的液体 |
| 渡劫 | 天劫降临 | 不是天雷劈你。是你看见祂了。祂在看你。 |
| ~~飞升~~ | ~~去往仙界~~ | **你没了。祂的手里多了一只眼睛。** |

### 3.4 忘尘宗深度设计（主角可选宗门）

作为对标"坐忘道"的核心宗派，忘尘宗需要的独特性：

**宗派宗旨**：
> 世间所见皆伪。山是山么？水是水么？你是你么？
> 《忘尘经》三卷：忘尘（忘伪）→ 忘我（忘执）→ 见真（见祂）
> 问题是——第二卷之后，忘的是执念，还是你自己？第三卷之后，你是见了祂，还是祂见了你？

**入门信物**：《忘尘经》残卷
- 经书无定文——每读不同，取决于读者此刻的"状态"
- 书页偶有字迹如虫蠕动，非幻觉
- 已有 7 位弟子读了第三卷后再没回来——不是死了，是不在他们应该在的地方了

**宗门NPC·净尘长老**：
> 一个看起来四十多岁的僧人，但实际上他已经不知道自己多少岁了——每次闭关出来，年龄都和他预期的不同。有时是变老了，有时是变年轻了。最近一次出来，他看起来像二十岁。他不高兴。因为这意味着"祂"越来越近。

### 4.2 STYLE_ANCHOR.md 核心约束（注入每批次 prompt）

```
## 鬼修MUD 风格锚点

### 可用意象域（白名单）
✅ 枯藤 老树 残垣 废庙 荒坟 古井 断碑 纸钱 香灰 油灯
✅ 月 雾 瘴 影 铜镜 旧衣 遗物 指甲 头发 牙齿
✅ 诵经 焚香 炼丹 画符 望气 问卦 招魂 封印 超度
✅ 血 肉 骨 皮 眼 舌 手 指

### 禁用意象域（黑名单）
❌ 电路 芯片 算法 神经接口 天网 数据流 量子 节点 防火墙
❌ 赛博系列全词库（见 terminology_map.md）
❌ 科技感比喻（如"像被格式化的硬盘"）

### 调性约束
- 叙事距离：近距离第三人称（主角视角），让读者和主角一起疑惑
- 恐怖来源：不是 jump scare，是"熟悉的东西不对了"
- 白描 > 解释：看到了什么 > 这意味着什么
- 聊斋比例：60%（诡异但不全是敌对的）+ 30%（认知侵蚀）+ 10%（不可名状）

### 对话风格
- 凡人说话：口语化，市井味，偶尔带方言感
- 低阶修士：半文半白，矜持
- 高阶修士/异化者：文言但不正常——句子忽然中断，主谓宾错位
- 非人之物：不说人话（用环境描述代替对话）

### 文本节拍要求
- 每个房间描述：2-3句（环境）→ 1句不对劲的细节 → 不留解释
- 每个敌人描述：1句视觉 → 1句反常点 → 战斗行为暗示
- 每个道具描述：1句外观 → 1句异常属性 → 不解释来源
```
