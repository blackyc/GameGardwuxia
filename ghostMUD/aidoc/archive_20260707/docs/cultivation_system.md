## 二、道心——唯一的精神轴

### 定义

道心是你还"是你"的程度。你的自我锚点、执念、名字、记忆——所有这些构成"你"的东西。祂的信息持续渗入世界，每一次吐纳、每一场战斗、每一次境界突破，都在磨损你的道心。

- 初始值：100
- 归零后果：**你不再是你。** 角色永久丢失。但在世界内留下一个痕迹——某个NPC会记得你，用错误的方式。
- 侵蚀不是独立的数值——侵蚀就是道心的下降。道心越低，你越不是你自己。

### 自然损耗

| 来源 | 道心变化 | 说明 |
|------|---------|------|
| 自然流逝 | -0.1/日 | 什么都不做也会缓慢被祂渗透 |
| 战斗 | -1~-3/次 | 取决于战斗强度和对手位阶 |
| 使用高等功法 | -2~-5/次 | 越是逆天的功法，代价越大 |
| 进入高灵浓度区域 | -0.5~-2/分钟 | "薄域"中祂的痕迹更密集 |
| 极限濒死（HP<10%） | -10~-20/次 | 生死关头，祂看得最清楚 |
| 境界突破 | -5~-10/次 | 每破一境，自己就少一分 |
| 境界突破失败 | -10~-20/次 | 反噬 |
| 被祂"标注"（剧情） | -10~-20/次 | 你被祂看见了——很深地看 |
| 使用侵术 | -2~-5/次 | 借祂之力，还祂之价 |

### 道心恢复

| 方式 | 恢复量 | 限制 |
|------|--------|------|
| 静坐冥想 | +1/时辰 | 安全区域 |
| 完成善缘任务 | +3~+5 | 单次 |
| 服用宁神丹药 | +5~+10 | 冷却12时辰，越用越弱 |
| 被他人"锚定" | +2 | 特定NPC事件 |
| 渡厄（归墟秘法） | +15 | 极稀有事件，代价未知 |

### 道心等级状态

| 道心值 | 状态 | 游戏表现 |
|--------|------|---------|
| 100-80 | 清明 | 完全正常 |
| 79-50 | 迟疑 | 偶尔看到文字描述中多出"不该有"的句子。NPC对话中出现模糊的低语 |
| 49-30 | 恍惚 | 镜中倒影不对。某些区域的描述变得"不对":正常文本里夹杂一两句不属于这个世界的描述 |
| 29-15 | 散乱 | 你的影子开始不跟你同步。你能"听见"NPC没说出口的话。功法文本在变化 |
| 14-5 | 崩解 | 你不确定自己是谁。战斗时可能攻击错误目标（包括自己）。你的名字在文本中偶尔被替换 |
| 4-1 | 破碎 | 祂的手已经在你身后了。游戏文本大面积扭曲 |
| 0 | **你不是你了** | 游戏结束。最终描述取决于你最后一次做的决定。 |

## 三、突破机制

### 突破成功判定

道心低于一定阈值后，突破难度急剧上升——你越不像"自己"，越难稳定地跨越境界：

| 道心段 | 突破基础概率 | 说明 |
|--------|------------|------|
| 80-100 | 70% | 清明——心神稳定，水到渠成 |
| 50-79 | 50% | 迟疑——偶有杂念，但仍可控 |
| 30-49 | 30% | 恍惚——心魔干扰，需额外准备 |
| 15-29 | 15% | 散乱——极为困难。功法起手时你的手不像你的手 |
| <15 | 不开放突破 | 崩解——你已无法维持足够久的心境 |

修正因子：
- 功法完整度：完整+10%，残缺-20%
- 丹药辅助：每颗悟道丹+5%（最多叠加3颗）
- 有人在旁护法：+10%

### 突破失败的代价

| 失败次数 | 代价 |
|---------|------|
| 第1次 | 道心-5（轻微反噬） |
| 第2次 | 道心-10，随机一项技能降1级 |
| 第3次 | 道心-20。触发"异化事件"——随机获得一项永久侵术，但道心上限-10 |
| 第4次+ | 道心-30。**异化事件升级**——你可能不再"完全是自己"。随机触发：记忆替换、名字改变、宗派认知偏移 |

## 五、死亡与重生

### 两种终结

| 终结类型 | 触发方式 | 后果 |
|---------|---------|------|
| **肉身死亡** | HP归零 | 道心≥30：可"回魂"——最近安全点复活。道心减半。道心<30：无法回魂，**永远死去** |
| **道心崩坏** | 道心归零 | 你不再是"你"。角色永久丢失。世界内留下痕迹——某个NPC会记得你，用错误的方式。你留下的残影可能成为其他玩家的"敌人" |

> 没有第三种死法。道心归零 = 被祂同化 = 你消失。不需要额外的"被标记带走"——因为侵蚀就是道心的流逝，终点只有一个。

## 六、战斗中道心消耗

| 触发条件 | 道心变化 |
|---------|---------|
| 面对位阶3+的鬼/怪/精 | -1/回合 |
| 面对堕修 | -1~-3/回合（位阶决定） |
| 在"薄域"战斗 | 灵力恢复+20%，但道心消耗翻倍 |
| 使用侵术 | -2~-5/次，对敌人额外精神恐惧 |
| 濒死（HP<10%） | 5%概率触发"祂的一瞥"：攻击×3，道心-15 |
| 面对祂的痕迹 | **-10/回合。不要战斗。走。** |
