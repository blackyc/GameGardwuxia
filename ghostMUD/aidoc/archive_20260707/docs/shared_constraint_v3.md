# Ghost MUD v2.0 —— 房间重写共享约束（v3）

> 基于 pkuxkx（北大侠客行）实采房间描述文本的句子结构分析。
> 所有 AI agent 写入房间时必须遵守本约束。

## 一、语料来源与句子分析

### 1.1 实采样本（来自 pkuxkx 论坛/搜索引擎片段）

**样本A — 扬州中央广场（城市中心房间）**
> 这里是城市的正中心，一个很宽阔的广场，铺着青石地面。一些游手好闲的人在这里溜溜达达，经常有艺人在这里表演。中央有一棵大榕树，盘根错节，据传已有千年的树龄，是这座城市的历史见证。树干底部有一个很大的洞(shudong)。你可以看到北边有来自各地的行人来来往往，南面人声鼎沸，一派繁华景象，东…

**样本B — 小吃店（商业/室内房间）**
> 这是一家热闹小吃店，经营各地的风味小吃，据说店主当然也是走南闯北的，才学到各地的手艺，后来定居在扬州，现在可是扬州城有名的小吃店，馋嘴的小孩子总是把这里挤的满满的。

**样本C — 万安塔四层（战斗/高塔房间）**
> 这里是万安塔的第四层，四周火把通明，塔内亮如白昼。在暗处站着几个番兵，守着一面响锣(luo)，对你虎视眈眈。

**样本D — 东门 / 东大街（通道/路口房间）**
> 东大街 这里明显的出口是 northwest、west、north、east 和south。

### 1.2 句子结构模式（从样本归纳）

| 模式 | 公式 | 典型长度 | 适用场景 |
|------|------|----------|----------|
| A | "这里是[地点/位置]，[氛围/特征]，[细节]。" | 10–18字/分句 | 核心地点、广场、塔楼 |
| B | "这是一[家/座/处/间][场所]，[功能]，[传说/历史]。" | 5–12字/分句，连缀3–8分句 | 商铺、客栈、酒馆 |
| C | "[方位][景物/人物]，[动作/状态]，[感官]。" | 10–20字 | 环境点缀 |
| D | "你可以看到[方向][景象/出路]。" | 12–22字 | 出口引导 |
| E | "[方位][站着/坐着/走着][数量][NPC名]，[正在做…]，[对你…]。" | 15–25字 | NPC在场场景 |
| F | "这里[明显的/唯一的]出口是 [方向列表]。" | 固定句式 | 出口声明 |

### 1.3 句子长短比（硬指标）

| 项目 | 范围 |
|------|------|
| 短分句（逗号分隔单元） | **4–12 字符** |
| 中句（一个完整意思） | **10–22 字符** |
| 长复句（多逗号连缀） | **25–54 字符**（整句） |
| 每房间总字数 | **40–100 字**（描述部分，不含出口声明） |
| 分句数 | **3–6 个逗号分隔单元** |
| 长短句交错 | 必含1–2短句 + 1长复句，或用2–3中等句 |

### 1.4 致命禁用词（写房间描述时不得出现）

| 禁用词 | 原因 |
|--------|------|
| 任何现代科技词（电脑/芯片/终端/服务器/系统/程序/接口/数据/信号/扫描…） | 聊斋世界观 |
| "契约""合同""利息""文档""报告""档案""问卷""表格" | 非修仙叙事体系 |
| "你" 作主语（"你看到""你走过"等） | 保持MUD第三人称描述传统 |
| "这儿""那儿""这么""那么" | 口语化，不符MUD文本规范 |
| "非常""十分""极其" | 空洞修饰，用具体描写替代 |
| "显然""当然"（除非在人物对话/"据说"模式中） | 暴露作者声音 |

### 1.5 准许使用

| 词汇/句式 | 说明 |
|-----------|------|
| "这里""此处""此间" | MUD标准开场 |
| "据说""相传""据传" | 引入传说/背景 |
| "只见""但见""可见" | 视觉导入 |
| "隐隐""若有若无""依稀" | 聊斋式氛围 |
| "幽幽""森森""蒙蒙""脉脉" | 叠词氛围词 |
| "一盏""一缕""一袭""一抹" | 量词+意象 |
| 文言虚词（之/乎/者/也/矣/耳） | 适量点缀，不可泛滥 |

## 二、房间分类与重写策略

### 2.1 三类房间处理优先级

#### ⭐ A类 — 直接复制房间（高相似度）
**条件**：pkuxkx/书剑MUD中存在同名或同功能房间，且聊斋世界观下可直接使用。
**规则**：
- 保持原有句子结构不变 → 替换地点名、NPC名、氛围词为聊斋版
- 每个原始房间**只能复制一次**（不得同一source room产出多个目标房间）
- 复制后必须在 comment 中标注来源（`// source: pkuxkx 扬州客店 room id: yz_hotel`）

**适用场景**：客店、酒楼、茶馆、药铺、当铺、铁匠铺、城门、大街
**聊斋化替换表**：
| 原词 | 聊斋版 | 上下文 |
|------|--------|--------|
| 官兵/守卫 | 城隍阴兵 / 巡夜鬼差 | 城市城防 |
| 掌柜/老板 | 掌柜（不变）/ 老掌柜 | 商铺 |
| 店小二 | 跑堂的 / 伙计 | 客栈酒楼 |
| 艺人/杂耍 | 说书人 / 算命先生 | 广场集市 |
| 乞丐 | 落拓道人 / 流浪散修 | 街头 |
| 商人 | 行脚商 / 货郎 | 街道 |
| 醉汉 | 醉醺醺的酒客 | 酒馆 |
| 番兵/武士 | 山精 / 巡山夜叉 | 野外/关卡 |
| 和尚/僧人 | 僧人（不变）/ 云游僧 | 寺庙 |
| 尼姑 | 尼姑（不变）/ 女冠 | 庵堂 |
| 道士 | 道士 / 真人 | 道观 |
| 青石板路 | 青石板路（不变） | 街道 |

#### ⭐ B类 — 参考重写房间（中等相似度）
**条件**：MUD存在类似功能房间，但聊斋世界观需要深度改写。
**规则**：
- 参考MUD原句的**句子长度、分句数、节奏感**，用聊斋元素重写
- 保持句式模板不变，替换内容
- 必须满足 §1.3 的句长指标

**适用场景**：宗派HQ房间、修炼密室、野外遇妖点、墓地/义庄、渡口/码头

#### ⭐ C类 — 完全原创房间（无对应源）
**条件**：聊斋世界观独有房间（如"狐仙祠""纸人铺""鬼市入口"等）。
**规则**：
- 严格遵循 §1.2 的句式模板
- 必须满足 §1.3 句长指标
- 必须通过句长校验脚本

## 三、七种核心房间模板

### 模板1：城市广场/中心
```
这里是[城/镇]的[中心/核心]，[形状/大小]的[广场/空地]，[铺着什么地面]。
[人群/氛围描述]，[活动/艺人表演]。
[方位]有[一棵/一座][标志物]，[特征描述]，据传已有[年龄/历史]。
你可以看到[方向]……[出口描述]。
```

### 模板2：商铺/店铺
```
这是一[家/间][店铺名]，[门面特征]，[招牌/幌子描述]。
[店主/伙计]正在[做什么]。
[货架/柜台上][陈列着什么]。
[气味/光线/声音]。
```

### 模板3：酒馆/客栈
```
这是一[家/座][酒馆/客栈]，[层数/规模]，[牌匾/灯笼描写]。
里面[几桌客人]，[正在做什么]。
[掌柜/跑堂][行为描写]。
[酒香/饭菜香/烛火/喧哗声]。
```

### 模板4：城门/大道
```
这里是[城门名/道路名]，[石板路/黄土路/泥路]向[方向]延伸。
[路旁][树木/房屋/摊贩]。
[时辰]时分，[人流/车马/鬼影]。
```

### 模板5：密室/修炼地
```
这是一间[大小][石室/洞府/静室]，[墙壁/石壁]上[凿痕/符文/青苔]。
[角落]放着[蒲团/石床/丹炉]。
[灵气/阴气/香火][流动/盘绕]。
[光线/温度/声音]。
```

### 模板6：野外/山道
```
这是[山名/地名]的[位置]，[山路/小径]蜿蜒[方向]。
[两旁][草木/怪石/坟冢]。
[远处/近处][景象/声音/气味]。
[天候/光线]。
```

### 模板7：鬼域/妖境
```
此处[阴气/妖气]弥漫，[地面/空气]中[异常现象]。
[近处][鬼影/妖物/异象]。
[声音]若有若无，[令人/使人]……
[特殊感官]。
```

## 七、房间嵌套系统（"观察"按钮）

### 7.1 设计理念
大房间嵌套小房间，通过交互面板「观察」按钮进入。参考放置江湖的密室/隐藏地图机制和pkuxkx的 look/ask 交互范式。

**核心规则**:
- 每个可嵌套的父房间在 `observable` 字段定义可探索内容
- 玩家点击「观察」→ 引擎检查当前房间 → 返回观察描述 → 若存在子房间且满足预设条件 → 显示入口选项
- 子房间有自己的独立描述、出口、NPC、物品
- 离开子房间回父房间（子房间出口default指向父房间）

### 7.2 预设条件类型（从 pkuxkx / 放置江湖 实战归纳）

| 类型 | 示例 | 数据字段 |
|------|------|----------|
| 技能等级 | 轻功≥40过独木桥、拳脚≥450踹门 | `{type:"skill", skill:"lightfoot", value:40}` |
| 修为境界 | 筑基以上感知灵气异常 | `{type:"realm", value:"筑基"}` |
| 道心值 | 道心>50察觉阴气 | `{type:"daoxin", value:50}` |
| 持有物品 | 家主令开门、钥匙开锁 | `{type:"item", id:"jiazhu_ling"}` |
| 任务完成 | 完成某任务链后NPC给入口线索 | `{type:"quest", id:"quest_hotel_owner"}` |
| 宗派归属 | 只有某宗派弟子可入 | `{type:"faction", id:"ziwei"}` |
| 时辰 | 子时鬼门开、午时阳气盛 | `{type:"time", value:"子时"}` |
| 环境操作 | 推巨石/搬柴/踹门（用技能替代） | `{type:"skill", skill:"str", value:30}` |
| 组合条件 | 需要两个以上条件同时满足 | `{type:"composite", and:[...]}` |

### 7.3 子房间数据格式
```javascript
// 父房间中
{
  id: "yt_hotel",
  name: "悦来客栈·大堂",
  template: 3,
  desc: "这是一家……",
  exits: {...},
```
