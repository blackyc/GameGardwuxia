# 房间 ID 命名规范

> 决策日期：2026-06-28
> 状态：**强制执行**

## 核心规则

所有房间 ID 必须包含 `·`（中文间隔号），格式为 `大区名·房间名`。

### 层级关系

| 层级 | ID 格式 | 示例 |
|------|---------|------|
| 顶层房间 | `大区·房间名` | `应天府·东大街`、`问剑峰·剑坪` |
| 子级房间 | `父房间·子房间名` | `薛家旧宅·古井底`、`问剑峰·竹林深处·岔路甲` |
| 深层嵌套 | `根·中间·叶子` | `薛家旧宅·枯井·井底暗河` |

### 渲染规则

- **大区标识**（左上角）= `location.split('·')[0]`（取第一段）
- **房间名显示** = `location.split('·').pop()`（取最后一段）
- 对不带 `·` 的旧 ID，fallback 为原字符串（向前兼容，但新房间不允许）

### 子级房间规则

子级房间的大区前缀填**直接父级**，而非根区域。

示例：玩家进入某宅院的井底 → ID 为 `薛家旧宅·古井底`，渲染时大区显示 `薛家旧宅`，文本描述为"你在古井底，你观察到……"

### 连接引用

`connections` 字段中的所有房间引用必须使用完整 ID（含 `·`），与 `LOCATIONS` 的 key 保持一致。
