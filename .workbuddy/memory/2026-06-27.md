## ghostMUD · T6.3 QUESTS 系统修复 + 迁移

**背景**：用户要求继续 docs 里的 task 游戏开发。核查发现 docs/task_agent_a/b/c/d（房间/敌人/物品生成）均已落地（83城市/35野外/28副本/60敌/120物）。权威追踪文档 `refactor_task_tracker.md` 显示最高优先级 P0 待办为 T6.3（QUESTS增量迁移）。

**发现的核心 Bug**：QUESTS 系统**完全断裂**——
- `integration_v2.js` QUESTS 用 `stage.action` + 每阶段 `stage.reward`
- 引擎 `game.js` 读 `stage.type` + 顶层 `q.rewards`
- → 任务永远不推进；完成时 `q.rewards undefined` 触发 TypeError；任务页渲染崩溃
- 且 NPC 的 `questStart:"lost_sealing_jade"` 等是悬空引用（无此 quest id），任务不可达

**修复内容**：
1. `work/integration_v2.js` QUESTS 重写为引擎契约：22条（原15条重新契约化 + 7条迁移自 v1 ghost_quests_v2，护送/解密/拜师原型，聊斋化，锚定185间有效房间）
2. `src/game.js` `checkQuestProgress` 增强：向后兼容的位置/目标门控（go类按location、kill按target、find按s.location）
3. `src/game.js` 新增 `_autoStartQuests()`：移动后/开局自动接取 startLocation 匹配的任务，免改410KB NPC文件
4. stage0 设计铁律：autoStart任务 stage0 不得是"抵达startLocation"（否则卡死）

**验证**：vite build ✓；契约校验22/22通过；端到端模拟 q001/q002/q003/q014 推进+完成+发奖无误。

**改动文件**：
